文生图与图生图：潜空间扩散、DiT 与原生多模态

上一章讲了怎样从噪声采样、怎样加条件。一个真实的文生图系统还要回答：百万像素放在哪里去噪，用什么网络，怎样读懂提示词、接受草图和参考图，怎样压到一两步，怎样判断画得好不好。这一章先把一张 1024×1024 的图从像素一路算到账单，再逐个部件讲设计理由；最后回到一个还没定论的问题：图像该用扩散生成，还是像文字一样逐个 token 地生成。

从零开始：一张 1024×1024 的图是怎样生成的

这一节用一个贯穿的例子：用一个 FLUX.1 规模（120 亿参数）的模型，按提示词 “a café on a rainy street at night, the neon sign reads OPEN” 生成一张 1024×1024 的图。每一步先说做什么，再算出具体的数，最后汇总成一张账单。熟悉潜空间扩散的读者可以直接跳到「去噪网络」。

一张图是一个三百万维的向量

1024×1024 的彩色图有 \(1024\times 1024\times 3 = 3{,}145{,}728\) 个数（红、绿、蓝三个通道），通常缩放到 \([-1, 1]\)。“生成一张图”就是从一个三百万维空间里的分布中采样。第 章的扩散模型原则上可以直接在这个空间里做，DDPM 和 Imagen 就是这样做的（像素空间扩散）。

问题在于大部分维度描述的是人眼几乎察觉不到的东西。把一张照片里相邻像素之间的细微起伏换成另一组统计上相同的起伏，人看不出区别，逐像素的均方误差却可能很大。像素空间的去噪器要花大量容量建模这些细节。潜空间扩散的论文（Rombach 等, 2022）把压缩分成两种：感知压缩去掉看不出来的细节，语义压缩理解画面里有什么。它的做法是让一个专门的网络先做前者，扩散模型只管后者。

第一步：VAE 把图压成潜图

潜空间扩散（latent diffusion, 2022，即 Stable Diffusion）先训练一个 VAE（变分自编码器）：编码器把图像压成一个小得多的“潜图”，解码器再把它还原。训练目标是“还原得像”：逐像素误差，加上比较深度网络特征的感知损失，加上一个让细节逼真的小对抗损失，再加一点 KL 惩罚让潜图的分布规整、便于扩散。训练好以后 VAE 冻结，扩散只在潜图上做，最后由解码器还原成像素。

代入例子：每边下采样 \(f = 8\)，16 个通道（SD3 与 FLUX.1 的配置）。\(1024\times 1024\times 3\) 变成 \(128\times 128\times 16 = 262{,}144\) 个数，少了 12 倍。每边压了 8 倍，数却只少 12 倍，是因为通道从 3 个变成了 16 个：潜图的每个“像素”是一个 16 维向量，描述原图一块 8×8 区域的内容。SD 1.x 只用 4 个通道（少 48 倍），细节和小字更容易糊掉。

第二步：切成 patch，变成 token

Transformer 去噪器处理的是 token 序列。把潜图切成 \(p\times p\) 的小块（patch，和第 章的 ViT 一样），每块拉平成一个向量，再用线性层投影到网络宽度 \(d\)：

\[ n_{\text{token}} = \frac{H}{\htmlClass{sym-f}{f}\,\htmlClass{sym-p}{p}}\times\frac{W}{f\,p} \]
VAE 把每边压缩 \(f\) 倍，去噪器再把潜图切成 \(p\times p\) 的 patch，每个 patch 一个 token。token 数决定了每一步的计算量，而注意力的代价随 token 数平方增长。
\(f\)
VAE 的下采样倍数：SD 系列与 FLUX.1 为 8；DC-AE 等深度压缩编码器为 32 或更高
\(p\)
patch 边长，常为 2
1024×1024，\(f = 8\)，\(p = 2\)：\(64\times 64 = 4096\) 个 token。每个 token 装着 \(2\times 2\times 16 = 64\) 个数，投影成 \(d = 3072\) 维（FLUX.1 的宽度）。2048×2048 时变为 16384 个 token，注意力的计算增加 16 倍。

第三步：把提示词变成向量

去噪网络不认识文字。提示词先经过一个文本编码器：一个预训练好、通常冻结的语言网络，把提示词变成一串向量，每个 token 一个。FLUX.1 用两个：T5-XXL 的编码器给出最多 512 个、每个 4096 维的向量序列，去噪网络逐 token 地“读”它；CLIP（第 章）的文本编码器给出一个 768 维的整句向量，和时间步一起去调制每一层（下文的 adaLN）。例子里的提示词约 20 个 token，其余位置是填充。T5 的分词器是在英文为主的语料上训练的，中文提示词它处理得很差，这是后来改用多语言大模型当编码器的原因之一。

文本编码器只跑一次：T5-XXL 的编码器约 47 亿参数，编码 512 个 token 约 \(2\times 4.7\times 10^9\times 512\approx 5\times 10^{12}\) 次浮点运算（FLOP），不到下面去噪总量的 0.3%。它决定的是模型“能听懂什么”，见下文「提示词」一节。

第四步：从噪声出发，去噪几十步

起点是一个和潜图同样形状（128×128×16）的纯高斯噪声。每一步，去噪网络看当前的潜图 \(\mathbf x_t\)、时间 \(t\) 和文本向量，预测速度（第 章的流匹配），沿速度走一小步。这里取 28 步。如果用 CFG，每一步要算两遍（有提示词、没有提示词各一遍），代价翻倍；FLUX.1 [dev] 用“引导蒸馏”把 CFG 的效果直接训进了模型，一遍就够（见「少步生成」）。一张图的计算量：

\[ C_{\text{图}} \approx \htmlClass{sym-K}{K}\cdot \htmlClass{sym-g}{g}\cdot\big(2\,\htmlClass{sym-Na}{N_{\text{act}}}\,\htmlClass{sym-n}{n} + 4\,\htmlClass{sym-L}{L}\,n^2 d\big) \]
步数 × 每步跑几遍 × 每遍的计算量。每遍里，线性层的部分是“每个 token 经过的参数量 × token 数 × 2”（一次乘加算 2 次运算）；注意力的部分随序列长度平方增长（\(QK^\top\) 和乘 \(V\) 各 \(2n^2d\)）。
\(K\)
去噪步数
\(g\)
用 CFG 时为 2，否则为 1
\(N_{\text{act}}\)
每个 token 实际经过的参数量。FLUX.1 按结构估算约 65 亿，总参数约 120 亿；为什么比总参数少，见下文「去噪网络」
\(n\)
序列长度：图像 token + 文本 token
\(L,\ d\)
块数与宽度（FLUX.1：57 块，3072 维）
FLUX.1，\(n = 4096 + 512 = 4608\)：线性部分 \(2\times 6.45\times 10^9\times 4608\approx 5.9\times 10^{13}\)，注意力 \(4\times 57\times 4608^2\times 3072\approx 1.5\times 10^{13}\)，每步约 \(7.4\times 10^{13}\) FLOP。28 步、不用 CFG，约 \(2.1\times 10^{15}\)（2.1 PFLOP）。H100 的 BF16 稠密峰值约 989 TFLOP/s，即使满载也要约 2 秒。

去噪占了绝大部分计算。后面的「潜空间的取舍」和「少步生成」动的就是卡片里的这几个数：更狠的 VAE 压缩（\(n\) 更小）、更少的步数（\(K\) 更小）、去掉 CFG 的第二遍（\(g = 1\)）；「去噪网络」和「提示词」动的则是同样一笔账能换来多少质量。下面的计算器可以改每一项：

一个实现细节：分辨率越高，噪声要越大

同一个噪声水平 \(t\)，对大图和小图的破坏程度不一样。设想一块颜色均匀的区域：像素越多，把它们平均一下，独立的噪声就抵消得越多，原来的颜色越容易被“猜出来”。所以在 1024² 上，\(t = 0.5\) 远没有把构图抹掉，模型在“从零定构图”这件事上练得太少。Stable Diffusion 3 的做法是把时间步整体往噪声一侧挪，叫分辨率相关的时间步偏移：

\[ t_m = \frac{\htmlClass{sym-al}{\alpha}\,\htmlClass{sym-tn}{t_n}}{1 + (\alpha - 1)\,t_n},\qquad \alpha = \sqrt{\htmlClass{sym-P}{P_m/P_n}} \]
在 \(P_n\) 个像素的图上，噪声水平 \(t_n\) 造成某种程度的破坏；在 \(P_m\) 个像素的图上要达到同样的破坏，需要 \(t_m\)。\(\alpha > 1\) 时 \(t_m > t_n\)：图越大，同样的难度需要更多噪声。
\(P_m/P_n\)
两种分辨率的像素数之比（这里不用 \(n\)，因为 \(n\) 在上一张卡里是序列长度）
\(\alpha\)
偏移系数。SD3 在 1024² 上训练和采样都取 \(\alpha = 3.0\)
\(t_n\)
原分辨率下的噪声水平（流匹配：\(\mathbf x_t = (1-t)\mathbf x_0 + t\boldsymbol\varepsilon\)）
从 256² 到 1024²，像素数 16 倍，\(\alpha = 4\)：\(t_n = 0.5\) 对应 \(t_m = 2/2.5 = 0.8\)。小图上“一半信号一半噪声”的难度，到大图上要加到 80% 噪声才相当。
推导：为什么偏移系数是 √(P_m/P_n)

第 1 步，一个最简单的图。设一张图所有 \(P\) 个像素都等于同一个值 \(c\)。流匹配加噪后，第 \(i\) 个像素是 \(y_i = (1-t)\,c + t\,\varepsilon_i\)，\(\varepsilon_i\) 独立、标准正态。

第 2 步，从噪声图里猜 \(c\)。最好的估计是把所有像素平均再除以 \((1-t)\)：

\[ \hat c = \frac{\bar y}{1-t} = c + \frac{t}{1-t}\cdot\frac1P\sum_{i=1}^{P}\varepsilon_i,\qquad \operatorname{std}(\hat c) = \frac{t}{1-t}\cdot\frac{1}{\sqrt P} \]

像素越多，平均掉的噪声越多，\(c\) 越容易猜准。这个标准差就是“噪声把信息破坏了多少”的度量。

第 3 步，让两种分辨率的破坏程度相等。要求 \(\frac{t_m}{1-t_m}\frac{1}{\sqrt{P_m}} = \frac{t_n}{1-t_n}\frac{1}{\sqrt{P_n}}\)，即

\[ \frac{t_m}{1-t_m} = \alpha\,\frac{t_n}{1-t_n},\qquad \alpha = \sqrt{P_m/P_n} \]

第 4 步，解出 \(t_m\)。\(t_m(1-t_n) = \alpha\,t_n(1-t_m)\)，移项得 \(t_m\big(1 - t_n + \alpha t_n\big) = \alpha t_n\)，就是卡片里的式子。换个说法：\(\frac{(1-t)^2}{t^2}\) 是单个像素的信噪比，平均 \(k\) 个像素信噪比乘 \(k\)；偏移等价于把对数信噪比整体减去 \(\ln(P_m/P_n)\)。

这个推导告诉我们：噪声水平本身没有绝对意义，要看图像在多大的尺度上还剩多少信息。真实图像相邻像素高度相关，比这个“纯色图”更容易被猜出来，所以 SD3 实际用的 \(\alpha = 3\) 是调出来的经验值，推导给的是方向和量级。FLUX 也按序列长度自动调整这个偏移。下文的图生图会再次用到“噪声水平 ↔ 尺度”这个对应关系。

潜空间的取舍：压得越狠越好吗

token 数决定成本，所以大家想压得更狠。DC-AE（2024-10）每边压 32 倍，1024² 的图只剩 32×32 的潜图，patch 取 1 也只有 1024 个 token，是 \(f = 8\)、\(p = 2\) 的四分之一。压缩的代价在两个方向上：

  • 重建的上限。VAE 丢掉的细节，扩散模型永远画不回来，小字、人脸、手指最先受损。SD3 论文里，潜空间从 4 个通道加到 16 个，VAE 重建图的 FID（下文「怎样衡量」）从 2.41 降到 1.06。
  • 可扩散性。潜空间越“丰富”，扩散模型要学的分布也越复杂。这一点长期被忽视，直到有人系统地测了一遍：

意外：VAE 重建得越好，生成反而可能越差

原以为
潜空间维度越高、重建越准，扩散模型的上限就越高。
实际发现
VA-VAE（Yao 等, CVPR 2025）在 ImageNet 256² 上固定扩散模型的训练预算做对比：提高每个潜 token 的维度，重建明显变好，生成质量却显著下降；要用大得多的模型、多得多的训练才追得回来。
为什么
高维潜空间没有约束，VAE 把什么都编码进去，结构杂乱，扩散模型要拟合的分布更难。他们在训练 VAE 时加一项损失，让潜变量对齐预训练视觉模型（DINOv2）的特征，潜空间有了语义结构，DiT（下文「去噪网络」）收敛快得多，ImageNet 256² 上的 FID 到 1.35。
现在怎么看
“可扩散性”成了设计 VAE 的第二个目标。RAE（2025-10）走得更远，直接用冻结的预训练表示编码器（DINOv2、SigLIP 等）当编码器，只训练解码器；Qwen-Image-2.0（2026-02）用 16 倍下采样、64 通道的 VAE，并加了语义对齐损失。另一些工作反其道而行，干脆回到像素空间（见演进史的支线）。

去噪网络：U-Net → DiT → MMDiT

去噪网络的输入是带噪的潜图、时间步和文本向量，输出是速度（或噪声）。它的演变沿着两条轴：骨干从卷积 U-Net 换成 Transformer，文字进来的方式从交叉注意力换成联合注意力。

先看骨干。U-Net 靠卷积，加上下采样到低分辨率之后插的几层注意力，让远处的像素互相“看见”；层级怎么分、每级多少通道、在哪几级插注意力，都是手工定的，放大时没有现成的规律可循。DiT 论文（2022-12）把潜图切成 patch 直接交给标准的 Transformer，在 ImageNet 上测出：每张图的计算量越大，FID（下文「怎样衡量」，越低越好）越低，关系相当稳定，和语言模型的扩展经验一样。之后的大型图像、视频模型都换成了 Transformer。

再看文字。原始 DiT 只按类别生成，没有文字。带文字的 DiT（如 PixArt-α, 2023-09）沿用 U-Net 的交叉注意力，读的是文本编码器给出的一份固定向量；SD3 的 MMDiT 把文字 token 和图像 token 放进同一次注意力。三代的样子：

  • U-Net（SD 1.x 约 8.6 亿参数，SDXL 约 26 亿）：卷积的编码-解码结构，中间插入自注意力层和交叉注意力层。交叉注意力里，图像特征做 query，文本向量做 key 和 value，每个位置去“查”提示词里的词。
  • DiT（Diffusion Transformer, 2022-12）：直接用 Transformer 处理 patch token，时间步和条件通过“自适应层归一化”（adaLN，下面的卡片）注入。它是 Sora 和之后大型图像、视频模型的基础。
  • MMDiT（SD3, 2024）：文本 token 和图像 token 拼成一条序列做联合注意力，两种模态各有一套权重。FLUX、Qwen-Image（200 亿参数, 2025-08）等沿用这一设计。

时间步怎样进来？同一个网络要在噪声很大（定构图）和很小（修纹理）两种情形下干不同的活，所以 DiT 让时间步 \(t\) 和整句条件 \(c\) 去调每一层：归一化之后的缩放和平移，以及残差分支的门控。DiT 论文比较过，这比把 \(t\) 当作一个额外的 token 输入效果更好。

\[ \mathbf h \leftarrow \mathbf h + \htmlClass{sym-al}{\boldsymbol\alpha(t, c)}\odot F\Big(\big(1 + \htmlClass{sym-g}{\boldsymbol\gamma(t, c)}\big)\odot\operatorname{LN}(\mathbf h) + \htmlClass{sym-be}{\boldsymbol\beta(t, c)}\Big) \]
层归一化之后的缩放、平移，以及残差分支的门控，不再是固定的可学习参数，而是由时间步 \(t\) 和条件 \(c\)（FLUX.1 里是 CLIP 的整句向量）经过一个小网络算出来。同一个网络在不同的噪声水平下，就会以不同的方式处理特征。
\(\boldsymbol\gamma\)
逐通道的缩放
\(\boldsymbol\beta\)
逐通道的平移
\(\boldsymbol\alpha\)
残差分支的门控，初始化为 0（所以叫 adaLN-Zero）：训练开始时每个块都是恒等映射，网络从“什么都不改”起步
\(F\)
这个子层本身：注意力或 MLP
FLUX.1 的一个双流块里，图像和文本两路各有注意力、MLP 两个子层，每个子层要 \(\boldsymbol\gamma, \boldsymbol\beta, \boldsymbol\alpha\) 三个 3072 维向量。把条件向量映射成这些向量的线性层，全模型合计约 32 亿参数（按公开结构估算），但它们每步只对一个条件向量算一次，不随 4096 个图像 token 增长。这是账单里 \(N_{\text{act}}\)（65 亿）比总参数（120 亿）少的一大部分；剩下约 22 亿是文本那一路的权重，图像 token 不经过它们。

最后是文字。交叉注意力和联合注意力差在哪里？设图像 token 为 \(X\)（\(n_x\) 个），文本 token 为 \(C\)（\(n_c\) 个）。联合注意力把两者拼起来，只做一次注意力：

\[ \operatorname{Attn}\big(\htmlClass{sym-Q}{[Q_c;\,Q_x]},\ \htmlClass{sym-K}{[K_c;\,K_x]},\ \htmlClass{sym-V}{[V_c;\,V_x]}\big),\qquad Q_x = X\,\htmlClass{sym-Wx}{W_Q^{\text{图}}},\quad Q_c = C\,\htmlClass{sym-Wc}{W_Q^{\text{文}}} \]
文本 token 和图像 token 排成一条序列，一起做自注意力；但查询、键、值的投影矩阵（以及后面的 MLP）按模态各用一套：图像用图像的权重，文本用文本的权重。

\([K_c; K_x]\)
两者的键，拼接后每个查询可以看到全部 \(n_c + n_x\) 个键
\([V_c; V_x]\)
两者的值
\(W^{\text{图}}\)
图像这一路的投影权重
\(W^{\text{文}}\)
文本这一路的投影权重
注意力矩阵是 \((n_c + n_x)^2\) 的方阵，分成四块：图→图（原来的自注意力）、图→文（原来的交叉注意力）、文→文、文→图（新的两块）。\(n_x = 4096\)、\(n_c = 512\) 时有 \(4608^2\approx 2120\) 万个分数，“自注意力 + 交叉注意力”是 \(4096^2 + 4096\times 512\approx 1890\) 万个，只多约 12%。

对图像 token 来说，联合注意力仍然只是“看周围的画面”加“看提示词”，没有新的信息来源；不同在于两者放进了同一个 softmax 里竞争：每个图像 token、每个头，自己决定这一步多看字还是多看图，比例由数据决定，而 U-Net 是把两者按固定权重相加（下面推导第 2、3 步）。真正的新东西在另一半：文本 token 也看得见图像，文字的表示每一层、每一步都随画面更新一次，不再是文本编码器给的固定向量。“the sign reads OPEN”这几个 token，可以在构图定下来之后“知道”招牌在哪里。代价很小，注意力分数只多约 12%。SD3 论文在同等规模下比较了几种结构，MMDiT 优于交叉注意力式的 DiT。

推导：联合注意力 = 自注意力与交叉注意力的自适应混合

第 1 步，写出一个图像 query 的输出。取一个图像 token 的查询 \(\mathbf q\)，它对文本键 \(j\in c\) 和图像键 \(j\in x\) 的分数都是 \(s_j = \mathbf q\cdot\mathbf k_j/\sqrt{d_h}\)。联合注意力在所有键上做一次 softmax：

\[ \mathbf o = \sum_{j\in c\,\cup\,x}\frac{e^{s_j}}{Z_c + Z_x}\,\mathbf v_j,\qquad Z_c = \sum_{j\in c}e^{s_j},\quad Z_x = \sum_{j\in x}e^{s_j} \]

第 2 步，按来源拆开。把求和分成文本和图像两部分，各自乘除自己的归一化常数：

\[ \mathbf o = \underbrace{\frac{Z_c}{Z_c + Z_x}}_{\alpha(\mathbf q)}\underbrace{\sum_{j\in c}\frac{e^{s_j}}{Z_c}\mathbf v_j}_{\text{只看文本：交叉注意力}} + \big(1-\alpha(\mathbf q)\big)\underbrace{\sum_{j\in x}\frac{e^{s_j}}{Z_x}\mathbf v_j}_{\text{只看图像：自注意力}} \]

第 3 步，和 U-Net 对比。U-Net 先过一层自注意力、再过一层交叉注意力，两者各自加到残差上，相当于两个输出以固定权重 1 相加。联合注意力里，混合比例 \(\alpha(\mathbf q)\) 是由分数本身算出来的：每个图像 token、每个头，自己决定这一步该多看提示词还是多看周围的画面。

第 4 步，文本那一半。文本 token 的查询同样看得到图像键，所以每一层之后，文本表示都被当前的画面更新一次；而且同一个网络在每一步都重新算一遍，文本表示也随 \(\mathbf x_t\) 和 \(t\) 变化。交叉注意力里，\(C\) 是文本编码器给出的固定向量，所有层、所有步都一样。

第 5 步，为什么两套权重。T5 的输出和 VAE 潜图的统计性质差别很大（尺度、分布、每一维的含义），各用一套投影把它们映射到同一个注意力空间，比强行共用一套更好。FLUX.1 折中：前 19 个块是两套权重的“双流块”，之后把两路拼起来，再过 38 个共用权重的“单流块”。

这个推导告诉我们：对图像 token 来说，联合注意力没有引入新的信息来源，它把“看图”和“看字”放进同一个 softmax 里竞争，比例由数据决定；真正的新东西在另一半：文本表示不再是固定的，而是在每一层、每一步跟着画面一起演化。直观上，“the sign reads OPEN”这几个 token 可以在构图定下来之后“知道”招牌在哪里。

提示词：文本编码器从 CLIP 到大语言模型

文本编码器决定模型能听懂多复杂的话。它换了三代，每一代都因为上一代卡在某类提示上：

  • CLIP（2021；SD 1.x、SDXL）。用对比学习训练，只学“这句话和这张图配不配”（第 章）。它知道画面里大致有什么，但对数量、左右位置、谁在做什么、字怎么拼都很弱，而且最多读 77 个 token。
  • T5（Imagen, 2022-05；SD3、FLUX.1）。纯语言模型的编码器，读过大量文本，句法和长描述理解好得多。Imagen 的结论是：加大冻结的文本编码器，比加大图像去噪网络更能提升画质和图文一致性。SD3 在推理时去掉 T5、只留两个 CLIP，人类评测里文字渲染的胜率降到 38%，提示遵循降到 46%，美观度不变（50%）。
  • 多模态大模型（2025 起）。Qwen-Image（2025-08）用 Qwen2.5-VL，FLUX.2（2025-11）用 240 亿参数的 Mistral Small 3.1，Qwen-Image-2.0（2026-02）用 Qwen3-VL，提示词可以长到上千个 token。大模型带来三样 T5 没有的东西：世界知识（“包豪斯风格的海报”长什么样）、多语言、能同时读图（编辑时直接把参考图也交给它）。

意外：文本编码器也会“拼不出字”

原以为
能画出逼真照片的模型，画几个字母应该不在话下。
实际发现
DALL·E 2、Stable Diffusion 1.x 生成的招牌、书名几乎全是乱码。Google 的研究（Liu 等, 2022）发现关键在文本编码器：CLIP 和 T5 用子词分词（第 章），一个词被切成一两个 token，模型根本不知道 “coffee” 由哪几个字母组成；换成按字节编码的 ByT5，拼写准确率大幅提高。这是原因之一：4 通道 VAE 会把小字糊掉，训练数据里清晰的文字也不多。
为什么
要把文字画对，模型必须知道每个字符的形状和顺序；子词 token 把这些信息藏在了一个整体编号里。这和语言模型数不清 “strawberry” 里有几个 r 是同一个问题（第 章「模型为什么数不清字母」）。
现在怎么看
2024–25 年，更多的潜空间通道、字符级或大语言模型做编码器、大量合成的文字渲染数据，让准确的中英文排版成为标配；Qwen-Image 以中文文字渲染见长，GPT-4o 与 Nano Banana Pro 能生成带准确多语言文字的海报和图表。

编码器决定模型能听懂什么，训练数据决定它学到什么。文生图模型在数亿到数十亿个图文对上训练，网上的原始配文（图片的替代文字）往往很短，也常和画面对不上，模型就学不会遵循长而具体的提示。DALL·E 3（2023-10）训练了一个专门的配文模型，给训练图重写详细描述，提示遵循明显改善，此后合成配文成了各家的标准做法。训练完还可以按奖励继续调：Flow-GRPO（2025-05）把第 章的 GRPO 用到流匹配模型上，同一提示采一组图，按检测器或偏好模型打分、组内比较，SD3.5 Medium 在 GenEval（下文「怎样衡量」）上从 63% 提到 95%。

图生图：SDEdit 与它的强度

最简单的图生图是 SDEdit（2021）：给输入图加噪到某个中间时刻，再从那里开始去噪。不需要任何额外训练，任何扩散模型都能用。

\[ \mathbf x_{\htmlClass{sym-s}{s}} = a_s\,\mathbf x_{\text{输入}} + b_s\,\boldsymbol\varepsilon\quad\longrightarrow\quad \text{从 } t = s \text{ 开始去噪到 } t = 0 \]
强度 \(s\) 决定保留多少原图：\(s\) 小时只加一点噪声，结果几乎就是原图加细节修饰；\(s\) 大时原图几乎被噪声淹没，模型按提示词自由重画，只保留大致的颜色和构图。
\(s\)
“重绘强度”，0 到 1
流匹配下 \(s = 0.3\)：\(\mathbf x_s = 0.7\,\mathbf x_{\text{输入}} + 0.3\,\boldsymbol\varepsilon\)，构图和人物都会保留，只改变画风；\(s = 0.8\)：原图只剩 20%，基本只保留色块的大致位置。各家实现里 \(s\) 的刻度不完全相同（噪声的参数化、时间步偏移都会改变它），同一个数值在不同模型里效果不同，只能对着结果调。

下面这个玩具模型可以直接试。它的“训练集”是 150 张 32×32 的小图：5 种形状 × 5 种颜色 × 白天 / 夜晚 × 3 种位置。和上一章一样，它直接算出最优去噪器，用流匹配加 CFG 采样，提示词通过关键词匹配变成条件。它不会泛化，只会在训练图之间插值（上一章的“完美去噪器只会背书”），但图生图的机制和真实模型一样。默认打开“图生图”页：草图是左上方一团红色，提示词“一张图”等于不加条件，强度 0.35。结果保住了红色和左上的位置，形状则被“吸”到最近的训练图（爱心、星星）上，因为这个玩具只认识 150 张训练图。把强度拉到 0.8，位置也不再保留，图形移到了中间，只有最粗的信息（整体是红色）还在。再把提示词换成“蓝色的星星”，看强度小时草图和提示词谁说了算。“文生图”页演示的是上一章的 CFG 和去噪预览。

强度是一个尺度截止

SDEdit 的论文把结果的好坏拆成两个指标：逼真（像不像真图）和忠实（像不像输入）。它的观察是 \(s\) 越大越逼真、越不忠实，论文在自己的噪声参数化下推荐 \(t_0\in[0.3, 0.6]\)。为什么一定此消彼长？先说“尺度”指什么：一张图可以拆成许多不同疏密的正弦花纹的叠加（傅里叶或 DCT 分解），稀疏的低频花纹描述大块的明暗，密集的高频花纹描述边缘和纹理；空间频率 \(k\) 用“每幅图里有几个周期”来计。在一个能精确求解的模型里，每个频率的答案是一个简单的式子：

\[ \htmlClass{c-new}{\lambda_k} = \frac{a_s^2\,\htmlClass{sym-tk}{\tau_k^2}}{a_s^2\,\tau_k^2 + b_s^2},\qquad \hat{\mathbf x}_k \approx \htmlClass{c-new}{\lambda_k}\,\mathbf x_{\text{输入},k} + \big(1-\htmlClass{c-new}{\lambda_k}\big)\cdot\text{按先验重新生成} \]
把图像拆成不同空间频率的成分（粗的色块是低频，细的纹理是高频）。对频率 \(k\) 的成分，\(\lambda_k\) 是结果从输入里“抄”过来的比例，剩下的部分由模型按真实图像的统计重新生成。真实图像在这个频率上越“强”（\(\tau_k\) 越大），这个成分越能扛住噪声。
\(\tau_k^2\)
真实图像在频率 \(k\) 上的典型强度（方差）。自然照片大致是 \(\tau_k^2\propto 1/k^2\)：粗结构强，细节弱
流匹配 \(s = 0.5\)：\(a = b = 0.5\)，\(\lambda = \tau^2/(\tau^2 + 1)\)。大色块 \(\tau = 3\)：\(\lambda = 0.9\)，几乎原样保留；细纹理 \(\tau = 0.3\)：\(\lambda = 0.08\)，几乎全部重画。
推导：SDEdit 的强度权衡，在高斯先验下的精确解

第 0 步，为什么可以一个频率一个频率地算。自然图像的统计近似平移不变（一块纹理挪个位置，统计不变），这类高斯先验的协方差在傅里叶（或 DCT）基下是对角的：每个空间频率分量是一个独立的一维问题，方差随频率升高而下降（大致 \(\propto 1/k^2\)）。所以下面第 1–6 步对一个分量成立，对整张图就是对每个频率各成立一次。

第 1 步，设定。先看一个维度（一个频率分量）。设真实图像在这一维上服从 \(\mathcal N(\mu, \tau^2)\)，输入图在这一维上的值是 \(x_{\text{in}}\)。加噪得到 \(x_s = a\,x_{\text{in}} + b\,\varepsilon\)。理想的反向随机采样（DDPM 式）从 \(x_s\) 出发，得到的正是后验 \(p(x_0\mid x_s)\) 的一个样本：反向 SDE 是前向马尔可夫链的时间反演，从任意 \(x_s\) 出发，它的转移恰好是 \(p(x_0\mid x_s)\)。第 章讲的是另一面：确定性的概率流 ODE 与反向 SDE 的边缘分布相同；但从固定的 \(x_s\) 出发，ODE 只会走到一个确定的点，不是后验样本。所以下面的分析针对随机采样器。（在这个高斯模型里可以验证，ODE 版本对输入的保留系数是下面 \(\lambda\) 的平方根，随 \(s\) 的走向相同，过渡更缓。）

第 2 步，算后验。先验 \(\mathcal N(\mu, \tau^2)\) 乘似然 \(\mathcal N(x_s;\ a x_0,\ b^2)\)，两个高斯相乘还是高斯。精度相加 \(1/\tau^2 + a^2/b^2\)，均值按精度加权：

\[ x_0\mid x_s\ \sim\ \mathcal N\Big(\lambda\,\frac{x_s}{a} + (1-\lambda)\,\mu,\ \ (1-\lambda)\,\tau^2\Big),\qquad \lambda = \frac{a^2\tau^2}{a^2\tau^2 + b^2} \]

第 3 步，代回输入。\(x_s/a = x_{\text{in}} + (b/a)\varepsilon\)，所以结果是

\[ \hat x = \lambda\,x_{\text{in}} + (1-\lambda)\,\mu + \lambda\frac{b}{a}\varepsilon + \sqrt{1-\lambda}\;\tau\,\xi,\qquad \xi\sim\mathcal N(0, 1) \]

均值是输入与先验均值之间的插值，\(\lambda\) 就是插值系数。

第 4 步，忠实度。结果离输入有多远（\(d\) 维各自独立时相加）。利用 \(\lambda b^2/a^2 = (1-\lambda)\tau^2\)，两个噪声项的方差合起来是 \(\lambda(1-\lambda)\tau^2 + (1-\lambda)\tau^2 = (1-\lambda^2)\tau^2\)：

\[ \mathbb E\,\|\hat{\mathbf x} - \mathbf x_{\text{in}}\|^2 = (1-\lambda)^2\,\|\mathbf x_{\text{in}} - \boldsymbol\mu\|^2 + d\,(1-\lambda^2)\,\tau^2 \]

\(\lambda\) 越小（\(s\) 越大），离输入越远。

第 5 步，逼真度。用“离真实分布中心多少个标准差”衡量，真实样本的期望值恰好是 \(d\)：

\[ \mathbb E\,\frac{\|\hat{\mathbf x} - \boldsymbol\mu\|^2}{\tau^2} = d + \lambda^2\Big(\frac{\|\mathbf x_{\text{in}} - \boldsymbol\mu\|^2}{\tau^2} - d\Big) \]

输入越不典型，括号越大；多出来的部分按 \(\lambda^2\) 衰减，\(\lambda\to 0\) 时结果和真实样本无法区分。

第 6 步，同一个旋钮。两个指标都只依赖 \(\lambda\)，而 \(\lambda\) 随 \(s\) 单调下降。流匹配、\(\tau = 1\) 时 \(\lambda = (1-s)^2/\big((1-s)^2 + s^2\big)\)：\(s = 0.3\) 得 0.84，\(s = 0.5\) 得 0.5，\(s = 0.7\) 得 0.16。

第 7 步，放回图像。按第 0 步，图像是许多频率分量的叠加，每个频率有自己的 \(\tau_k\)。\(\tau_k \gg b/a\) 的成分 \(\lambda_k\approx 1\)，照抄输入；\(\tau_k \ll b/a\) 的成分 \(\lambda_k\approx 0\)，重新生成。\(\tau_k = b/a\) 的那个频率 \(k_c\) 就是截止，\(s\) 增大，\(b/a\) 增大，截止向更低的频率移动。截止是软的：代入 \(\tau_k^2\propto 1/k^2\) 得 \(\lambda_k = 1/\big(1 + (k/k_c)^2\big)\)，\(k = k_c/3\) 时 \(\lambda = 0.9\)，\(k = 3k_c\) 时 \(\lambda = 0.1\)，从基本保留到基本重画要跨 9 倍的频率。

这个推导告诉我们：强度 \(s\) 不是“改多少”的模糊旋钮，而是一个软的尺度截止：比截止粗得多的结构基本归输入，细得多的基本归模型，截止附近约一个数量级的频率范围是渐变的。忠实和逼真由同一个 \(\lambda\) 控制，所以不存在两者同时最好的 \(s\)；选 \(s\) 就是选“哪些尺度归草图”。实际模型不是高斯，逼真度也不只看尺度，但这个结构（低频保留、高频重画）在真实图生图里清楚可见：小强度只改质感，中强度改形状细节，大强度只剩色块布局。

推导的结论：强度 \(s\) 是一个软的尺度截止，比截止粗得多的结构基本从输入抄过来，细得多的基本按模型的先验重画；忠实和逼真由同一个保留比例 \(\lambda\) 控制，所以不存在两者同时最好的 \(s\)，选 \(s\) 就是选“哪些尺度归草图”。

下面的玩具把这个推导直接算出来。“真实图像”是功率谱 \(\propto 1/k^2\) 的随机灰度纹理，这是自然照片的典型统计；它看起来不像照片，只用来保证每个频率的统计和自然图像一致，看点是哪些频率被抄、哪些被重画。在这个先验下每个频率成分的后验都是精确的高斯，结果就是理想去噪器的输出。右图纵轴“不像真图”是一个简化的口径：把频率分成五个倍频带，比较每个带的功率和真实图像差几倍（取以 2 为底的对数的绝对值，再平均）。默认 \(s = 0.35\) 时截止约在每幅图 11.7 个周期，2 个周期的大色块保留 0.96，16 个周期的笔画只保留 0.35。拖动强度，看截止频率怎样移动、三个结果怎样变化：

SDEdit 只有一个旋钮 \(s\)，上面的分析说明了它为什么不够用：\(s\) 把图像按空间尺度切成两半，比截止粗的基本归草图，比截止细的基本归模型。想保住人物的轮廓、又彻底换掉画风，两个要求落在同一个尺度上，调 \(s\) 无解。下一节的几种技术都是在绕开这一刀：局部重绘手动划出“哪块归输入”，ControlNet 和 IP-Adapter 把结构和参考图从旁路送进网络，上下文内编辑干脆把参考图放进序列、从纯噪声起步，不再靠“加噪再去噪”去保留原图。

控制与编辑：绕开尺度截止

只改一部分用局部重绘（inpainting）：画一个掩码，只重新生成掩码内部。最简单的做法不需要训练，每一步都把掩码外的区域换回原图：

\[ \mathbf x_t \leftarrow \htmlClass{sym-m}{\mathbf m}\odot\mathbf x_t + (1-\htmlClass{sym-m}{\mathbf m})\odot\big(a_t\,\mathbf x_{\text{原图}} + b_t\,\boldsymbol\varepsilon\big) \]
每一步去噪之后，掩码外的部分被替换成“原图加噪到当前水平”的版本，掩码内的部分保留模型生成的结果。这样模型每一步都能看到周围真实的内容，生成的部分会去配合它。
\(\mathbf m\)
掩码：要重画的位置为 1，要保留的位置为 0；\(\odot\) 是逐元素相乘
把照片里的一只杯子换成一盆花：掩码盖住杯子。早期（\(t\) 大）掩码内是噪声，周围是加了重噪声的原图，模型先定下“这里放什么、多大”；后期周围几乎是清晰的原图，模型把边缘、光照和它对齐。缺点是生成部分只能“被动适应”，接缝处常不一致。专门的重绘模型把掩码和被遮住的原图也作为输入通道（SD 的重绘版输入 9 个通道：4 + 4 + 1），在训练里学会补全。

更精细的控制来自额外的输入。ControlNet（2023-02）复制一份去噪网络的编码器，接收边缘图、深度图、人体姿态等控制信号，通过“零初始化”的连接注入主网络：

\[ \mathbf y = F(\mathbf x) + \htmlClass{c-new}{Z}\Big(F_{\text{副本}}\big(\mathbf x + \htmlClass{c-new}{Z}(\mathbf c)\big)\Big),\qquad Z\ \text{初始化为全零} \]
\(F\) 是冻结的原网络，\(F_{\text{副本}}\) 是它的一份可训练副本，接收控制信号 \(\mathbf c\)。两者之间用权重初始化为 0 的卷积 \(Z\) 连接，所以训练刚开始时 \(\mathbf y = F(\mathbf x)\)，模型的行为与原来完全一样，不会被一开始的随机噪声破坏。
用几万张“人体姿态骨架 → 照片”的配对训练，副本逐渐学会把姿态信息翻译成主网络能用的特征。因为原网络冻结，它生成高质量图像的能力完全保留；不同的 ControlNet（边缘、深度、姿态）可以叠加使用。

参考图也可以当条件。IP-Adapter（2023-08）给交叉注意力加一组只读参考图特征的 key / value，只训练约 2200 万参数。2025 年以后的主流是上下文内编辑：把参考图编码成 token，和要生成的目标图 token 拼进同一条序列，靠联合注意力直接“看着”参考图画新图，位置编码里多出一维，用来区分哪些 token 属于参考图（FLUX.1 Kontext, 2025-05）。它从纯噪声起步，原图的信息不是靠“加噪后的残留”传进来，而是每一层都能完整地查到，所以不必用一个强度在“保结构”和“改风格”之间取舍；代价是要专门训练，序列也变长。Qwen-Image-Edit（2025-08）还把输入图同时送进 Qwen2.5-VL，让大模型理解“要改什么”。

个性化：几张照片教会模型一个新概念

想让模型画出“你家的那只狗”，提示词写不出来：它的毛色花纹、脸型是语言描述不了的。Textual Inversion（2022-08）只给新概念学一个词向量，模型本身不动，表达力有限。DreamBooth（2022-08）直接微调整个去噪网络：用 3–5 张照片，提示词写成“a [V] dog”，[V] 是一个稀有 token 当作标识符。它要同时防两件事，一是模型背下这几张照片，二是“狗”这个词整体被带偏，所以加了先验保持损失：

\[ \mathcal L = \underbrace{\big\|\hat{\mathbf x}_\theta(\mathbf x_t,\ \htmlClass{sym-cv}{c_{[V]}}) - \mathbf x\big\|^2}_{\text{学会这只狗}} + \htmlClass{sym-lam}{\lambda_{\text{pr}}}\,\underbrace{\big\|\hat{\mathbf x}_\theta(\mathbf x'_{t'},\ \htmlClass{sym-cc}{c_{\text{dog}}}) - \htmlClass{sym-xp}{\mathbf x'}\big\|^2}_{\text{别忘了一般的狗}} \]
第一项是普通的去噪损失，训练图是你的几张照片，提示词带标识符；第二项用微调前的模型自己生成的“a dog”图片，提示词只有类别名，要求模型在一般的狗上保持原来的输出。

后来社区更常用的是把同样的训练换成 LoRA（第 章）：只训练注意力投影上的低秩增量。一个 \(3072\times 3072\) 的投影，秩 16 的 LoRA 只有 \(2\times 3072\times 16\approx 9.8\) 万个参数，是原矩阵的 1%。一个人物、一种画风就是一个小文件，可以叠加使用。

几张图就够，是因为模型本来就会画狗，只需要在它的分布里指定一个个体。难的是别学过头：“a [V] dog”和“a dog”的编码很接近，更新会把所有的狗都带偏（语言漂移，下面推导第 3 步）；训练久了又会背下这几张照片的姿势和背景。稀有标识符、先验保持、低秩、早停，都是在限制更新的方向或幅度。

推导：为什么几张图就够，为什么会“串味”和背图

第 1 步，几张图就够，因为要学的东西很少。模型已经会画“狗”：各种姿势、光照、场景都在它的分布里。新概念只需要在这个分布里“指定一个个体”，对应毛色、脸型等少量信息。微调要做的是一个小改动，而不是学一个新分布。

第 2 步，看一个读文本的线性层。下面是一个线性玩具（单个线性层、一步梯度），只用来说明方向，不是定理。交叉注意力（或联合注意力）里，文本向量 \(\mathbf c\) 经过投影 \(\mathbf k = W\mathbf c\)。对提示词 \(\mathbf c_{[V]}\) 的一个训练样本，损失对 \(W\) 的梯度是外积 \(\mathbf g\,\mathbf c_{[V]}^\top\)（\(\mathbf g\) 是损失对 \(\mathbf k\) 的梯度）。走一步：

\[ \Delta W = -\eta\,\mathbf g\,\mathbf c_{[V]}^\top \]

第 3 步，“狗”被带偏多少。对普通提示词 \(\mathbf c_{\text{dog}}\)，键的变化是

\[ \Delta W\,\mathbf c_{\text{dog}} = -\eta\,\mathbf g\,\big(\mathbf c_{[V]}^\top\mathbf c_{\text{dog}}\big) \]

它正比于两个提示词编码的内积。“a [V] dog”和“a dog”只差一个 token，编码后非常相似，内积很大，于是所有的狗都开始长得像你的狗。DreamBooth 论文把这叫语言漂移（language drift）。

第 4 步，先验保持在做什么。第二项的梯度是 \(-\eta\lambda_{\text{pr}}\,\mathbf g'\,\mathbf c_{\text{dog}}^\top\)，专门把 \(\Delta W\mathbf c_{\text{dog}}\) 往 0 拉。它是软惩罚，不是硬约束，所以更新只是倾向于满足 \(\Delta W\mathbf c_{\text{dog}}\approx 0\)，主要利用 \(\mathbf c_{[V]}\) 中与 \(\mathbf c_{\text{dog}}\) 正交的那部分：

\[ \mathbf c_\perp = \mathbf c_{[V]} - \big(\mathbf c_{[V]}^\top\hat{\mathbf c}_{\text{dog}}\big)\,\hat{\mathbf c}_{\text{dog}} \]

在这个玩具里，这部分来自标识符 [V]；真实的文本编码器里，各个词的表示不能这样干净地拆开。选稀有 token 是经验做法：它本来几乎不带含义，把新概念绑在它上面，对其它词的扰动较小。

第 5 步，背图。只有 \(n = 4\) 张图、提示词固定为 \(\mathbf c_{[V]}\) 时，去噪损失的最优解是对这 4 张图的后验均值（第 章「完美的去噪器只会背书」）。训练得足够久，模型就只会复现这 4 张照片的姿势和背景，论文称之为“吸附到少数几个视角”。实用的办法都是在限制它走到这个最优解：少训练几步、学习率小、LoRA 的秩低（限制 \(W\) 能变动的方向）、加先验保持。

这个推导告诉我们：个性化的困难不是“学不会”，而是“学得太多”：数据只有几张，能拟合的东西远多于该学的东西。稀有标识符、先验保持、低秩、早停，都是在限制更新的方向或幅度。这和第 章 LoRA “学得少，也忘得少”是同一件事。

少步生成：从几十步到一两步

账单里步数 \(K\) 和 CFG 的 \(g\) 是乘在最外面的。第 章解释了为什么直接减少步数会模糊（第一步只能给出所有可能图像的平均）。图像产品走到 1–4 步，靠的是几种蒸馏，每种的核心想法都不同：

  • 一致性模型（Song 等, 2023-03）与 LCM（2023-10）：第 章的概率流 ODE 是确定性的，从同一条轨迹上任何一点出发都走到同一个终点。一致性模型直接学这个映射 \(f_\theta(\mathbf x_t, t)\approx\mathbf x_0\)，训练目标叫自一致性：同一条轨迹上相邻两点的输出应该相同，\(f_\theta(\mathbf x_{t_{n+1}}, t_{n+1}) = f_{\theta^-}(\hat{\mathbf x}_{t_n}, t_n)\)。这里 \(\hat{\mathbf x}_{t_n}\) 是老师的 ODE 求解器从 \(\mathbf x_{t_{n+1}}\) 往回走一小步得到的点，\(\theta^-\) 是参数的滑动平均（一个变化较慢的目标网络）；再加一个边界条件：\(t\) 接近 0 时 \(f\) 原样输出输入。相邻两点处处一致、一端被钉住，整条轨迹就都映射到同一个终点，于是一步就能出图；多走几步（映射到终点、再加噪、再映射）可以提高质量。LCM 把它搬到潜空间，并把 CFG 一起蒸馏进去，2–4 步出图；LCM-LoRA 把它做成了可以挂在任何 SD 模型上的小插件。
  • 引导蒸馏（Meng 等, 2022）：学生网络把引导强度 \(w\) 当作一个输入，一遍前向就复现老师“有条件 + 无条件、按 \(w\) 外推”的结果，\(g\) 从 2 变成 1。FLUX.1 [dev] 用的就是它。
  • 对抗蒸馏：学生一步或几步生成，由判别器判断“像不像真图”，像 GAN 一样训练。ADD（SDXL Turbo, 2023-11）的判别器建在冻结的 DINOv2 特征上，要先解码成像素，又贵又只能到 512²；LADD（SD3 Turbo, 2024-03）改用老师自己的潜空间特征，高分辨率也能训。FLUX.1 [schnell]（1–4 步）和 FLUX.1 Kontext [pro] 用 LADD（Kontext [dev] 用的是引导蒸馏）。
  • 分布匹配蒸馏（DMD, 2023-11；DMD2, 2024-05）：不要求学生复现老师的每条轨迹，只要求学生生成的整体分布和老师一样。它的梯度有一个很干净的形式：
\[ \nabla_\theta D_{\text{KL}}\big(p_{\text{假}}\,\|\,p_{\text{真}}\big) = \mathbb E_{\mathbf z}\Big[\big(\htmlClass{sym-sf}{\mathbf s_{\text{假}}(\mathbf x)} - \htmlClass{sym-sr}{\mathbf s_{\text{真}}(\mathbf x)}\big)^{\!\top}\,\frac{\partial \mathbf x}{\partial\theta}\Big],\qquad \mathbf x = \htmlClass{sym-G}{G_\theta}(\mathbf z) \]
一步生成器 \(G\) 把噪声 \(\mathbf z\) 直接变成图 \(\mathbf x\)。要让它的输出分布接近真实分布，只需要在 \(\mathbf x\) 处比较两个分数（对数密度的梯度）：真实分布的，和生成器当前分布的。两者之差就是该把 \(\mathbf x\) 往哪里推。
\(\mathbf s_{\text{真}}\)
真实分布的分数，由原来的多步扩散模型（老师，带 CFG）给出
\(\mathbf s_{\text{假}}\)
生成器当前输出分布的分数，由另一个扩散模型一边训练一边拟合生成器的输出
\(G_\theta\)
一步生成器，通常用老师的权重初始化
某处生成器的样本太多（假分布的密度高于真分布），\(\mathbf s_{\text{假}}\) 指向那里而 \(\mathbf s_{\text{真}}\) 不指向，\(-(\mathbf s_{\text{假}} - \mathbf s_{\text{真}})\) 把样本推开；样本太少的地方反过来，把样本拉进来。两个分数处处相等时梯度为 0，分布对齐了。实际计算在加噪后的 \(\mathbf x_t\) 上进行，各个噪声水平都比一次。
推导：DMD 的梯度为什么是两个分数之差

第 1 步，写出目标。生成器 \(\mathbf x = G_\theta(\mathbf z)\)，\(\mathbf z\sim\mathcal N(0, I)\)，输出分布记为 \(p_\theta\)。反向 KL：

\[ D_{\text{KL}}(p_\theta\,\|\,p_{\text{真}}) = \mathbb E_{\mathbf z}\Big[\log p_\theta\big(G_\theta(\mathbf z)\big) - \log p_{\text{真}}\big(G_\theta(\mathbf z)\big)\Big] \]

第 2 步，对 \(\theta\) 求导。\(\theta\) 出现在两个地方：样本位置 \(\mathbf x = G_\theta(\mathbf z)\)，以及密度 \(p_\theta\) 本身。用链式法则：

\[ \nabla_\theta D_{\text{KL}} = \mathbb E_{\mathbf z}\Big[\big(\nabla_{\mathbf x}\log p_\theta(\mathbf x) - \nabla_{\mathbf x}\log p_{\text{真}}(\mathbf x)\big)^{\!\top}\frac{\partial\mathbf x}{\partial\theta}\Big] + \mathbb E_{\mathbf x\sim p_\theta}\big[\nabla_\theta\log p_\theta(\mathbf x)\big] \]

第 3 步，第二项为 0。\(\mathbb E_{p_\theta}[\nabla_\theta\log p_\theta] = \int\nabla_\theta p_\theta = \nabla_\theta\int p_\theta = \nabla_\theta 1 = 0\)，和第 章基线不改变梯度期望用的是同一个恒等式。剩下的就是卡片里的式子。

第 4 步，两个分数从哪来。\(\mathbf s_{\text{真}}\) 由老师的去噪器给出（第 章：去噪器等价于分数）。\(\mathbf s_{\text{假}}\) 没有现成的模型，就再训一个扩散模型，专门在生成器最新的输出上做去噪训练，和生成器交替更新。干净图像的分布集中在很薄的一层上，两个分布的支撑几乎不重叠，分数不可靠，所以两个分数都在加噪后的 \(\mathbf x_t\) 上计算，相当于比较两个被“抹平”的分布。

第 5 步，代价。反向 KL 在 \(p_\theta\) 为 0 的地方不惩罚，所以它偏爱“只覆盖真实分布的一部分模式、但每个都画得像”。DMD 因此多样性比老师差，第一版加了一个回归损失（用老师预先生成的噪声–图像对），DMD2 去掉回归损失、改加 GAN 损失，在 SDXL 上做到一步和四步生成。

这个推导告诉我们：DMD 把“教一步生成器”变成了两个扩散模型之间的比较：老师说“真图往哪个方向更密”，另一个模型说“你现在的图往哪个方向更密”，学生沿着差值走。它不需要复现老师的轨迹，所以能一步到位；代价是反向 KL 的模式偏好，这也是对抗损失在各种蒸馏方法里反复回来的原因。

DMD 不需要复现老师的轨迹，所以能一步到位；代价来自反向 KL 的模式偏好：它偏爱只覆盖真实分布的一部分、但每张都画得像，多样性比老师差，DMD2 因此加了 GAN 损失。这也是对抗损失在各种蒸馏方法里反复回来的原因。

2026 年的商用图像模型普遍有 4–8 步的快速版本；开放权重一侧，FLUX.2 [klein]（2026-01）把参数压到 40 亿和 90 亿，FLUX 3 Image Klein（2026-10）56 亿参数，步数蒸馏版跑 16 步。

怎样衡量“画得好”

一个文生图模型至少要回答三个问题：画得像不像真图（逼真度），够不够多样（多样性），听不听提示词（贴合度）。常见的度量各管一部分：

  • FID（Fréchet Inception Distance, 2017）：比较生成图与真实图在特征空间里的分布，同时反映逼真度和多样性。下面讲它测的是什么、看不见什么。
  • CLIP score：生成图与提示词在 CLIP 空间里的余弦相似度，衡量贴合度。它继承了 CLIP 的弱点：数不清个数、分不清左右。
  • GenEval（2023）等针对性基准：用目标检测器检查“三只猫”是不是三只、“红色的杯子在左边”对不对。文字渲染、编辑也各有专门的基准。
  • 人类偏好竞技场：让人在两张匿名生成图里选更好的，汇总成 Elo 分（第 章）。2025 年以后前沿模型的排名主要看这类榜单。
\[ \text{FID} = \big\|\htmlClass{sym-mr}{\boldsymbol\mu_r} - \htmlClass{sym-mg}{\boldsymbol\mu_g}\big\|^2 + \operatorname{Tr}\Big(\htmlClass{sym-Sr}{\Sigma_r} + \htmlClass{sym-Sg}{\Sigma_g} - 2\big(\Sigma_r^{1/2}\,\Sigma_g\,\Sigma_r^{1/2}\big)^{1/2}\Big) \]
把真实图像和生成图像都送进同一个图像分类网络（Inception-v3），取倒数第二层的 2048 维特征。两边各算出均值和协方差，当作两个高斯；FID 就是这两个高斯之间的距离：第一项比中心差多远，第二项比各个方向上的散布差多少。
\(\boldsymbol\mu_r\)
真实图像特征的均值
\(\boldsymbol\mu_g\)
生成图像特征的均值
\(\Sigma_r\)
真实图像特征的协方差矩阵（2048×2048）
\(\Sigma_g\)
生成图像特征的协方差矩阵
一维时退化成 \((\mu_r - \mu_g)^2 + (\sigma_r - \sigma_g)^2\)。真实特征 \(\mu = 0,\ \sigma = 1\)，生成的 \(\mu = 0.3,\ \sigma = 0.8\)：FID \(= 0.09 + 0.04 = 0.13\)。论文里通常用 5 万张生成图来算。
第 1 步：中心差多远。所有生成图整体偏了（比如偏色），这一项就变大。
第 2 步：两边散布的总量。迹是各方向方差之和。如果两堆特征毫不相关，平方距离的期望就是这两项相加。
第 3 步：减去最好的配对能省下的部分。把两堆点一一配对、让配对的点尽量近，能省下的平方距离最多是这一项。形状完全一样时它正好抵消前一项。
推导：FID 是什么距离，以及它看不见什么

第 1 步，两个高斯之间的搬运距离。把一堆沙子（分布 \(P\)）搬成另一堆（分布 \(Q\)），每粒沙子的代价是搬运距离的平方，最小总代价就是 Wasserstein-2 距离的平方 \(W_2^2\)：在所有“配对方式”里取 \(\mathbb E\|X - Y\|^2\) 的最小值。两边都是高斯时，最优配对是一个线性映射，最小值恰好是卡片里的式子（Dowson 与 Landau, 1982）。一维时最优配对就是按分位数对齐，\(Y = \mu_2 + \frac{\sigma_2}{\sigma_1}(X - \mu_1)\)，得到 \((\mu_1 - \mu_2)^2 + (\sigma_1 - \sigma_2)^2\)，即卡片里一维的例子。卡片第 3 步减去的那一项，就是最优配对能省下的平方距离。

第 2 步，它其实是一个下界。上面只用到了均值和协方差。对任意两个分布（不必是高斯），只要前两阶矩是这些值，\(W_2^2\) 都不小于这个式子，两者都是高斯时取等号（Gelbrich 界）。所以 FID 的准确含义是：“只看前两阶矩时，两堆特征至少差多远”。两个形状完全不同、但均值和协方差相同的分布，FID 为 0，下面演示的默认选项就是这种情况。

第 3 步，有限样本的偏差。均值用 \(M\) 个样本估计，每一维有 \(\sigma^2/M\) 的抽样方差，两边都估计时

\[ \mathbb E\,\|\hat{\boldsymbol\mu}_r - \hat{\boldsymbol\mu}_g\|^2 = \|\boldsymbol\mu_r - \boldsymbol\mu_g\|^2 + \frac{\operatorname{Tr}\Sigma_r + \operatorname{Tr}\Sigma_g}{M} \]

协方差项同样有正的偏差。即使两个分布完全相同，算出的 FID 也大于 0，大约按 \(1/M\) 下降；2048 维的协方差矩阵有 200 多万个元素，所以需要 5 万张图。Chong 与 Forsyth（2020）进一步指出，这个 \(1/M\) 项的系数因生成器而异，不同样本数下比较，模型的排名可能颠倒。

这个推导告诉我们：FID 是二阶矩意义下的搬运距离，它看不见更高阶的差别，也分不清“不够像”和“不够多样”，它的值还依赖样本数和用哪个网络提特征。它适合在同一套设置下比较同类模型，不适合当作“图好不好看”的绝对刻度。

FID 只看两堆特征的均值和协方差，所以它是一个下界：更高阶的差别它看不见，值还随样本数和提特征的网络变。下面的玩具用二维特征把这几点演示一遍。默认选项就是这样的反例：生成分布和真实分布长得完全不同，FID 却是 0；拖动样本数，看同一对分布的 FID 怎样随样本数下降。

FID 还该不该当主指标

支持
简单、可复现、和过去十年的 GAN 与扩散论文可比。在 ImageNet 类条件生成这类设定固定的任务上，它仍是主要指标（2025 年最好的模型在 256² 上已到 1.1–1.4）。
反对
Stein 等（NeurIPS 2023）的人类评测发现，Inception 特征与人的判断相关性差，建议换成 DINOv2 特征。Kynkäänniemi 等（ICLR 2023）发现，只调整生成图里各个 ImageNet 类别的比例、画质不变，FID 就能明显下降。Jayasumana 等（CVPR 2024）改用 CLIP 特征和 MMD 距离（CMMD；最大均值差异，比较两组样本在核特征空间里的均值，不需要假设分布形状）。
现在怎么看
前沿文生图模型发布时几乎不再拿 FID 当卖点，改用人类偏好竞技场加针对性的基准；FID 退回到研究里做消融比较。竞技场也有自己的问题：投票人群、提示词分布、风格偏好都会影响排名（第 章）。

自回归与统一模型：图像也能逐个 token 生成吗

扩散之外，另一条路线是把图像也变成 token，像语言模型那样逐个预测（自回归）。先用本章的账单比一比。同样生成一张图，扩散把全部潜 token 一起去噪：1024² 的例子里是 4096 个 token、28 步。DALL·E（2021）先用一个离散 VAE 把 256² 的图压成 32×32 = 1024 个 token，每个 token 是一本 8192 个码字的码本里的一个编号（这种“换成码本里最近的码字”叫向量量化，细节在这一步丢掉一部分），然后一个一个预测，要 1024 次前向。VAR（2024-04，NeurIPS 2024 最佳论文）把“下一个 token”换成“下一个尺度”：先预测 1×1 的 token 图，再 2×2、3×3……直到 16×16，256² 上共 10 个尺度、680 个 token，每个尺度内部并行，前向只要 10 次。

离散 token 会丢细节，扩散又不是逐个生成。2024 年的几种折中，区别在两个问题上：图像 token 是离散的还是连续的，一张图是逐个生成还是整张一起生成：

  • 纯离散 token（Chameleon, 2024-05；Janus 的生成端）：图像先量化成码本编号，和文字 token 排在一条序列里，用同一个交叉熵损失逐个预测。最简单，理解和生成共用一切；代价是量化损失和逐个生成的串行步数。
  • MAR（2024-06）：仍然一个（或一批）位置一个位置地生成，生成顺序和语义由 Transformer 决定，但 token 保持连续值：Transformer 为每个待生成的位置输出一个条件向量，再由一个很小的 MLP 扩散头，以它为条件去噪，采出这个 token 的连续值。不用码本，也就没有量化损失。
  • Transfusion（2024-08）：同一个 Transformer 对文字做下一 token 预测，对整张图的连续潜 patch 做扩散去噪；一张图内部的 token 互相双向注意，整张图一起去噪若干步，不逐个生成。论文报告，它比“把图量化成离散 token 再训语言模型”扩展得更好。HunyuanImage 3.0（2025-09，800 亿参数的 MoE，每个 token 激活 130 亿）就是按 Transfusion 的方式把扩散放进语言模型的。

第 章的多模态模型只“看”图：图像经视觉编码器变成连续向量，接在文字前面。把“画”也放进同一个模型，就是理解与生成统一。难点在于两件事要的图像表示不一样：理解要语义（这是一只猫、在桌子左边），生成要能还原像素细节。Janus（2024-10）的出发点就是：同一个视觉编码器同时服务两种需求会互相拖累，所以它把两端拆开，理解用 SigLIP 编码器，生成用离散码本，中间共享一个语言模型。BAGEL（2025-05）在一个模型里放两组专家权重：理解专家读视觉编码器的特征，生成专家用流匹配在 VAE 潜空间里去噪，两组在同一条序列上做注意力，和 MMDiT“按模态各用一套权重”是同一个思路。Qwen-Image-2.0（2026-02）走松耦合：冻结的 Qwen3-VL 负责理解提示词和参考图，一个独立的 MMDiT（据报道约 70 亿参数）负责生成和编辑。

图像该用扩散生成，还是自回归生成

扩散派
扩散一次修正整张图，每一步都能看到全局，高分辨率下细节更稳；视频生成几乎全是扩散（第 章）；开放权重的强模型（FLUX 系列、Qwen-Image 系列）都是扩散或流匹配。
自回归派
自回归和语言模型共用一套训练与推理设施（KV 缓存、批处理、强化学习），把理解和生成放进同一个模型最自然。GPT-4o 的图像生成（2025-03）按 OpenAI 系统卡的说法是“原生嵌入 ChatGPT 的自回归模型”，在提示遵循、文字渲染、多轮编辑上明显领先；VAR 把前向次数降到十次左右。
现在怎么看
边界在消失。公开了结构的统一模型（Transfusion、BAGEL、HunyuanImage 3.0）多数是在语言模型里做扩散：序列层面（先画什么、图和字怎样交错）用自回归，单张图内部用扩散或流匹配。纯离散 token 的路线目前主要靠闭源系统支撑，而 GPT Image 2 之后 OpenAI 没有公开用的是哪一种。

2026 年的头部产品：闭源一侧有 GPT Image 2 / 2.5、Nano Banana 系列和 Seedream 5.0，开放权重一侧有 FLUX 3 Image Klein、FLUX.2、Qwen-Image-2.1 和 HunyuanImage 3.0。各自的发布时间见演进史的最后一个节点。

水印与版权

水印能可靠地识别 AI 生成的图像吗

支持
Google 的 SynthID 在生成时就把不可见的水印嵌入像素，经过压缩、裁剪、调色仍能检测；C2PA 内容凭证在文件中记录来源与编辑历史，主要相机厂商和平台已支持。欧盟《人工智能法》第 50 条要求对 AI 生成内容做可机读的标注。
反对
研究表明，不可见水印可以被“再生成”攻击去除：给图像加噪再用扩散模型去噪，水印随之消失而画面几乎不变（Zhao 等, 2023 证明了这类攻击对一大类水印普遍有效）。用 SDEdit 推导的语言说：水印是幅度很小、不属于“真实图像统计”的扰动，加噪后被淹没，去噪时按模型的先验重画，扰动就没了。元数据可以直接删掉；开源模型的生成结果没有任何水印。检测“这张图是不是 AI 生成”的分类器同样不可靠。
现在怎么看
水印能为“诚实的”平台提供来源信息，但无法阻止有意的伪造。社会层面更现实的方向是反过来：为真实拍摄的照片提供可信的来源证明（相机签名、C2PA），而不是试图标出所有假图。

用艺术家的作品训练图像模型，合法吗

权利方
训练集里有大量受版权保护的作品；模型能模仿在世艺术家的画风，和他们直接竞争。
模型方
模型学到的是统计规律而不是作品本身，画风也不受版权保护。
现在怎么看
图像侧最受关注的是 Getty Images 诉 Stability AI：英国高等法院 2025 年 11 月驳回了 Getty 的大部分主张（模型本身不是侵权复制品），只在商标问题上部分支持；美国的同名案据报道在 2026 年 4 月的裁定后继续审理。关键事实是模型能否逐字复现训练图像（上一章的记忆问题）。各国的分歧和数据授权的全貌见第 、 章。

常见误解

  • 扩散模型直接在像素上去噪。2022 年以后几乎所有实用模型都在 VAE 的潜空间里去噪，最后一步才解码成像素；VAE 的质量直接决定细节和文字的上限。像素空间在研究里有回归的迹象（JiT, 2025），但还不是产品主流。
  • 图生图就是“照着画”，强度只是“改多少”。强度是一个软的尺度截止：比截止粗得多的结构基本保留，细得多的基本重画。要精确保住轮廓又大改风格，靠调强度做不到，需要 ControlNet 或上下文内编辑。
  • 自回归的原生多模态模型已经取代了扩散。公开了结构的统一模型（Transfusion、BAGEL、HunyuanImage 3.0）大多是在语言模型里做扩散；开放权重的主力（FLUX、Qwen-Image）仍是扩散或流匹配。只有闭源的 GPT-4o 明确自称自回归。

演进史

2014–2020

GAN：一步生成照片级图像，但只在窄领域

卡在哪
VAE 生成的图模糊；逐像素的自回归模型（PixelCNN 等）极慢。
怎么解决
生成器与判别器对抗训练（2014）。BigGAN（2018）、StyleGAN（2018–19）在人脸等单一领域达到照片级。FID（2017）在这一时期被提出，用来比较 GAN。
代价
训练不稳定，容易模式崩塌（只会画少数几种）；扩展到开放的文字描述时力不从心。后来的 GigaGAN（2023）把 GAN 做到 10 亿参数的文生图，也没追上扩散的质量和多样性；GAN 留下的是对抗损失（见「少步生成」）。
引出
能不能用语言模型那样稳定、可扩展的训练方式来生成任意内容的图？
2021

DALL·E：把图像变成 token，按文字自回归生成

卡在哪
GAN 难以按任意文字生成。
怎么解决
离散 VAE 把 256² 的图压成 32×32 = 1024 个 token（词表 8192），接在最多 256 个文本 token 后面，用 120 亿参数的 Transformer 逐个预测；每个提示词采 512 张，再用 CLIP 挑最好的。
代价
1024 个 token 串行生成，慢；离散化丢细节；画质有限。
引出
同一时期，DDPM（2020）之后扩散的质量追上了 GAN；能不能按文字做扩散？
延续自回归图像生成
Parti（2022，200 亿参数）证明加大自回归模型能画好复杂场景；MaskGIT 与 Muse（2022–23）改成并行地预测被遮住的 token，快得多；VAR（2024）改成预测下一个尺度。这条线在 2025 年随 GPT-4o 回到主流，见「自回归与统一模型」。
2021–2022

像素扩散 + 引导 + 大文本编码器：GLIDE、DALL·E 2、Imagen

卡在哪
扩散的质量已经追上 GAN，但只能无条件或按类别生成：怎样按任意文字、在多高的分辨率上生成？
怎么解决
GLIDE（2021-12，35 亿参数）在像素空间按文字做扩散，人类评测更偏好无分类器引导而不是 CLIP 引导，CFG 从此成为标配。DALL·E 2（2022-04）先由文字生成 CLIP 图像向量，再解码成图。Imagen（2022-05）用冻结的 T5-XXL，发现加大文本编码器比加大去噪网络更有效。三者都先生成 64×64，再用超分模型逐级放大。
代价
像素空间加级联，非常贵；模型都不开放。
引出
能不能便宜到消费级显卡能跑？
被淘汰unCLIP 的两阶段与像素级联
DALL·E 2 的“先生成 CLIP 向量、再解码”和 Imagen 的像素级联，都在潜扩散普及后被放弃：潜空间里一个模型就能直接出 1024²。这一代留下的是 CFG。
2022–2023

潜空间扩散：Stable Diffusion 与开源生态

卡在哪
像素空间太贵，高质量模型只在少数公司手里。
怎么解决
VAE 把图压缩 48 倍后在潜空间扩散。SD 1.x（2022-08，8.6 亿参数 U-Net + CLIP）开源，消费级显卡就能跑；SDXL（2023-07）26 亿参数、两个文本编码器、1024²。ControlNet、DreamBooth / LoRA、IP-Adapter 形成控制与个性化的生态。
代价
U-Net 的扩展性差；CLIP 读不懂长提示、不会拼字；仍需几十步。
引出
换成 Transformer，并解决文字和复杂提示。
仍在发展控制与个性化生态
ControlNet、LoRA 的思路没有随 U-Net 退场：FLUX 和 Qwen-Image 都有对应的 ControlNet 与 LoRA。2025 年以后，一部分需求（换装、保持人物一致、按参考图改）被上下文内编辑直接满足，不再需要单独训练。
2024

MMDiT + 流匹配：SD3、FLUX.1

卡在哪
复杂提示、文字渲染、模型规模上不去。
怎么解决
SD3（2024-03 论文）：MMDiT 联合注意力、流匹配、16 通道 VAE、两个 CLIP 加 T5、分辨率相关的时间步偏移，最大 80 亿参数。FLUX.1（2024-08，120 亿参数）：双流块加单流块；引导蒸馏的 [dev] 和对抗蒸馏的 [schnell]（1–4 步）。
代价
120 亿参数的显存门槛；T5 能拼字，但缺少世界知识、不懂中文、不能读图。
引出
能不能和语言大模型合为一体，让同一个系统理解、规划、编辑？
争论回到像素空间？
JiT（Li 与何恺明, 2025-11, CVPR 2026）指出：自然图像在一个低维流形上，噪声却不在，所以让网络直接预测干净图像 \(\mathbf x_0\)，而不是噪声或速度，一个普通的 Transformer 就能在像素上用 16×16 甚至 32×32 的大 patch 工作，不需要 VAE、预训练特征或对抗损失，ImageNet 上的 FID 与潜空间模型相当。它能否扩展到开放域文生图和精细的文字渲染，还没有定论。
2025–2026

统一模型与上下文内编辑

卡在哪
多轮修改、保持人物一致、复杂排版，以及需要世界知识的提示（“画一张解释光合作用的海报”）。
怎么解决
GPT-4o 图像生成（2025-03，官方称为自回归模型）；上下文内编辑：FLUX.1 Kontext（2025-05）、Qwen-Image-Edit（2025-08）、Nano Banana（2025-08）；大语言模型当文本编码器（FLUX.2，2025-11）；Nano Banana Pro（2025-11）生成前先有一段“思考”，会先画中间草图调整构图。2026 年：Nano Banana 2（Gemini 3.1 Flash Image，2026-02），据报道 10 月有 2.1；Qwen-Image-2.0（生成与编辑合一，2026-02，只提供 API），9 月的 2.1 以非商用许可放出权重；GPT Image 2（2026-04）据报道是 OpenAI 第一个内置“思考”的图像模型，9 月的 GPT Image 2.5 据报道把延迟最多降低一半，10 月的几个人类偏好榜单上据报道排在最前；BFL 的 FLUX 3（2026-07）把图像、视频、音频和机器人动作放进同一个模型，10 月放出 56 亿参数、开放权重的 FLUX 3 Image Klein；字节的 Seedream 5.0（2026-02 起）据报道是闭源的。多参考图、4K、长文字成为标配。
代价
闭源模型的结构不公开，研究与产品之间出现断层；深度伪造与版权问题更尖锐。
引出
从单张图像到连续的视频（第 章）。

自测

1. 一个模型在 512² 上训练时，t = 0.6 的噪声恰好能抹掉构图。换到 1024² 上，按 SD3 的推导，t 应取多少才有同样的破坏程度？
像素数之比 \(P_m/P_n = 4\)，\(\alpha = 2\)。\(t_m = \frac{2\times 0.6}{1 + 0.6} = 0.75\)。
2. 想把一张照片变成水彩风格，同时保持人物轮廓不变。按推导里的高斯模型（τ = 1、流匹配），强度 s = 0.4 时某个成分的保留比例 λ 是多少？如果强度小了风格不够、大了轮廓变形，问题出在哪里，还可以加什么？
\(\lambda = 0.6^2/(0.6^2 + 0.4^2) = 0.36/0.52\approx 0.69\)。水彩的笔触和轮廓都在中高频，强度对它们是同一个截止：要重画笔触，截止就得移到轮廓所在的尺度以下，轮廓也会被重画。调强度无法同时满足。可以加以原图边缘图或深度图为条件的 ControlNet 锁住轮廓，再用较大的强度改风格；或者改用上下文内编辑，把原图作为参考放进序列。
3. 用 DreamBooth 学你家的狗，不加先验保持，只用“a [V] dog”训练 3000 步。会出现哪两种问题？各对应推导里的哪一步？
一是语言漂移：“a dog”的输出也变成你的狗，因为更新 \(\Delta W\mathbf c_{\text{dog}}\) 正比于 \(\mathbf c_{[V]}^\top\mathbf c_{\text{dog}}\)，两个提示词编码高度相似（第 3 步）。二是背图：训练越久越接近“对这几张照片的后验均值”，生成结果复现训练照片的姿势和背景（第 5 步）。补救：加先验保持损失、减少步数、降低学习率、用低秩 LoRA。
