文生图与图生图：潜空间扩散、DiT 与原生多模态

上一章讲了去噪的数学。一个真实的文生图系统还要解决三件事：在哪个空间里去噪（像素太贵，要先压缩到潜空间），用什么网络去噪（U-Net → DiT → MMDiT），怎样听懂提示词并接受各种控制（文本编码器、图生图、局部重绘、参考图）。2025–26 年，这条线又和语言大模型合流：GPT-4o、Nano Banana 这类原生多模态模型让“对话式修图”成为常态。这一章依次讲这些部件，最后讨论水印能否识别 AI 图像，以及版权诉讼走到了哪一步。

第 章的扩散原理对任何数据都成立，但直接用在百万像素的图像上太贵，而且原理本身不涉及“按文字生成”。这一章把原理变成产品。

  • 交叉注意力：第 章；ViT 与 patch：第 章
  • LoRA：第 章；层归一化：第 章

潜空间：先压缩，再扩散

直接在 1024×1024×3 的像素上做扩散，每一步都要处理三百万个数，而且大部分算力花在人眼察觉不到的高频细节上。潜空间扩散（Latent Diffusion, 2022，即 Stable Diffusion）先训练一个 VAE（变分自编码器），把图像压缩成一个小得多的“潜图”，扩散只在潜图上做，最后用 VAE 的解码器还原成像素。

\[ n_{\text{token}} = \frac{H}{\htmlClass{sym-f}{f}\,\htmlClass{sym-p}{p}}\times\frac{W}{f\,p} \]
VAE 把每边压缩 \(f\) 倍，Transformer 去噪器再把潜图切成 \(p\times p\) 的 patch，每个 patch 一个 token。token 数决定了每一步的计算量，而注意力的代价随 token 数平方增长。
\(f\)
VAE 的下采样倍数：SD 系列为 8；DC-AE 等深度压缩编码器 32 或更高
\(p\)
DiT 的 patch 边长，常为 2
1024×1024，\(f = 8\)，\(p = 2\)：\(64\times 64 = 4096\) 个 token。2048×2048 时变为 16384 个，注意力计算增加 16 倍。通道数也在增加：SD 1.x 的潜图是 4 个通道，SD3 与 FLUX 改为 16 个，细节和文字更好。

去噪网络：U-Net → DiT → MMDiT

  • U-Net（SD 1.x、SDXL）：卷积的编码-解码结构，中间插入自注意力层和交叉注意力层：图像特征做 query，文本向量做 key 和 value，每个像素位置去“查”提示词里的词。
  • DiT（Diffusion Transformer, 2022-12）：直接用 Transformer 处理 patch token，时间步和条件通过“自适应层归一化”注入。扩展性和语言模型一样好，是 Sora 和之后所有大型图像、视频模型的基础。
  • MMDiT（SD3, 2024）：文本 token 和图像 token 拼成一条序列做联合注意力，两种模态各有自己的一套权重。FLUX、Qwen-Image（20B, 2025-08）等沿用这一设计。
\[ \operatorname{adaLN}(\mathbf h;\ t, c) = \big(1 + \htmlClass{sym-g}{\boldsymbol\gamma(t, c)}\big)\odot\operatorname{LN}(\mathbf h) + \htmlClass{sym-be}{\boldsymbol\beta(t, c)} \]
层归一化之后的缩放和平移系数不再是固定的可学习参数，而是由时间步 \(t\) 和条件 \(c\) 经过一个小网络算出来。同一个网络在不同的噪声水平下，就会以不同的方式处理特征。
\(\boldsymbol\gamma\)
逐通道的缩放（初始化为 0，使训练开始时等同普通的层归一化）
\(\boldsymbol\beta\)
逐通道的平移
噪声很大时（\(t\) 接近 1），网络应关注整体构图；噪声很小时，应关注纹理细节。adaLN 让每一层在不同的 \(t\) 下放大或抑制不同的特征通道，相当于为每个噪声水平“调制”出一个略有不同的网络。DiT 论文发现，这比把 \(t\) 当作一个额外的 token 输入效果更好。

文本编码器也在升级：从 CLIP（2021）到 T5-XXL（Imagen, 2022），再到 2025 年后直接用多模态大模型（如 Qwen2.5-VL）编码提示词。模型能理解长而复杂的描述，也能把中文、英文文字准确“写”进图里。

意外：图像模型多年来“不会写字”，原因在分词器

原以为
能画出逼真照片的模型，画几个字母应该不在话下。
实际发现
DALL·E 2、Stable Diffusion 1.x 生成的招牌、书名几乎全是乱码。Google 的研究（Liu 等, 2022）发现关键在文本编码器：CLIP 和 T5 用子词分词（第 章），一个词被切成一两个 token，模型根本不知道“咖啡”这两个字或 “coffee” 由哪几个字母组成；换成按字符编码的 ByT5，拼写准确率大幅提高。
为什么
要把文字画对，模型必须知道每个字符的形状和顺序；子词 token 把这些信息藏在了一个整体编号里。这和语言模型数不清 “strawberry” 里有几个 r 是同一个问题。
现在怎么看
2024–25 年，更大的潜空间通道数、字符级或大语言模型作为文本编码器、大量合成的文字渲染数据，让准确的中英文排版成为标配；Qwen-Image 以中文文字渲染见长，GPT-4o 与 Nano Banana Pro 能生成带准确多语言文字的海报和图表。

控制与编辑：图生图之后的十年

最简单的图生图是 SDEdit（2021）：给输入图加噪到某个中间时刻，再从那里开始去噪。

\[ \mathbf x_{\htmlClass{sym-s}{s}} = a_s\,\mathbf x_{\text{输入图}} + b_s\,\boldsymbol\varepsilon\quad\longrightarrow\quad \text{从 } t = s \text{ 开始去噪到 } t = 0 \]
强度 \(s\) 决定保留多少原图：\(s\) 小时只加一点噪声，结果几乎就是原图加细节修饰；\(s\) 大时原图几乎被噪声淹没，模型按提示词自由重画，只保留大致的颜色和构图。
\(s\)
“重绘强度”，0 到 1
流匹配下 \(s = 0.3\)：\(\mathbf x_s = 0.7\,\mathbf x_{\text{输入}} + 0.3\,\boldsymbol\varepsilon\)，构图和人物都会保留，只改变画风；\(s = 0.8\)：原图只剩 20%，基本只保留色块的大致位置。一个草图变成精致插画，常用 0.6–0.75。

更精细的控制来自额外的输入。ControlNet（2023-02）复制一份去噪网络的编码器，接收边缘图、深度图、人体姿态等控制信号，通过“零初始化”的连接注入主网络：

\[ \mathbf y = F(\mathbf x) + \htmlClass{c-new}{Z}\Big(F_{\text{副本}}\big(\mathbf x + \htmlClass{c-new}{Z}(\mathbf c)\big)\Big),\qquad Z\ \text{初始化为全零} \]
\(F\) 是冻结的原网络，\(F_{\text{副本}}\) 是它的一份可训练副本，接收控制信号 \(\mathbf c\)。两者之间用权重初始化为 0 的卷积 \(Z\) 连接，所以训练刚开始时 \(\mathbf y = F(\mathbf x)\)，模型的行为与原来完全一样，不会被一开始的随机噪声破坏。
用几万张“人体姿态骨架 → 照片”的配对训练，副本逐渐学会把姿态信息翻译成主网络能用的特征。因为原网络冻结，它生成高质量图像的能力完全保留；不同的 ControlNet（边缘、深度、姿态）可以叠加使用。
技术年份做法
局部重绘2022掩码外的区域在每一步都替换成原图对应噪声水平的版本，只生成掩码内部
DreamBooth / LoRA2022–23用几张图片微调，让模型学会一个新的人物、画风、物体（第 章）
IP-Adapter2023把参考图像的特征当作额外的“提示词”注入交叉注意力
InstructPix2Pix2022-11用一句指令编辑图片（“把天空变成晚霞”）
FLUX.1 Kontext、Qwen-Image-Edit2025上下文内编辑：参考图 token 和目标图 token 放在同一条序列里，人物一致性和文字编辑大幅提升
Nano Banana / Pro（Gemini 图像）2025-08 / 11对话式多轮编辑；Pro 版支持多张参考图融合、多个人物保持一致、4K 输出和准确的多语言文字

原生多模态：自回归回来了

扩散之外，另一条路线是把图像也变成 token，让语言模型直接生成。早期的 DALL·E（2021）、Parti（2022）质量不如扩散；2024 年以后几项突破改变了局面：

  • VAR（2024, NeurIPS 最佳论文）：不按像素顺序，而是“由粗到细”预测下一个分辨率尺度。Infinity 再把 token 换成按比特预测。
  • MAR / Transfusion（2024）：自回归负责结构和语义，每个 token 用一个小扩散头生成连续值，避免离散化带来的损失。
  • GPT-4o 图像生成（2025-03）：语言模型原生生成图像，提示词理解、文字渲染、多轮编辑明显领先，让“统一模型”成为主流方向之一。
  • 理解与生成统一：Janus、BAGEL、HunyuanImage 3.0（80B MoE，自回归框架）等，同一个模型既能看图又能画图。2026 年 GPT Image 2、Nano Banana 2 / Pro 处在榜首，开源的 FLUX.2、Qwen-Image-2.0、Seedream 5.0 紧随其后。

为什么文本用自回归、图像用扩散？文本离散、顺序性强；图像连续、在空间上整体相关，扩散擅长同时调整所有像素。统一模型通常把两者结合：语言模型负责“想清楚画什么”，扩散解码器负责“画得精细”（上一章的争议框）。

水印与版权

水印能可靠地识别 AI 生成的图像吗

支持
Google 的 SynthID 在生成时就把不可见的水印嵌入像素，经过压缩、裁剪、调色仍能检测；C2PA 内容凭证在文件中记录来源与编辑历史，主要相机厂商和平台已支持。欧盟《人工智能法》要求对 AI 生成内容做可机读的标注。
反对
研究表明，不可见水印可以被“再生成”攻击去除：给图像加噪再用扩散模型去噪，水印随之消失而画面几乎不变（Zhao 等, 2023 证明了这类攻击对一大类水印普遍有效）；元数据可以直接删掉；开源模型的生成结果没有任何水印。检测“这张图是不是 AI 生成”的分类器同样不可靠。
现在怎么看
水印能为“诚实的”平台提供来源信息，但无法阻止有意的伪造。社会层面更现实的方向是反过来：为真实拍摄的照片提供可信的来源证明（相机签名、C2PA），而不是试图标出所有假图。

用艺术家的作品训练图像模型，合法吗

权利方
图像模型在数十亿张网络图片上训练，其中包括大量受版权保护的作品；模型能模仿在世艺术家的画风，与他们直接竞争。Getty Images 起诉 Stability AI，艺术家集体起诉多家公司。
模型方
训练学到的是统计规律而非复制作品；画风本身不受版权保护。英国高等法院在 2025 年 11 月的 Getty 诉 Stability 案判决中驳回了 Getty 的大部分主张（模型本身不是侵权复制品），只在商标问题上部分支持 Getty。
现在怎么看
各国判决尚不一致，美国的 Getty 案仍在审理中（据报道 2026 年 4 月的裁定允许其直接侵权和商标主张继续）。“模型能否逐字复现训练图像”（上一章的记忆问题）是关键事实，各家模型普遍加入了过滤和拒绝生成在世艺术家风格、名人肖像的措施。详见第 、 章。

常见误解

  • 扩散模型直接在像素上去噪。几乎所有实用模型都在 VAE 的潜空间里去噪，最后一步才解码成像素；VAE 的质量直接决定细节和文字的上限。
  • 提示词越长越好。取决于文本编码器：CLIP 只能读 77 个 token，长提示后半截被截断；用大语言模型做编码器后，长描述才真正有效。
  • 图生图就是“照着画”。SDEdit 的强度决定保留多少原图；要精确控制构图和姿态，需要 ControlNet 或参考图注入。
  • AI 图像都带水印，很容易识别。开源模型不带水印，现有水印也能被再生成攻击去除。
  • 原生多模态模型取代了扩散模型。它们常常是“语言模型规划 + 扩散解码”的组合，扩散仍是高保真像素生成的主力。

自测

1. 生成一张 1536×1024 的图，VAE 下采样 8 倍，DiT 的 patch 为 2，共多少个 token？
\((1536/16)\times(1024/16) = 96\times 64 = 6144\) 个。
2. ControlNet 为什么要把连接层初始化为全零？如果随机初始化会怎样？
零初始化让训练开始时副本的输出被乘以 0，整个模型的行为与原模型完全相同，然后逐步学习加入控制。若随机初始化，训练一开始就会向主网络注入大量噪声特征，破坏它已有的生成能力，需要很长时间才能恢复，甚至无法恢复。
3. 想把一张照片变成水彩风格，同时保持人物轮廓不变。SDEdit 的强度该大还是小？如果强度小了风格不够、大了轮廓变形，还可以加什么？
中等偏小（如 0.4–0.6）。若两者无法兼得，可以加上以原图边缘图或深度图为条件的 ControlNet 锁住轮廓，再用较大的强度改变风格。
