注意力：每个位置都去“查”其它位置

2017 年的 Transformer 去掉了循环网络，只用注意力处理序列。注意力做的事一句话说得清：每个位置发出一个 query（查询），和所有位置的 key（标签）比相关度，再按相关度把它们的 value（内容）加权平均，作为自己的新表示。这一章先手算一遍，再讲它为什么这样设计、代价在哪里、2017 年以后怎样改。

上一章结束时，每个 token 都有了一个嵌入向量，但它们彼此独立：“它”不知道自己指的是谁，“bank”在“河岸”和“银行”两种句子里是同一个向量。需要一种机制，让每个位置根据上下文改写自己的表示。

注意力之前：循环网络的瓶颈

2017 年之前，处理序列的主力是循环神经网络（RNN，及其改进版 LSTM）：从左到右一个 token 一个 token 地读，每读一个，就用它更新一个固定大小的“记忆”向量：

\[ \htmlClass{sym-h}{\mathbf h_t} = \tanh\big(\htmlClass{sym-W}{W}\,\htmlClass{sym-h}{\mathbf h_{t-1}} + \htmlClass{sym-U}{U}\,\htmlClass{sym-x}{\mathbf x_t}\big) \]
新的记忆，由旧的记忆和当前 token 混合后经过一个非线性函数得到。整句话读完，所有信息都压在最后一个 \(\mathbf h\) 里。
\(\mathbf h_t\)
读完第 \(t\) 个 token 后的隐藏状态（记忆），大小固定
\(\mathbf x_t\)
第 \(t\) 个 token 的嵌入
\(W\)
记忆到记忆的权重矩阵，每一步共用
\(U\)
输入到记忆的权重矩阵
记忆只有 2 维，\(W = \begin{pmatrix}0.5&0\\0&0.5\end{pmatrix}\)，\(U = I\)。读入 \(\mathbf x_1 = (1, 0)\)：\(\mathbf h_1 = \tanh(1, 0) = (0.76,\ 0)\)。再读入 \(\mathbf x_2 = (0, 1)\)：\(\mathbf h_2 = \tanh(0.38,\ 1) = (0.36,\ 0.76)\)。第一个 token 留下的 0.76 已经衰减成 0.36，再读几个就几乎看不见了。

当时的机器翻译用两个这样的 RNN：编码器从左到右读完原句，最后的 \(\mathbf h\) 就是整句的“摘要”；解码器从这个固定大小的向量出发，一个词一个词地写出译文。这个设计有三个问题：

  1. 信息瓶颈。一整句、一整段的信息都要挤进一个几百维的向量，前面的内容会被后面的冲淡。
  2. 不能并行。第 \(t\) 步依赖第 \(t-1\) 步的结果，训练时 GPU 只能一步步串行地算，序列越长越慢。
  3. 远距离信息传不过来。第 1 个 token 的信息要经过 \(n-1\) 次更新才能到达第 \(n\) 步。两个位置之间，信号要经过的计算步数叫路径长度；RNN 里它等于两个位置的距离。反向传播时，梯度沿着同一条路走回来，每步乘一个雅可比矩阵，范数小于 1 就指数级衰减，叫梯度消失。LSTM 用门控缓解了它，但没有根治。
远处的信息为什么传不过来：数一数路径长度

看梯度怎样从第 \(n\) 步传回第 1 步。对 \(\mathbf h_t = \tanh(W\mathbf h_{t-1} + U\mathbf x_t)\) 求导，利用 \(\tanh'(z) = 1-\tanh^2 z\)：

\[ \frac{\partial \mathbf h_t}{\partial \mathbf h_{t-1}} = \operatorname{diag}\big(1-\mathbf h_t^2\big)\,W \]

由链式法则，跨越 \(n-1\) 步的雅可比矩阵是 \(n-1\) 个这样的矩阵连乘。tanh 的导数不超过 1，于是

\[ \Big\|\frac{\partial \mathbf h_n}{\partial \mathbf h_1}\Big\| \le \prod_{t=2}^{n}\big\|\operatorname{diag}(1-\mathbf h_t^2)\big\|\,\|W\| \le \|W\|^{n-1} \]

（\(\|W\|\) 是 \(W\) 的最大奇异值。）\(\|W\| = 0.9\)、相隔 100 个 token 时，上界是 \(0.9^{99}\approx 3\times 10^{-5}\)。反过来 \(\|W\|>1\) 时梯度又可能爆炸。LSTM 把记忆的更新改成加法 \(\mathbf c_t = \mathbf f_t\odot\mathbf c_{t-1} + \dots\)，这条路径上的雅可比是 \(\operatorname{diag}(\mathbf f_t)\)：遗忘门 \(\mathbf f_t\) 接近 1 时梯度几乎原样传回。但它通常小于 1，取 0.95，100 步后仍只剩 \(0.95^{100}\approx 0.006\)。

再看注意力。输出是 \(\mathbf o_i = \sum_j a_{ij}\mathbf v_j\)（下一节定义），对任意位置的 value 求导：\(\partial \mathbf o_i/\partial \mathbf v_j = a_{ij} I\)。不管 \(i\) 和 \(j\) 相隔多远，中间只有一步。Transformer 原论文用三个量比较几种层（\(n\) 为序列长度，\(d\) 为维度，\(k\) 为卷积核宽度）：

层的类型每层计算量必须串行的步数最长路径长度
自注意力\(O(n^2 d)\)\(O(1)\)\(O(1)\)
循环\(O(n d^2)\)\(O(n)\)\(O(n)\)
卷积（空洞卷积）\(O(k n d^2)\)\(O(1)\)\(O(\log_k n)\)

这个推导告诉我们：RNN 难学长距离依赖，不是调参能解决的：两个位置相隔多远，信号就要连乘多少次。注意力把任意两个位置之间的路径长度降成 1，也去掉了串行；代价是要为每一对位置都算一个分数，计算量从 \(O(nd^2)\) 变成 \(O(n^2d)\)。这个代价贯穿了本章的后半部分。

2014 年，Bahdanau 等人给这种翻译模型加了一个机制：解码器每生成一个词，不再只看那个压缩过的向量，而是回头对输入句子的每一个位置算一个相关度，按相关度加权平均。这就是注意力。论文里画出了这些相关度：把 “European Economic Area” 译成 “zone économique européenne” 时，每个法语词的注意力都落在对应的英语词上，连形容词的语序颠倒也对上了。没有人教过模型两种语言的词怎样对应，这种“对齐”是从翻译任务里自己学出来的。它让模型可以直接“看”到任意远的位置，瓶颈和远距离问题一起解决了。2017 年的 Transformer 把这个思路推到底：干脆去掉循环，序列内部也只用注意力，即自注意力（self-attention）。

从零开始：一句四个词的话，手算一遍注意力

普通的字典查询是精确匹配：给一个键，返回唯一对应的值。注意力把它变成软匹配：查询和每个键都算一个相似度，按相似度把所有值混合起来。这一节只用一句四个词的话、每个词三个数，把每一步都代入数字算出来；后面讲掩码、词序、缩放和多头，都接着用这个例子。

先在两维里直观地感受“软匹配”：拖动 query 和几个 key，看 softmax 怎样按相似度把 value 混合起来。演示里还有一个温度 \(\tau\)：分数先除以 \(\tau\) 再做 softmax。\(\tau\) 小，分布尖，接近“只取分数最大的那个”的硬查询；\(\tau\) 大，接近对所有 value 取平均。后面要讲的除以 \(\sqrt{d_h}\)，其实就是一个固定的温度；第 章采样时调的温度，是同一个旋钮。

四行排成一个 \(4\times 3\) 的矩阵 \(X\)，每行一个词。现在每个向量只知道自己：“追”不知道谁在追、追什么，“球”不知道自己是红的、正在被追。注意力要做的，就是让每个词从其它词那里取回需要的信息，改写自己。

第 1 步：同一个向量，乘三个矩阵

每个词的向量 \(\mathbf x\) 分别乘三个可学习的矩阵，得到三个角色不同的向量：

  • query \(\mathbf q = \mathbf x W_Q\)：我在找什么样的信息；
  • key \(\mathbf k = \mathbf x W_K\)：我这里有什么样的信息，供别人匹配；
  • value \(\mathbf v = \mathbf x W_V\)：如果被选中，我交出去的内容。
\[ \htmlClass{sym-q}{\mathbf q_i} = \htmlClass{sym-x}{\mathbf x_i}\,\htmlClass{sym-WQ}{W_Q},\qquad \htmlClass{sym-k}{\mathbf k_i} = \htmlClass{sym-x}{\mathbf x_i}\,\htmlClass{sym-WQ}{W_K},\qquad \htmlClass{sym-v}{\mathbf v_i} = \htmlClass{sym-x}{\mathbf x_i}\,\htmlClass{sym-WQ}{W_V} \]
同一个词向量，乘三个不同的矩阵，得到它的查询、键和值。三个矩阵对所有位置共用，是这个注意力头要学的全部参数。
\(\mathbf x_i\)
第 \(i\) 个词的向量，\(d\) 维（行向量）
\(W_Q, W_K, W_V\)
三个 \(d\times d_h\) 的矩阵，把 \(d\) 维投影到 \(d_h\) 维
\(\mathbf q_i,\ \mathbf k_i,\ \mathbf v_i\)
第 \(i\) 个词的 query、key、value，都是 \(d_h\) 维；\(d_h\) 叫头维度
\(d = 3\)，\(d_h = 2\)，\(W_Q = \begin{pmatrix}0&2\\1&0\\2&0\end{pmatrix}\)（三行对应事物、会动、颜色）。“小猫”的 \(\mathbf x = (1, 1, 0)\)：\(\mathbf q = 1\times(0, 2) + 1\times(1, 0) + 0\times(2, 0) = (1, 2)\)。\(\mathbf x\) 只含 0 和 1，乘法就是“哪几位是 1，就把 \(W\) 的哪几行加起来”。

再取 \(W_K = \begin{pmatrix}1&-1\\0&1\\0&1\end{pmatrix}\)、\(W_V = \begin{pmatrix}0&0\\1&0\\0&1\end{pmatrix}\)，四个词各算一遍：

这些数可以这样读。key 的两维是（是事物, 是描述）：“小猫”“球”是事物，“追”“红”是描述（动作或属性）；“球”的 key 第二维取 −1，让事物和事物互相排斥。query 的两维是（找事物, 找描述）：“追”和“红”找事物，“球”找描述，“小猫”主要找描述。value 只有（会动, 颜色）两维：这个头只搬“动”和“色”，“事物”这一维被丢掉了。三个矩阵是我手工挑的；真实模型里它们从随机数开始由训练学出来，学到的“角色”也没有现成的名字。

为什么不直接拿 \(\mathbf x\) 当 query、key 和 value？那样 A 看 B 和 B 看 A 的分数永远相同，每个词也往往和自己最像。拆成三个矩阵，“找什么”“被怎样找到”“交出什么”就能各学各的：玩具里“球”的 query 和自己的 key 点积是 −2，它不找同类，专找描述它的词。这样一套 \(W_Q, W_K, W_V\) 叫一个注意力头。

第 2–5 步：打分、缩放、softmax、加权求和

对第 \(i\) 个词，拿它的 query 和每个词的 key 做点积，除以 \(\sqrt{d_h}\)，得到的数叫注意力分数（attention score，也叫注意力 logit）；用 softmax 把分数变成和为 1 的权重，再按权重把 value 加起来：

\[ \htmlClass{sym-o}{\mathbf o_i} = \sum_{j} \htmlClass{c-adv}{\htmlClass{sym-a}{a_{ij}}}\, \htmlClass{c-dir}{\htmlClass{sym-v}{\mathbf v_j}},\qquad \htmlClass{sym-a}{a_{ij}} = \operatorname{softmax}_j\!\Big(\frac{\htmlClass{sym-q}{\mathbf q_i}\cdot \htmlClass{sym-k}{\mathbf k_j}}{\sqrt{\htmlClass{sym-dh}{d_h}}}\Big) \]

把所有位置的 query、key、value 分别排成矩阵 \(Q, K, V\)（每行一个位置），所有位置可以一次算完：

\[ \operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\Big(\frac{\htmlClass{sym-QK}{QK^\top}}{\sqrt{d_h}}\Big)\,V \]
\(QK^\top\) 一次算出所有位置两两之间的分数，得到一个 \(n\times n\) 的矩阵；按行 softmax，再乘 \(V\)。整个过程只有矩阵乘法，非常适合 GPU 并行。
\(QK^\top\)
\(n\times n\) 的分数矩阵，第 \(i\) 行第 \(j\) 列是 \(\mathbf q_i\cdot\mathbf k_j\)
玩具里 \(Q\) 和 \(K\) 都是 \(4\times 2\)，\(QK^\top\) 是 \(4\times 4\)：第一行 \((1, 2, 2, -1)\)，即“小猫”的 q 和四个 key 的点积。整张表一次矩阵乘法算完，上面的权重表就是它除以 \(\sqrt2\) 后逐行 softmax 的结果。

Q 和 K 其实是一个低秩的双线性形式

把 \(\mathbf q_i = \mathbf x_i W_Q\)、\(\mathbf k_j = \mathbf x_j W_K\) 代入分数：

\[ \mathbf q_i\cdot\mathbf k_j = \mathbf x_i\,W_Q W_K^\top\,\mathbf x_j^\top = \mathbf x_i\,W_{QK}\,\mathbf x_j^\top,\qquad W_{QK} = W_Q W_K^\top \in \mathbb R^{d\times d} \]

所以分数是两个 token 向量之间的一个双线性函数，由一个 \(d\times d\) 矩阵决定。\(W_Q, W_K\) 都是 \(d\times d_h\)，它们的乘积秩最多是 \(d_h\)。用两个窄矩阵相乘，而不是直接学一个 \(d\times d\) 的矩阵，等于强制这个双线性形式是低秩的：参数从 \(d^2\) 降到 \(2 d d_h\)，计算也更省（先各自投影到 \(d_h\) 维再点积）。玩具里：

\[ W_{QK} = \begin{pmatrix}0&2\\1&0\\2&0\end{pmatrix}\begin{pmatrix}1&0&0\\-1&1&1\end{pmatrix} = \begin{pmatrix}-2&2&2\\1&0&0\\2&0&0\end{pmatrix} \]

行是 query 一方的特征（事物、会动、颜色），列是 key 一方的特征。第一行说：“事物”去找“会动”和“颜色”（+2），排斥另一个“事物”（−2）；第一列说：“会动”和“颜色”去找“事物”。验证一下：“球”\((1,0,0)\) 看“追”\((0,1,0)\)，取第 1 行第 2 列，得 2，和上面的点积相同。这张表不对称，秩为 2，正好等于 \(d_h\)。

同理，value 和每个头最后的输出投影 \(W_O\)（见多头一节）可以合成 \(W_{OV} = W_V W_O\)，它决定“被看到的位置把什么信息写回来”。可解释性研究把一个注意力头拆成这两部分分析：\(W_{QK}\) 叫QK 电路，决定看哪里；\(W_{OV}\) 叫OV 电路，决定搬什么（Elhage 等, 2021，见章末必读）。

这个推导告诉我们：Q 和 K 不是两种独立的“东西”，而是一个“相关度函数”的两半；分开写是为了低秩和计算效率。也因为 \(W_{QK}\) 不必对称，“A 关注 B”和“B 关注 A”可以不同：玩具里“球”看“追”的分数是 2，“追”看“球”只有 1。

因果掩码、编码器与解码器

GPT 这类模型的任务是预测下一个 token（第 章），第 \(i\) 个位置只能看到前 \(i\) 个 token，否则就是偷看答案。做法是在 softmax 之前给分数矩阵加一个因果掩码：

\[ A = \operatorname{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_h}} + \htmlClass{sym-M}{M}\Big),\qquad \htmlClass{sym-M}{M_{ij}} = \begin{cases} 0 & j \le i\\ -\infty & j > i \end{cases} \]
右上三角（“后面的位置”）的分数被设成负无穷，softmax 之后权重恰好为 0，前面位置的权重重新归一化。
\(M\)

玩具里“红”是第 3 个词，缩放后的分数是 \((1.41,\ 0,\ 0,\ 1.41)\)。加上掩码 \((0, 0, 0, -\infty)\) 变成 \((1.41,\ 0,\ 0,\ -\infty)\)；取指数 \((4.11,\ 1,\ 1,\ 0)\)，总和 6.11，权重 \((0.67,\ 0.16,\ 0.16,\ 0)\)。“球”被完全屏蔽。

掩码带来一个重要的好处：训练时整段文本一次输入，每个位置都在预测自己的下一个 token，\(n\) 个预测在一次前向计算里并行完成。这是 Transformer 训练效率远高于 RNN 的原因之一。

生成时：矩阵一行一行长出来，KV 缓存从这里来

生成时 token 是一个一个出来的。第 \(t\) 步只多了一个新 token，只需要为它算一行：它的 q 和前面 \(t\) 个 key 打分。前面各行一个数都不会变，因为掩码保证了它们看不到新 token。所以旧 token 的 k、v 算一次就可以存起来反复用，这就是 KV 缓存（第 章）。q 不用存：以后每一步只用得到最新那个 token 的 q。提示词那部分可以一次并行算完，叫预填充；之后每步一行，叫解码（第 章）。下面的演示用的是随机向量（不是玩具，格子里的数和手算的表无关），只看形状：每一步只长出一行，上面各行不变。

缓存的大小很快变得可观。Llama 3 8B 每个 token 要存 32 层 × 8 组 K/V × 128 维 × 2（K 和 V），BF16 下每个数 2 字节，合计 131 KB；8192 个 token 约 1.1 GB，128K 个 token 约 17 GB，这只是一个请求。每生成一个 token，都要把整个缓存从显存读一遍，所以解码的速度往往受限于显存带宽，而不是算力（原因见“代价”一节）。K、V 若不分组共用，每个 token 要存 4 倍，约 524 KB。

编码器、解码器与交叉注意力

不加掩码、每个位置能看到全部上下文的叫编码器（BERT 就是这样，擅长理解）；加掩码的叫解码器（GPT 系列，擅长生成）。名字沿用自翻译模型：解码器负责写输出，只能看已经写出的部分。如果 query 来自一个序列、key 和 value 来自另一个序列，叫交叉注意力：原始 Transformer 的解码器用它读取输入句子，文生图模型用它让图像的每个位置去“查”提示词（第 章）。Bahdanau 的注意力就是交叉注意力：query 来自解码器，key 和 value 来自编码器。

顺序从哪来

把“小猫追红球”换成“红球追小猫”：四个词不变，只是顺序变了。不加掩码时再算一遍，每个词的权重和输出与原句完全相同，只是行和列跟着换了位置。意思完全不同的两句话，在注意力看来是同一组向量。这个性质叫置换等变：把输入打乱，\(Q, K, V\) 的行跟着打乱，分数矩阵的行和列按同样方式重排，按行做的 softmax 不受影响，输出也只是跟着重排（完整的证明在第 章）。所以必须另外注入位置信息，今天的标准做法 RoPE 按位置旋转 q 和 k，下一章详细讲。

有一个例外：加了因果掩码后，换词序会改变输出（演示里勾上掩码再切换词序：“红”排第一时只能看自己）。第 \(i\) 个位置恰好能看到 \(i\) 个词，这本身就泄露了位置。下一章里“不加位置编码也能训练”这个意外发现，原因就在这里。

为什么要除以 \(\sqrt{d_h}\)

玩具里 \(d_h = 2\)，除以 \(\sqrt2\) 只是让分数小了三成，不缩放时“球”那一行的权重是 \((6\%, 46\%, 46\%, 1\%)\)，差别不大。真实模型 \(d_h = 128\)，情况完全不同。假设 query 和 key 的每一维都是独立的、均值 0、方差 1 的随机数（初始化时大致如此），点积是 \(d_h\) 项乘积的和：

\[ \operatorname{Var}(\mathbf q\cdot\mathbf k) = \sum_{m=1}^{d_h}\operatorname{Var}(q_m k_m) = \sum_{m=1}^{d_h}\mathbb E[q_m^2]\,\mathbb E[k_m^2] = \htmlClass{c-new}{d_h} \]
每一项的方差是 1，\(d_h\) 项相加，方差就是 \(d_h\)：点积的典型大小是 \(\sqrt{d_h}\)。除以 \(\sqrt{d_h}\) 正好把方差拉回 1。
\(d_h = 128\)：不缩放时点积的标准差约 \(\sqrt{128}\approx 11.3\)。16 个这样的分数里，最大的平均比次大的高约 \(0.48\times 11.3\approx 5.4\)，按这个平均差距算，softmax 之后最大的权重是次大的 \(e^{5.4}\approx 200\) 多倍（这是几何平均；差距的中位数小一些，一半的情况下不到 60 多倍）。缩放后标准差为 1，按平均差距两者只差 \(e^{0.48}\approx 1.6\) 倍。
点积的方差为什么是 \(d_h\)，训练之后又会怎样

第 1 步，单项。设 \(q_m, k_m\) 独立，均值 0、方差 1。乘积的均值 \(\mathbb E[q_mk_m] = \mathbb E[q_m]\,\mathbb E[k_m] = 0\)；方差 \(\mathbb E[q_m^2k_m^2] - 0^2 = \mathbb E[q_m^2]\,\mathbb E[k_m^2] = 1\)。

第 2 步，求和。不同维度的乘积互相独立，独立变量之和的方差等于方差之和（的“初始化”一节用过同一条），所以 \(\operatorname{Var}(\mathbf q\cdot\mathbf k) = d_h\)。由中心极限定理，\(d_h\) 大时 \(\mathbf q\cdot\mathbf k\) 近似服从 \(\mathcal N(0, d_h)\)。

第 3 步，分数拉开多远。16 个独立的标准正态数，最大的一个平均约 1.77，次大的约 1.28，差 0.48。乘上标准差 \(\sqrt{d_h}\)，差距随维度按 \(\sqrt{d_h}\) 增长，权重之比按 \(e^{0.48\sqrt{d_h}}\) 增长：\(d_h = 16\) 时约 7 倍，\(d_h = 128\) 时约 200 倍，\(d_h = 1024\) 时约 \(5\times 10^6\) 倍。这是按平均差距算的几何平均，典型值（中位数）小一些，分别约 4、60、\(10^5\) 倍，但随 \(\sqrt{d_h}\) 指数增长的趋势一样。

第 4 步，训练之后。上面假设 q 和 k 独立。训练的目的恰恰是让该匹配的 q 和 k 方向一致。极端情况 \(\mathbf k = \mathbf q\)：\(\mathbf q\cdot\mathbf q = \sum_m q_m^2\)，均值是 \(d_h\) 而不是 0，除以 \(\sqrt{d_h}\) 后还剩 \(\sqrt{d_h}\)，随维度增长。μP（Yang 等, 2022）据此主张除以 \(d_h\) 而不是 \(\sqrt{d_h}\)，让模型变宽时分数的量级保持不变、最优超参数可以从小模型直接搬到大模型。实际的大模型多把 \(d_h\) 固定在 64–256 之间、不随规模变化（Llama 3 的 8B、70B、405B 都是 128，Qwen3-Next、Qwen3.5 的全注意力层是 256），变大时增加的是头数，所以两种缩放只差一个常数，可以并进 \(W_Q\) 的初始化或学习率里。

这个推导告诉我们：\(1/\sqrt{d_h}\) 是按“初始化时 q、k 互相独立”算出来的，它只保证训练开始时分数的标准差是 1。训练开始以后，分数的大小由学到的权重决定，需要另外的机制来控制。

\(d_h = 128\) 时，不缩放的点积标准差约 11.3。一个 query 对 16 个 key 打分，最大的平均比次大的高约 5.4，按这个差距算，权重之比是 200 多倍：softmax 几乎只剩最大的那一项，这叫 softmax 饱和。饱和的坏处不在前向，而在反向：每个分数收到的梯度，等于“它的权重”乘以“它的上游梯度比加权平均高多少”。分布接近独热时，小权重的位置第一个因子≈0，最大的那个位置第二个因子≈0，所有分数同时收不到梯度，训练就卡住了（推导见下）。

softmax 的雅可比：饱和时梯度为什么会消失

设 \(\mathbf a = \operatorname{softmax}(\mathbf s)\)。对 \(a_i = e^{s_i}/\sum_m e^{s_m}\) 求偏导（商的求导法则）：

\[ \frac{\partial a_i}{\partial s_j} = \frac{\delta_{ij}e^{s_i}\sum_m e^{s_m} - e^{s_i}e^{s_j}}{\big(\sum_m e^{s_m}\big)^2} = a_i\,(\delta_{ij} - a_j) \]

（\(\delta_{ij}\) 在 \(i = j\) 时为 1，否则为 0。）设损失对权重的梯度是 \(g_i = \partial L/\partial a_i\)，传到分数上：

\[ \frac{\partial L}{\partial s_j} = \sum_i g_i\,a_i(\delta_{ij} - a_j) = a_j\Big(g_j - \sum_i a_i g_i\Big) = a_j\,(g_j - \bar g) \]

每个分数收到的梯度，等于它的权重乘以“它的上游梯度比加权平均高多少”。分布接近独热、\(a_1\approx 1\) 时：其它位置 \(a_j\approx 0\)，梯度≈0；第 1 个位置 \(\bar g\approx g_1\)，括号≈0，梯度也≈0。所有分数同时收不到梯度。

代入数字。4 个位置均匀分布 \((0.25\times 4)\)：雅可比对角线是 \(0.25\times 0.75 = 0.19\)，非对角线 \(-0.0625\)。饱和分布 \((0.97, 0.01, 0.01, 0.01)\)：对角线 \(0.97\times 0.03 = 0.029\) 和 \(0.0099\)，非对角线 \(-0.0097\) 和 \(-0.0001\)，整体小了一个数量级；最大权重到 0.999 时，再小 30 倍。

这个推导告诉我们：注意力的分数必须控制在合适的量级。除以 \(\sqrt{d_h}\) 是一种温度，它把初始化时的分数拉回标准差 1；训练过程中分数仍可能越变越大，饱和又会回来，这是大模型训练不稳定的一个来源。

\(1/\sqrt{d_h}\) 是按“初始化时 q、k 互相独立”算出来的，它只保证训练开始时分数的标准差是 1。训练的目的恰恰是让该匹配的 q 和 k 方向一致，它们也会越变越长，分数随之放大，饱和又会回来，这是大模型训练不稳定的一个来源。除以 \(\sqrt{d_h}\) 只是一个固定的温度，管不住训练中的变化。

所以 2023 年以后，大模型普遍在缩放之外再加一道保护，最常见的是 QK-Norm：点积之前，先对 q、k 各做一次 RMSNorm（下一章），把它们的长度固定住。

\[ \htmlClass{sym-s}{s_{ij}} = \frac{\htmlClass{c-clip}{\operatorname{RMSNorm}}(\mathbf q_i)\cdot\htmlClass{c-clip}{\operatorname{RMSNorm}}(\mathbf k_j)}{\sqrt{d_h}},\qquad |s_{ij}| \le \sqrt{d_h} \] QK-Norm：先把 q、k 各自归一化到固定长度再点积，分数有了上限
点积之前，把 q 和 k 各自除以自己的均方根长度（再乘一个可学习的系数），两个长度都是 \(\sqrt{d_h}\) 的向量做点积再除以 \(\sqrt{d_h}\)，结果不超过 \(\sqrt{d_h}\)。q、k 本身怎么变长，都被抵消掉。
\(s_{ij}\)
注意力分数（softmax 之前）
\(d_h = 128\)：不加保护时，训练中 q、k 都变长 3 倍，分数就放大 9 倍，标准差从 1 变成 9；加了 QK-Norm，分数始终在 \(\pm 11.3\) 以内（乘上学到的系数后上限可调），标准差仍约为 1。

另外两种做法各一句。Gemma 2（2024）用 logit 软截断 \(s \leftarrow 50\tanh(s/50)\)，把分数平滑地压进 \(\pm 50\)。Kimi K2（2025-07）的 QK-Clip 不改前向计算，每步更新后检查每个头的最大分数，超过阈值就把这个头的 \(W_Q, W_K\) 按比例缩小。

三种保护的出处和取舍

QK-Norm。Henry 等（2020）最早在低资源机器翻译上提出对 q、k 做归一化。ViT-22B（Dehghani 等, 2023）把视觉 Transformer 扩大到 220 亿参数时发现分数越训越大、损失发散，靠它稳住了训练，此后在语言模型里普及：Gemma 3（2025-03）用它替换了 Gemma 2 的软截断，Qwen3（2025-04）也加上了它。

logit 软截断。\(50\tanh(s/50)\) 在 \(|s|\) 小时几乎不改分数，大时把它压在 \(\pm 50\) 以内（Gemma 2 在注意力里取 50，在输出层取 30）。缺点是和当时常用的 FlashAttention 实现不兼容，额外的 tanh 也要算。

QK-Clip。Kimi K2 取阈值 \(\tau = 100\)。它针对的问题出现在一个试验模型上：激活 90 亿、总共 530 亿参数的混合专家模型（每个 token 只用到一部分参数，第 章），用一种新优化器 Muon 训练，最大分数很快超过 1000；报告指出这种量级通常带来明显的损失尖峰（训练中损失突然暴涨），甚至发散。QK-Clip 只在超过阈值的头上缩小权重，前向计算不变，推理时没有额外开销。

三者的区别：管的是同一件事，即训练中分数的上限。QK-Norm 改前向、对所有头始终生效；软截断也改前向，但只压最大的那些分数；QK-Clip 只在训练时动权重。

下面的演示把这一节串起来：每个点 240 个随机 query，各对 16 个随机 key 打分，看多少个 query 的梯度已小于均匀分布时的 10%。默认是 \(d_h = 128\)、不缩放：43% 的 query 已经“死了”，最大权重平均 88%。切到“除以 \(\sqrt{d_h}\)”，曲线变平，最大权重平均降到 24%；再把 \(c\) 拖大，模拟训练中 q、k 越变越长，饱和又回来；最后切到 QK-Norm，\(c\) 再大也没有影响。

多头注意力

一个注意力头只能给出一组权重，也就是一种“关注方式”，可一个词往往同时需要几种信息：主语是谁、宾语是谁、前一个词是什么。多头注意力用 \(h\) 套各自的 \(W_Q, W_K, W_V\)，把同一个 \(\mathbf x\) 投到 \(h\) 个 \(d_h\) 维的子空间里，每套是一个独立的头，各算各的，结果拼起来再乘一个输出矩阵 \(W_O\)。下面按标准多头讲，每个头都有自己的 K、V（几个头共用 K、V 的 GQA 见“放回大模型”）：

\[ \begin{aligned} \operatorname{MultiHead}(X) &= \big[\,\htmlClass{sym-hd}{\text{head}_1};\ \dots;\ \text{head}_h\,\big]\,\htmlClass{sym-WO}{W_O}\\ \text{head}_m &= \operatorname{Attention}(XW_Q^{(m)},\ XW_K^{(m)},\ XW_V^{(m)}) \end{aligned} \]
\(h\) 个头各自用一套小矩阵做注意力，输出拼接成 \(d\) 维，再用 \(W_O\) 混合。
\(\text{head}_m\)
第 \(m\) 个头的输出，维度 \(d_h\)，通常取 \(d/h\)（玩具为了好算不守这一条）
\(W_O\)
输出投影，\(d\times d\)，把各头的结果混在一起
Llama 3 8B：\(d = 4096\)，\(h = 32\)，每头 \(d_h = 128\)。每个头的 \(W_Q^{(m)}\) 是 \(4096\times 128\)，32 个头拼起来正好是 \(4096\times 4096\)：参数量和“一个 4096 维的大头”完全相同，只是被分成了 32 种独立的关注方式。

回到玩具。“追”想知道谁在追、追什么，可上面那个头给“小猫”和“球”各 33%：一个 softmax 只能给出一种混合，主语和宾语被搅在一起。多头的办法是并排放两个头，各有自己的 \(W_Q, W_K\)，各做一次 softmax。为了好算，每个头只取 \(d_h = 1\)（\(\sqrt{d_h} = 1\)，不用缩放），两个头里“追”的 query 都是 2。头 1 的 key 是“事物 + 会动”，四个词依次是 \((2, 1, 0, 1)\)，分数 \((4, 2, 0, 2)\)，softmax 后 78% 给“小猫”；头 2 的 key 是“事物 − 会动”，依次是 \((0, -1, 0, 1)\)，分数 \((0, -2, 0, 2)\)，78% 给“球”。两个头各取各的 value 再拼起来，主语和宾语就落在输出的不同位置上。一个头只有一种注意力分布，\(h\) 个头才能同时看 \(h\) 个地方。取 \(d_h = d/h\) 时，\(h\) 个头的参数量和计算量与一个 \(d\) 维的大头相同（推导见下），多头买到的就是这 \(h\) 个独立的 softmax。训练好的模型里，头确实各有分工（下一节）。

多头 = 在 \(h\) 个低维子空间里各查一次

把输出矩阵 \(W_O\)（\(d\times d\)）按行切成 \(h\) 块，每块 \(d_h\times d\)，记作 \(W_O^{(m)}\)。拼接后再相乘，等于各头分别相乘再相加：

\[ \big[\text{head}_1;\dots;\text{head}_h\big]W_O = \sum_{m=1}^{h}\text{head}_m\,W_O^{(m)} = \sum_{m=1}^{h} A^{(m)}\,X\,\underbrace{W_V^{(m)}W_O^{(m)}}_{W_{OV}^{(m)}} \]

其中 \(A^{(m)} = \operatorname{softmax}\big(XW_{QK}^{(m)}X^\top/\sqrt{d_h}\big)\)。多头注意力于是是 \(h\) 个互不通信的小单元之和：每个单元用自己的 QK 电路决定看哪里，用自己的 OV 电路决定搬什么，结果加在一起。

参数量。每个头的 \(W_Q, W_K, W_V\) 各 \(d\times d_h\)，加上 \(W_O^{(m)}\) 的 \(d_h\times d\)，共 \(4dd_h\)；\(h\) 个头共 \(4dd_hh = 4d^2\)（因为 \(hd_h = d\)）。一个 \(d_h = d\) 的单头也是 \(4d^2\)。计算量。每个头算分数 \(2n^2d_h\) FLOPs，\(h\) 个头 \(2n^2d\)，同样与单头相同。

不同在哪。单头只有一个 softmax：每个位置只能给出一种权重分布。\(h\) 个头有 \(h\) 个 softmax，可以同时看 \(h\) 个地方。代价是每个头的 \(W_{QK}^{(m)}\) 秩最多是 \(d_h\)：头切得太细，每个头能表达的“相关度”就太粗糙，Bhojanapalli 等（2020）称之为低秩瓶颈。这也是 \(d_h\) 一般固定在 64–256、模型变大时加头数而不是把头切得更细的原因。

这个推导告诉我们：多头不是“更多参数”，而是把同样的参数分成 \(h\) 份独立的查找，各头的输出相加后写回同一个向量（下一章的残差流）。各头独立，也是 MQA、GQA 能成立的前提：K、V 只是各头的“被查材料”，可以让几个头共用一份。

训练好的模型里，大部分头可以直接删掉

发现
Michel 等（2019）在翻译模型和 BERT 上逐个删头，大部分头单独删掉，成绩没有显著变化。Voita 等（2019）把英俄翻译模型编码器的 48 个头剪掉 38 个，BLEU（翻译质量的自动评分）只降 0.15。但一次删太多，成绩会突然崩溃（Michel 等）。
但是
剩下的少数头不能动：最后才被剪掉的，是看相邻位置、跟踪句法、关注罕见词这类分工明确的头。长上下文模型里，不到 5% 的“检索头”负责从上下文里复制信息，屏蔽它们，在长文里找一句话的“大海捞针”测试就会失败，模型开始编造（Wu 等, 2024）。
意义
冗余主要用在训练中：很多头同时探索，少数头最终承担关键功能。推理时它被用来省显存，GQA 共用 K、V 几乎不掉点。

训练出来的注意力模式

可解释性研究（Anthropic 等, 2021–2022）在训练好的模型里找到了一些分工清晰的头。下面的演示是按规则画的示意图，不是真实模型的权重；可以输入自己的句子，悬停看每一行在看哪里。正文只讲其中两种：归纳头和注意力汇。

归纳头：照着前文接着写

读到“哈利 波特 走进了 …… 哈利”，下一个词多半是“波特”。归纳头（induction head）做的就是这件事：上次见到 A 后面跟着 B，这次又见到 A，就去看 B，预测下一个是 B。它要两层配合：前一层的前一个 token 头只看紧挨着的前一个位置，把“我前面是谁”写进每个位置；后一层的归纳头再用它去匹配。只有一层时，key 里没有“我前面是谁”，只能找到前面那个 A 本身（推导见下）。Olsson 等（2022）发现，归纳头在训练早期一个很窄的窗口里突然形成，同一时刻上下文学习（in-context learning，不改参数、只靠上下文变得更会预测）的能力也跃升，并推测大模型的大部分上下文学习可能都靠它。后来的消融实验（Yin 与 Steinhardt, 2025）发现，看几个示例就做新任务的 few-shot 能力主要靠另一类“函数向量头”，其中不少在训练早期先是归纳头。

归纳头为什么至少要两层

任务：前文出现过“… A B …”，现在又读到 A，要预测下一个是 B。例如“哈利 波特 走进了 …… 哈利 →？”。

只有一层行不行？第 \(i\) 个位置（第二个 A）的 query 只依赖 \(\mathbf x_i\)，第 \(j\) 个位置的 key 只依赖 \(\mathbf x_j\)（和它的位置）。分数 \(\mathbf x_iW_{QK}\mathbf x_j^\top\) 能表达“找和我一样的 token”，于是会找到前面那个 A 本身，把 A 复制过来，预测出 A：错了一位。真正要找的是“前一个 token 是 A 的那个位置”，可位置 \(j\) 的向量里没有“我前面是谁”的信息。

第 1 层：前一个 token 头。它的分数只看相对位置，几乎把全部权重放在 \(j-1\) 上（这需要位置编码，第 章）。它的 OV 电路把 \(\mathbf x_{j-1}\) 的内容搬到位置 \(j\)：

\[ \mathbf r_j \leftarrow \mathbf r_j + \mathbf x_{j-1}W_{OV}^{(1)} \]

（\(\mathbf r_j\) 是位置 \(j\) 的向量，每一层的输出都加到它上面。）现在 B 所在的位置里写着“我前面是 A”。

第 2 层：归纳头。它的 query 读当前 token 的内容（“我是 A”），key 读第 1 层写进去的那一份（“我前面是 A”）：

\[ s_{ij} = \frac{\big(\mathbf x_iW_Q^{(2)}\big)\cdot\big(\mathbf x_{j-1}W_{OV}^{(1)}W_K^{(2)}\big)}{\sqrt{d_h}},\quad \text{在}\ x_{j-1} = x_i\ \text{时最大} \]

于是第二个 A 的注意力落在 B 上；归纳头的 OV 电路把 B 的内容搬回来，输出层据此提高“B”的概率。key 用到了前一层某个头的输出，这种跨层配合叫 K 组合（K-composition, Elhage 等, 2021）。

这个推导告诉我们：在上下文里“照着前文接着写”，需要两个头跨层配合，单层注意力做不到：只有注意力层的一层模型里找不到归纳头，两层模型里就有。至于它为什么在训练中“突然”出现，一种常见的解释是：两个零件缺一不可，任何一个没长好，另一个也得不到有用的梯度。这只是假说，Olsson 等把这次相变的成因列为开放问题。演示里切换“前一个 token”和“归纳头”两种模式，看的就是这两层。

注意力汇：softmax 必须把权重分出去

很多头会把大量权重放在第一个 token 上，哪怕它只是一个“开始”标记，这叫注意力汇（attention sink）。原因在 softmax：权重和必须为 1，一个头“没什么要看”的时候，多出来的权重总得有个去处。汇所在位置的 value 很小，权重倒进去，输出几乎不变，等于这个头“什么也没做”（推导见下）。StreamingLLM（2023）利用了这一点：做滑动窗口推理时保留开头 4 个 token，Llama 2 等模型就能稳定处理 400 万 token 的流式输入；把开头的 token 挤出窗口，困惑度（预测越不准越高）立刻飙升。

注意力汇为什么出现：权重必须和为 1

注意力的输出是 value 的加权平均：\(\mathbf o_i = \sum_{j\le i}a_{ij}\mathbf v_j\)，\(a_{ij}>0\)，\(\sum_j a_{ij} = 1\)。

第 1 步，一个头有时需要“什么也不做”。很多头只在特定情况下有用：归纳头只在出现重复时有事做。没事做时，最好的输出是 \(\mathbf o_i\approx\mathbf 0\)，不往这个位置的向量里写任何东西。

第 2 步，softmax 不允许“全部为零”。权重和必须为 1，\(\mathbf o_i\) 只能落在各个 \(\mathbf v_j\) 的加权平均里。要让它接近 0，办法是把权重集中到某个 value 接近 0 的位置上。

第 3 步，为什么是第一个 token。这个“垃圾桶”必须对所有位置都可见；在因果掩码下，只有第 1 个位置被每个位置看到。于是模型学会让第一个 token 的 key 和几乎所有 query 都匹配。Gu 等（ICLR 2025）的测量显示，汇所在位置的 value 对输出几乎没有贡献，它的作用更像一个附加在 key 上的偏置。

第 4 步，给它一个正式的出口。在 softmax 的分母里加一项可学习的常数 \(b\)：

\[ a_{ij} = \frac{e^{s_{ij}}}{e^{b} + \sum_{j'\le i}e^{s_{ij'}}},\qquad \sum_{j} a_{ij} = 1 - \frac{e^{b}}{e^{b} + \sum_{j'\le i}e^{s_{ij'}}} < 1 \]

所有分数都低时，权重和接近 0，输出接近 0，不需要占用一个真实的 token。\(b = 0\) 时分母多出一个 \(e^0 = 1\)，就是 Evan Miller（2023）提出的“分母加一”；gpt-oss（2025-08）让每个头学一个自己的 \(b\)。另一种出口是门控：输出乘一个 0 到 1 之间的门，门关上就是“什么也不做”（下面的门控注意力）。Gu 等还发现，把 softmax 换成不归一化的 sigmoid，10 亿参数以内的模型就不再出现注意力汇。

这个推导告诉我们：注意力汇是“权重和为 1”加上因果掩码之后，模型能找到的最便宜的空操作。显式地给它一个空操作，它就不再需要占用第一个 token。

注意力汇常和巨量激活（massive activations）一起出现。这里的“激活值”指每个位置的向量（下一章的残差流）里的数：Sun 等（2024）发现其中极少数几个比其它的大得多（可达 10 万倍），几乎不随输入变化，作用相当于固定的偏置：只把其中 4 个置零，模型就崩溃，换成它们的平均值却几乎没有影响。它们恰好出现在汇所在的位置上，也是量化最难处理的离群值（第 章）。

另一种出口是给头加一个开关。Qwen 团队 2025 年的门控注意力（gated attention）在注意力输出之后、乘 \(W_O\) 之前，逐头逐维乘一个由当前 token 决定的 sigmoid 门：\(\mathbf o_i' = \sigma(\mathbf x_iW_g)\odot\mathbf o_i\)。门关上，这个头的输出就接近零，不必再占用第一个 token：论文里各层平均分给第一个 token 的注意力从 46.7% 降到 4.8%，训练也更稳。这篇论文获 NeurIPS 2025 最佳论文，门控注意力已用在 Qwen3-Next（2025-09）和 Qwen3.5（2026-02）的全注意力层里（它在块里的位置和更多数字见下一章）。

注意力汇是缺陷还是功能

一种看法
它是 softmax 的副作用。门控注意力的实验表明，给出显式的出口之后汇基本消失；gpt-oss 也提供了这样的出口。
另一种看法
它是模型学会的“隐式门控”。2026 年的研究（如 “The Spike, the Sparse and the Sink”）发现，汇与巨量激活同时出现主要源于 Pre-Norm（在注意力和 MLP 之前先做归一化，下一章），去掉它两者就分开；也有研究认为，汇让梯度集中到第一个 token 上，巨量激活是为缓冲这股梯度长出来的（Chen 等, 2026）。
现在怎么看
汇是“权重和必须为 1”下的变通办法，这一点没有分歧；巨量激活和汇谁是因、谁是果，仍无定论。

注意力权重能不能当作“解释”

主张
权重大的位置就是模型“认为重要”的位置，可以直接用来解释模型的决定。
反方
Jain 与 Wallace（2019）发现，常常能找到完全不同的注意力分布，而输出几乎不变；value 的大小、后续的层也都会改变最终影响。玩具里“追”给“球”33% 的权重，取回的却是零；注意力汇上权重最大，提供的信息却几乎为零。
现在怎么看
权重可以提示“信息从哪里流过来”，但不等于因果解释。要确认某个位置的作用，得做干预实验（改掉它看输出怎么变），见第 章。

代价：平方级的计算与显存

自注意力要为每一对位置算一个分数。设序列长度为 \(n\)、隐藏维度为 \(d\)：一层里分数 \(QK^\top\) 和加权求和 \(AV\) 两步的计算量约 \(4n^2d\)，随 \(n\) 的平方增长；Q/K/V/O 投影和下一章的 MLP 都是一个位置一个位置地算，随 \(n\) 线性增长，合计约 \(24nd^2\)（逐项推导见第 章）。

\[ \underbrace{4\,n^2 d}_{\text{注意力：}QK^\top\ \text{和}\ AV} \quad\text{vs}\quad \underbrace{24\,n\,d^2}_{\text{投影与 MLP（下一章）}} \]
注意力的计算量随 \(n\) 的平方增长，线性层随 \(n\) 线性增长。两者在 \(n = 6d\) 时相等；序列再长，注意力就成了主要开销。
玩具里一个头只有 \(4\times 4 = 16\) 个分数，Llama 3 8B 在训练长度 8192 下一个头就有约 6700 万个。\(d = 4096\)：\(n = 6\times 4096 \approx 2.5\) 万 token 时两者相当。到 \(n = 100\) 万，注意力的计算量是线性层的 \(10^6/(6\times 4096) \approx 40\) 倍。显存方面，一个头的 \(n\times n\) 分数矩阵在 \(n = 128\text{K}\) 时就有约 \(1.7\times 10^{10}\) 个数，BF16 下约 34 GB。

这个平方代价有两张面孔。训练和预填充时，一次要算 \(n\times n\) 个分数：计算量是 \(4n^2d\)，朴素实现还要把 \(n\times n\) 的矩阵写进显存再读出来。解码时每步只多一行分数，算得不多，但要把整个 KV 缓存从显存读一遍：每读一个数只做一次乘加，普通多头注意力相当于每字节 1 次运算，Llama 3 8B 的 GQA 每份 K、V 被 4 个头共用，也只有约 4 次；而 H100 每读 1 字节能做约 300 次运算，算力大半闲着。前一张面孔靠 FlashAttention 这类“换计算顺序”的方法缓解，后一张靠 MQA、GQA、MLA 这类“缩小 KV”的方法缓解，两者都不改变平方本身；要改变平方，得改注意力的公式。下一节按这两条线，再加上“数值不稳”一条，把 2017 年以后的改动排一遍。

一层注意力要算多少、存多少：训练、预填充与解码

训练与预填充（一次处理 \(n\) 个 token）。一次 \((m\times k)\) 乘 \((k\times p)\) 的矩阵乘法约 \(2mkp\) 次浮点运算（FLOPs）。只数注意力自己的项（按标准多头）：

  • Q、K、V、O 四个投影：\(n\times d\) 乘 \(d\times d\)，各 \(2nd^2\)，共 \(8nd^2\)；GQA 的 K、V 投影更小。
  • 分数 \(QK^\top\)：每个头 \(n\times d_h\) 乘 \(d_h\times n\)，\(2n^2d_h\)；\(h\) 个头共 \(2n^2d\)。
  • 加权求和 \(AV\)：同样 \(2n^2d\)。

平方项合计 \(4n^2d\)，整层的线性部分（再加上下一章 MLP 的 \(16nd^2\)）是 \(24nd^2\)，两者之比 \(n/6d\)。因果掩码让一半的分数不必算，好的内核会跳过它们，平方项再减半。存储方面，朴素实现要把每个头 \(n\times n\) 的分数矩阵写进显存；FlashAttention 分块计算、不写回，显存降到 \(O(n)\)，计算量不变。

解码（每步 1 个 token）。第 \(t\) 步：投影 \(8d^2\) FLOPs；和缓存里 \(t\) 个 key 打分、再加权求和，共 \(4td\)；还要把这 \(t\) 对 K、V 从显存读一遍。生成 \(n\) 个 token，注意力的总计算是 \(\sum_t 4td\approx 2n^2d\)，仍是平方，只是摊到了每一步。如果不缓存，每一步都要为前面所有 token 重算 K、V，光这一项就是 \(\sum_t 4td^2\approx 2n^2d^2\)，又多出一个 \(d\) 倍。

解码慢在读。每从缓存读一个 key 元素，要和共用它的每个 query 头各做一次乘加（2 FLOPs）；BF16 一个数 2 字节。普通多头每个 KV 头只配 1 个 query 头，相当于每字节 1 FLOP；GQA 每组 \(h/g\) 个头共用，约 \(h/g\) FLOP/字节，Llama 3 8B 是 4。H100 的 BF16 稠密算力约 989 TFLOPS、显存带宽约 3.35 TB/s，每读一个字节能做约 300 次运算，所以解码时的注意力几乎全部时间都花在读 KV 缓存上（第 章把这个比值和批大小一起算了一遍）。

这个推导告诉我们：训练和预填充卡在 \(n\times n\) 的计算与显存，解码卡在每步读整个 KV 缓存的带宽。换实现只能缓解其中一项，去不掉平方；要去掉平方，只能改公式。

每一代在修什么：从一条线到几条线

2017 年以前，注意力的改动是一代接一代的，改的都是“分数怎么算”：

\[ \operatorname{score}(\htmlClass{sym-s}{\mathbf s}, \htmlClass{sym-hh}{\mathbf h}) = \begin{cases} \htmlClass{sym-w}{\mathbf w}^\top\tanh\big(\htmlClass{sym-w}{W_1}\mathbf s + \htmlClass{sym-w}{W_2}\mathbf h\big) & \text{加性（2014）}\\ \mathbf s^\top \htmlClass{sym-W}{W}\,\mathbf h & \text{乘性（2015）}\\ \htmlClass{c-new}{\mathbf q\cdot\mathbf k/\sqrt{d_h}} & \text{缩放点积（2017）}\end{cases} \]
加性打分用一个小网络比较两个向量；乘性打分用一个矩阵做双线性比较，点积是 \(W = I\) 的特例；缩放点积先把两边各自投影成 q、k，再点积、除以 \(\sqrt{d_h}\)。
\(\mathbf s\)
解码器当前的状态，相当于 query（只在这张卡里这样用，别处的 \(s\) 是分数）
\(\mathbf h\)
编码器在某个位置的隐藏状态，同时充当 key 和 value
\(\mathbf w, W_1, W_2\)
加性打分的参数：一个只有一层隐藏层的小网络
\(W\)
乘性打分的矩阵
\(n\) 个 query 对 \(n\) 个位置：每个 \(W_1\mathbf s\)、\(W_2\mathbf h\) 都可以提前算好，但 \(\tanh\) 必须对每一对单独算，要存一个 \(n\times n\times d_a\) 的中间结果（\(d_a\) 是小网络隐藏层的宽度），无法写成一次矩阵乘法。点积打分把 \(n\times n\) 个分数写成一次 \(QK^\top\)，直接用 GPU 上最快的矩阵乘法。

加性注意力（Bahdanau 等, 2014）用一个小网络比较解码器状态和编码器在每个位置的状态，每一对位置都要单独过一次网络。Luong 等（2015）换成乘性或纯点积打分，一次矩阵乘法就能算完所有分数，还试了只看一个窗口的“局部注意力”，这是后来滑动窗口注意力的前身。Transformer（2017）指出，维度大时不缩放的点积反而不如加性打分，并推测原因是点积太大、softmax 饱和，于是除以 \(\sqrt{d_h}\)（“为什么要除以 \(\sqrt{d_h}\)”一节）；它同时让 Q、K、V 都来自同一序列，去掉了循环。

2017 年以后，改动不再是一代接一代，而是几条各自推进的线，很多工作发生在同一时期。按要解决的问题分成三条，外加一项不改公式的工程改进：

算得多（\(n^2\) 个分数）。要降低 \(n^2\) 本身，只能改公式。稀疏注意力让每个 query 只看挑出来的一部分位置：Sparse Transformer（2019）让每个位置只看最近的约 \(\sqrt n\) 个位置和每隔 \(\sqrt n\) 取一个的“跨步”位置，两层叠起来任意两个位置仍连得通，计算量降到 \(O(n\sqrt n)\)；GPT-3（2020）就交替使用稠密层和局部带状的稀疏层。这种模式固定、与内容无关，会漏掉该看的位置，没成为主流；DeepSeek V3.2（2025）的 DSA 改成先用一个很轻的打分器按内容挑出 top-k。线性注意力去掉 softmax，把历史压进固定大小的状态，精确回忆变弱，所以和全注意力混用：Qwen3-Next、Kimi Linear、Qwen3.5 都是 3 层线性配 1 层全注意力。细节见第 章。

读得多（解码时读 KV 缓存）。Shazeer（2019）为此提出 MQA：缓存和读取量除以头数，代价是质量下降、训练不稳。GQA（2023）取中间，还可以用原预训练约 5% 的算力把现成的多头模型改造过来，成了今天的默认做法。DeepSeek-V2 的 MLA（2024）只缓存一个 512 维的潜向量（外加 64 维单独处理位置），每层每 token 存 576 个数，128 个头的普通多头注意力要存 \(2\times 128\times 128 = 32768\) 个；代价是 RoPE 要“解耦”出一小块单独旋转（第 章）。

数值不稳（分数失控、注意力汇）。就是“为什么要除以 \(\sqrt{d_h}\)”和“注意力汇”两处讲的事：分数越训越大会让 softmax 饱和，权重和必须为 1 又逼出了注意力汇。QK-Norm、软截断、QK-Clip 管分数的上限，门控注意力和可学习的汇给 softmax 一个出口。它们只改一两处，不动平方代价。

不改公式：FlashAttention（2022）。它不属于上面任何一条：一个字都没改公式，只改了搬数据的顺序。它把 Q、K、V 切成小块放进片上的高速存储，用在线 softmax 边扫边归一化，结果与原公式完全相同（不是近似），显存从 \(O(n^2)\) 降到 \(O(n)\)，速度快 2–4 倍。代价是每一代 GPU 都要重新写内核（第 章）。

十二年下来，\(\operatorname{softmax}(QK^\top/\sqrt{d_h})V\) 这个核心没有被替换：改动要么包在它外面，要么只在一部分层里用别的东西代替它。

常见误解

  • 注意力权重越大，说明这个词越重要。权重只说明看了哪里，取回什么由 value 决定，见“注意力权重能不能当作解释”的争议框。
  • 除以 \(\sqrt{d_h}\) 是为了防止数值溢出。溢出靠 softmax 之前先减去最大值解决，这不改变结果。\(\sqrt{d_h}\) 管的是分布的形状：分数拉得太开，softmax 饱和，梯度传不回去。
  • Transformer 天然知道词的顺序。注意力本身对顺序不敏感：“小猫追红球”和“红球追小猫”在不加掩码时得到同样的一组输出，只是换了位置。顺序信息要另外注入，即下一章的位置编码。
  • KV 缓存是一种为了提速而做的近似。它是精确的。因果掩码保证旧 token 看不到新 token，它们的 k、v 和注意力输出在生成过程中根本不会变，缓存只是省掉了重复计算。会改变结果的是另一些技术：把缓存量化成低精度、丢掉一部分旧 token、用线性注意力替代。

演进史

2014-09

Bahdanau 注意力：翻译时回头看原句

卡在哪
编码器把整句压成一个固定向量，句子一长，翻译质量就急剧下降。
怎么解决
解码器每写一个词，都对原句的每个位置打分、加权取信息（本章开头）。
代价
主体仍是 RNN，训练依旧串行、很慢。
引出
既然注意力已经能看到所有位置，还需要循环吗？
2017-06

Transformer：只用注意力

卡在哪
RNN 无法并行训练，长距离依赖难以学习。
怎么解决
去掉循环，多头缩放点积注意力 + MLP 堆叠，配合位置编码，所有位置并行计算。
代价
计算和显存随序列长度平方增长；生成时 KV 缓存随长度线性增长，每步都要读一遍。
引出
平方的计算和读 KV 的带宽成了此后效率工作的两个靶子（Sparse Transformer 和 MQA 的论文各以一个为出发点）。
被取代卷积序列模型（ConvS2S, 2017）
同年 Facebook 用卷积代替循环，也能并行。但卷积的感受野随层数缓慢扩大，远距离依赖需要很多层；注意力一层就能连接任意两个位置，最终胜出。
退出生成主线只有编码器与编码器-解码器
2018 年起，BERT（只有编码器，双向注意力）和 GPT（只有解码器，因果掩码）都先在海量文本上预训练，再用到具体任务上。BERT 式的双向编码器和 T5 式的编码器-解码器，在 2019–2021 年的很多基准上领先。但只有解码器的模型把所有任务都写成“接着往下写”，一个结构、一个目标就能扩展到底，还能直接用 KV 缓存生成。到大模型时代，前沿模型几乎都是只有解码器的。双向编码器留在了检索、向量化和重排序里。
2019–2023

效率：近似注意力输给精确而快的注意力

卡在哪
长序列又慢又占显存；生成时每步都要读一遍所有头的 K、V。
怎么解决
固定模式的稀疏和各种近似大多没成主流；胜出的是只改计算顺序的 FlashAttention（2022），和减少 KV 头数的 MQA（2019）、GQA（2023）。
代价
平方没有消失，只是更快、更省显存。
引出
2024 年起上下文走向百万 token，KV 缓存和平方计算重新成为推理的主要成本（2024–2026 节点）。
大多被淘汰2020 年的“高效注意力”家族
Reformer、Linformer、Performer、Longformer、BigBird 等用哈希、低秩、核近似或固定的稀疏模式降低复杂度。它们大多在质量上有损，而且对 GPU 不友好（不规则访存），实际速度提升有限。FlashAttention 让精确注意力足够快之后，它们基本退出了主流。留下来的是“局部窗口 + 少量全局”的思想（滑动窗口注意力），以及线性注意力这条线，后者在 2025 年以混合架构的形式回归。
2020–2025

数值：给分数和 softmax 加保护

卡在哪
与效率线同时期的另一条线：模型和学习率变大后，分数越训越大，损失发散（ViT-22B, 2023）；注意力汇（2023）和巨量激活（2024）给流式推理和量化添了麻烦。
怎么解决
QK-Norm（2020 年提出，2023 年起普及）、软截断（2024）、QK-Clip（2025）管分数的上限；可学习的汇和门控注意力（2025）给 softmax 一个出口。
代价
大多是经验性的改动；汇和巨量激活的成因仍有争论（见上面的争议框）。
引出
两条线在同一个模型里汇合：Qwen3-Next（2025-09）和 Qwen3.5（2026-02）用 3:1 的线性混合省 KV，剩下的全注意力层带门。
2024–2026

百万 token：压缩 KV、线性混合、稀疏选择

卡在哪
接 2019–2023 的效率线：上下文到了百万 token，用了 GQA 之后，KV 缓存与平方计算仍是推理的主要成本。
怎么解决
MLA 把 KV 压成潜向量（2024）；3:1 的线性注意力混合（2025–26）；DSA 按内容挑 top-k（2025）。
代价
每种新结构都要配新的内核和推理框架支持；线性层的精确回忆变弱。
引出
这些变化都发生在同一个 Transformer 块里，注意力之外还有 MLP、归一化、残差连接和位置编码（下一章）。
回归线性注意力
2020 年的线性注意力因为精确回忆差被搁置。加上 Delta 规则和遗忘门之后（DeltaNet、Gated DeltaNet、KDA），它的状态更新相当于在线做一步梯度下降，记忆不再只加不减。2025 年起它作为混合架构的主体回到了前沿模型里（第 章）。
争论MiniMax 从线性混合回到全注意力
MiniMax-01（2025-01）用 7:1 的线性注意力混合，M2（2025-10）回到了全注意力，理由是复杂推理与智能体任务上的缺陷和工程生态不成熟。同一时期 Qwen 和 Kimi 则继续加码混合。哪条路更适合前沿模型，取决于任务和部署条件，目前没有定论。

自测

1. 加因果掩码后，玩具里“红”的输出从 \((0.50, 0.10)\) 变成 \((0.84, 0.16)\)，“会动”这一维反而变大了。为什么？“球”那一行为什么完全不变？
不加掩码时，“红”把 40% 给“小猫”、40% 给“球”。“球”的 value 是 \((0, 0)\)，这 40% 什么也没取回。加了掩码，“红”看不到排在后面的“球”，缩放后的分数 \((1.41, 0, 0, -\infty)\) 经 softmax 变成 \((0.67, 0.16, 0.16, 0)\)：原来给“球”的权重大半转给了“小猫”，而“小猫”的 value 是 \((1, 0)\)，“会动”就从 \(0.40 + 0.10 = 0.50\) 涨到 \(0.67 + 0.16 = 0.84\)（后一项来自“追”），颜色只来自“红”自己的 0.16。“球”排在最后，掩码只屏蔽它后面的位置，而它后面没有词，所以这一行和不加掩码时一样。
2. 把 \(d_h\) 从 128 提到 512、仍然不缩放，softmax 会怎样？除以 \(\sqrt{d_h}\) 之后呢？
点积的标准差从 \(\sqrt{128}\approx 11.3\) 变成 \(\sqrt{512}\approx 22.6\)。16 个分数里最大和次大的平均差距跟着翻倍，从约 5.4 到约 10.9，按平均差距算，权重之比从约 200 倍变成约 \(e^{10.9}\approx 5\times 10^4\) 倍：分布更接近独热，饱和更严重。演示里 \(d_h = 512\)、不缩放时，梯度≈0 的 query 从 43% 升到 71%，最大权重平均 95%。除以 \(\sqrt{d_h}\) 之后标准差回到 1，和维度无关：没有 query “死掉”，最大权重平均约 24%。
3. 为什么归纳头至少需要两层？如果只有一层注意力，看到第二个“哈利”时，它最可能预测出什么？
一层时，每个位置的 key 只含它自己的 token 和位置，没有“我前面是谁”的信息。分数能表达“找和我一样的 token”，于是找到前面那个“哈利”本身，把“哈利”复制过来，预测下一个还是“哈利”。要找到“前一个 token 是哈利的位置”（即“波特”），需要第一层的前一个 token 头先把“哈利”写进“波特”的位置，第二层的归纳头再用它的 key 去匹配。
4. \(d = 4096\) 的模型，序列多长时，一层里注意力的计算量（\(4n^2d\)）开始超过投影与 MLP（\(24nd^2\)）？到 32K 时注意力约是后者的几倍？
令 \(4n^2d = 24nd^2\)，得 \(n = 6d = 24576\)，约 2.5 万个 token。到 \(n = 32768\) 时，比值是 \(4n^2d / 24nd^2 = n/(6d) = 32768/24576 \approx 1.33\) 倍。这里按标准多头算；用 GQA 时投影更小，交叉点会提前一些。几千 token 的日常对话里，大头仍是线性层；长上下文时，平方项才变成主角。

注意力让每个位置都能看到所有位置，但它对顺序完全不敏感：“小猫追红球”和“红球追小猫”在它看来一样。它也只是加权平均，缺少对每个位置的非线性加工；一层又不够（归纳头至少要两层），层一深就难训练。下一章（第 章）把注意力、MLP、归一化、残差连接和位置编码拼成一个完整的 Transformer 块。
