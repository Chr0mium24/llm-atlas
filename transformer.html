Transformer：注意力、MLP、归一化、残差和位置编码怎样拼成一个块

大模型的主体是同一种“块”堆几十到上百层，注意力只是块的一半。这一章先用一个 4 维的玩具向量把一个块从头算到尾，再讲清残差连接、MLP、归一化和位置编码各自为什么是现在的样子。要回答的问题是：今天的块为什么长这样，而不是 2017 年的样子？

上一章的注意力让每个位置能从其它位置收集信息，但它留下了三个问题：只有一层不够，层一深就难训练；注意力本质上只是加权平均，缺少逐位置的非线性加工；它对顺序完全不敏感。这一章的部件分别回答这三个问题。
  • Q/K/V 注意力、多头、因果掩码、梯度消失：第 章
  • 嵌入、softmax、logit：第 章
  • 矩阵乘法、激活函数、梯度与链式法则、雅可比矩阵、初始化：
  • 不需要事先了解 Transformer 的其它部件。「从零开始」一节用一个 4 维向量把一个块完整算一遍。

一个块里有什么

今天的大语言模型几乎都是只有解码器（decoder-only）的 Transformer：只用带因果掩码的自注意力，任务统一成“预测下一个 token”。整个模型是：词嵌入 → 同一种Transformer 块重复 \(L\) 次 → 最后一次归一化 → 输出层得到 logit。每个块内部有两个子层，前后各一次归一化和残差相加：

\[ \htmlClass{sym-h}{\mathbf h} = \htmlClass{c-dir}{\mathbf x} + \htmlClass{sym-attn}{\operatorname{Attn}}\big(\htmlClass{sym-norm}{\operatorname{Norm}}(\mathbf x)\big),\qquad \htmlClass{sym-xp}{\mathbf x'} = \htmlClass{c-dir}{\mathbf h} + \htmlClass{sym-mlp}{\operatorname{MLP}}\big(\operatorname{Norm}(\mathbf h)\big) \]
先归一化，再做注意力，结果加回原向量；再归一化，过 MLP，结果再加回去。每个子层都只是在原向量上做“增量修改”。
\(\mathbf h\)
注意力子层之后的中间结果
\(\operatorname{Attn}\)
多头因果自注意力（第 章），唯一在位置之间交换信息的部件
\(\operatorname{Norm}\)
归一化（RMSNorm），把向量缩放到固定的尺度，见下文
\(\operatorname{MLP}\)
逐位置的前馈网络，每个位置独立计算，见下文
\(\mathbf x'\)
这个块的输出，作为下一个块的输入
Llama 3 8B：\(L = 32\) 个块，每个位置的向量 \(d = 4096\) 维。一个 token 从嵌入到输出要经过 32 次注意力、32 次 MLP、65 次归一化和 64 次残差相加。

这是 2023 年以后的“现代标准块”（Llama 风格）：Pre-RMSNorm、RoPE、SwiGLU，注意力用 GQA（分组查询注意力：多个 query 头共用一组 K、V 头，KV 缓存按比例缩小，见第 章「放回大模型」）。下一节先不问为什么，用一个玩具把这个块完整算一遍；之后各节依次解释残差、MLP、归一化和位置编码。

从零开始：一个向量穿过一个块

用一个小到可以手算的例子。隐藏维度（hidden dimension，每个位置上向量的维数）取 \(d = 4\)；输入只有三个 token“今天 / 天气 / 很”，我们跟踪最后一个位置“很”，它的向量最终要用来预测下一个 token（“好”“冷”……）。本章把向量写成行向量，矩阵乘在右边：\(\mathbf xW\)。所有数字都是挑过的玩具值，只为好算；真实模型的 \(d\) 有几千，数值由训练得到。

第 0 步：嵌入，残差流的起点

模型的第一步是查表：词表里每个 token 对应嵌入矩阵的一行（第 章）。“很”取出的向量是

\[ \mathbf x = (2,\ 0,\ -1,\ 1) \]

从这里开始，这个位置上始终只有一条 4 维向量。块里的每个子层都从它读取信息，再把算出的修改量加回去。这条被反复读写的向量，就是下文要正式定义的残差流。另外两个位置也各有自己的一条，同时在做同样的计算。

第 1 步：归一化，只改大小、不改方向

注意力之前先做一次归一化。现代模型用 RMSNorm：把向量除以它的均方根（root mean square，各分量平方的平均值再开方）：

\[ \begin{aligned} \operatorname{RMS}(\mathbf x) &= \sqrt{\tfrac14\big(2^2 + 0^2 + 1^2 + 1^2\big)} = \sqrt{1.5} \approx 1.22\\ \mathbf u &= \mathbf x / 1.22 = (1.63,\ 0,\ -0.82,\ 0.82) \end{aligned} \]

\(\mathbf u\) 和 \(\mathbf x\) 方向相同，只是被缩放到“每维典型大小约为 1”。（真实的 RMSNorm 还要逐维乘一组学到的系数，这里取全 1。）关键在于：被缩放的是送进注意力的副本 \(\mathbf u\)，\(\mathbf x\) 本身原样保留。为什么这样安排，见「归一化」一节。

第 2 步：注意力，从别的位置搬来信息，再加回去

第 章讲过注意力怎样算：“很”的 query 和三个位置的 key 做点积、softmax，得到三个权重；再按权重把各位置交出的内容（value 乘上输出矩阵 \(W_O\) 之后的向量）加起来。这里直接用结果（这三个权重是由“很”归一化后的 \(\mathbf u\) 算出的 query，和三个位置各自归一化后算出的 key 做点积、softmax 得到的）：设权重是“今天”0.2、“天气”0.7、“很”0.1，三个位置交出的内容分别是 \((0, 0, 2, 0)\)、\((0, 2, 0, -1)\)、\((1, 0, 0, 0)\)：

\[ \mathbf a = 0.2\,(0, 0, 2, 0) + 0.7\,(0, 2, 0, -1) + 0.1\,(1, 0, 0, 0) = (0.1,\ 1.4,\ 0.4,\ -0.7) \]

“天气”的权重最大，它的信息（主要在第 2 维）被搬到了“很”的位置上。然后把 \(\mathbf a\) 加回原来的向量：

\[ \mathbf h = \mathbf x + \mathbf a = (2,\ 0,\ -1,\ 1) + (0.1,\ 1.4,\ 0.4,\ -0.7) = (2.1,\ 1.4,\ -0.6,\ 0.3) \]

是“加回”，不是“替换”：\(\mathbf h\) 里完整地含着 \(\mathbf x\)，注意力只是在上面叠了一层修改。

第 3 步：MLP，升维、激活、降维

第二个子层是一个两层的全连接网络，叫 MLP，它只看当前这一个位置。先对 \(\mathbf h\) 再做一次归一化：\(\operatorname{RMS}(\mathbf h) = \sqrt{6.82/4} \approx 1.31\)，\(\mathbf u' = (1.61,\ 1.07,\ -0.46,\ 0.23)\)。然后分三步：

  • 升维。乘一个 \(4\times 8\) 的矩阵 \(W_1\)，4 维变 8 维。\(W_1\) 的每一列可以看成一个“键” \(\mathbf k_i\)，分数 \(z_i = \mathbf u'\cdot\mathbf k_i\) 衡量 \(\mathbf u'\) 和这个键有多吻合。例如 \(\mathbf k_1 = (0, 1, 0, 1)\)，\(z_1 = 1.07 + 0.23 = 1.30\)。8 个分数是 \(\mathbf z = (1.30,\ 1.38,\ -1.53,\ -1.61,\ 0.69,\ 0.54,\ -0.46,\ -0.31)\)。
  • 激活。逐个元素过一个非线性的激活函数。原版用 ReLU \(\max(0, z)\)：负的变成 0，得到 \((1.30,\ 1.38,\ 0,\ 0,\ 0.69,\ 0.54,\ 0,\ 0)\)。8 个键里只有 4 个被激活。
  • 降维。乘一个 \(8\times 4\) 的矩阵 \(W_2\)，回到 4 维。\(W_2\) 的第 \(i\) 行是一个“值” \(\mathbf v_i\)。结果是被激活的键按分数把对应的值加起来；这里 \(\mathbf v_1 = (0, 0, 0, 0.5)\)、\(\mathbf v_2 = (-0.25, 0, 0, 0)\)、\(\mathbf v_5 = (0, 0.5, 0, 0)\)、\(\mathbf v_6 = (0, 0, -0.5, 0.5)\)：\[ \mathbf m = 1.30\,\mathbf v_1 + 1.38\,\mathbf v_2 + 0.69\,\mathbf v_5 + 0.54\,\mathbf v_6 = (-0.34,\ 0.34,\ -0.27,\ 0.92) \]

最后同样加回去，得到这个块的输出：

\[ \begin{aligned} \mathbf x' = \mathbf h + \mathbf m &= \underbrace{(2,\ 0,\ -1,\ 1)}_{\text{嵌入}\ \mathbf x} + \underbrace{(0.1,\ 1.4,\ 0.4,\ -0.7)}_{\text{注意力}\ \mathbf a} + \underbrace{(-0.34,\ 0.34,\ -0.27,\ 0.92)}_{\text{MLP}\ \mathbf m} \\ &= (1.76,\ 1.74,\ -0.87,\ 1.22) \end{aligned} \]

这就是一个块的全部计算。残差流从头到尾只被加了两次，从没被覆盖：输出 \(\mathbf x'\) 恰好是嵌入、注意力、MLP 三份贡献之和。真实模型把这个块重复 \(L\) 次，每个块的输入是上一个块的输出，最后一个块之后再归一化一次，乘输出矩阵得到词表上的 logit。下面的演示把上面这几步拆成 9 帧，左图是残差流的组成：

残差连接：让梯度能穿过一百层

玩具里的两次“加回去”就是残差连接（He 等, 2015）：一个子层 \(F\) 不直接输出新向量，而是输出一个修改量，加到输入上：

\[ \htmlClass{sym-x}{\mathbf x_{l+1}} = \htmlClass{c-dir}{\mathbf x_l} + \htmlClass{c-adv}{\htmlClass{sym-F}{F_l}(\mathbf x_l)}\quad\Longrightarrow\quad \frac{\partial \mathcal L}{\partial \mathbf x_l} = \frac{\partial \mathcal L}{\partial \mathbf x_L}\prod_{k=l}^{L-1}\Big(\htmlClass{c-dir}{I} + \htmlClass{sym-J}{\frac{\partial F_k}{\partial \mathbf x_k}}\Big) \]
每一层的输出 = 原样传下去的输入 + 这一层算出来的修改。反向传播时，每层的雅可比矩阵都是“单位矩阵 + 子层的雅可比”，所以梯度总有一条不经过任何乘法衰减的直通路径。
\(\mathbf x_l\)
第 \(l\) 层的输入向量
\(F_l\)
第 \(l\) 层的子层（注意力或 MLP，含归一化）
\(\partial F_k/\partial\mathbf x_k\)
子层的雅可比矩阵：输入微小变化时，输出怎样变化
48 层，每层把梯度缩小到 0.9 倍。没有残差：\(0.9^{48}\approx 0.006\)，第一层几乎收不到梯度。有残差：展开连乘，其中“全部取 \(I\)”的那一项就是 \(\partial\mathcal L/\partial\mathbf x_L\) 本身，原封不动地到达第一层。

由此产生理解 Transformer 的一个重要视角：每个位置上有一条贯穿所有层的向量，叫残差流（residual stream）。注意力和 MLP 都不替换它，只是从中读取信息、算完再写回去。注意力负责把别的位置的信息搬到当前位置，MLP 负责在当前位置内部加工；所有层共享这条“总线”，后面的层可以读到前面任何一层写入的内容。把玩具里的 \(\mathbf x' = \mathbf x + \mathbf a + \mathbf m\) 推广到 \(L\) 个块：

\[ \htmlClass{sym-xo}{\mathbf x_{\text{out}}} = \htmlClass{c-dir}{\htmlClass{sym-x0}{\mathbf x_0}} + \htmlClass{c-adv}{\sum_{j=1}^{2L}\htmlClass{sym-D}{\Delta_j}},\qquad \text{logit} = \operatorname{Norm}(\mathbf x_{\text{out}})\,\htmlClass{sym-WU}{W_U} \]
最后一个块之后的残差流 = 嵌入 + 所有子层写入的修改之和。输出层读的就是这个和：每一层的写入都直达输出，中间没有哪一步会把它擦掉。
\(\mathbf x_0\)
嵌入向量，残差流的起点
\(\Delta_j\)
第 \(j\) 个子层（注意力或 MLP）加进残差流的修改量；一个块两个，\(L\) 个块共 \(2L\) 个
\(\mathbf x_{\text{out}}\)
最后一个块的输出
\(W_U\)
输出矩阵（\(d\times V\)，是第 章里 \(W_U\) 的转置，因为本章用行向量），把向量变成词表上 \(V\) 个 logit
玩具块：三份贡献分别是 \((2, 0, -1, 1)\)、\((0.1, 1.4, 0.4, -0.7)\)、\((-0.34, 0.34, -0.27, 0.92)\)。归一化只是整体除以一个数（这里 1.45），所以 logit 也能拆成三份之和：嵌入直接贡献多少、注意力贡献多少、MLP 贡献多少。把 logit 拆成各子层贡献之和，叫直接 logit 归因（direct logit attribution）；同一个线性性也让 logit lens 成立：把中间某层的部分和直接乘 \(W_U\)，看模型此刻想说哪个词（第 章）。
残差流为什么像一条总线

第 1 步，读是线性的。第 \(j\) 个子层要用之前的信息，它读到的是 \(\operatorname{Norm}(\mathbf x_j)\) 再乘自己的矩阵 \(W\)（例如 \(W_Q\) 或 \(W_1\)）。RMSNorm 只是除以一个标量 \(r_j\) 再逐维乘系数（相当于乘一个对角矩阵 \(\operatorname{diag}(\mathbf g)\)），所以：

\[ \begin{aligned} \operatorname{Norm}(\mathbf x_j)\,W &= \frac{1}{r_j}\Big(\mathbf x_0 + \sum_{i<j}\Delta_i\Big)\operatorname{diag}(\mathbf g)\,W \\ &= \frac{1}{r_j}\Big(\mathbf x_0 W' + \sum_{i<j}\Delta_i W'\Big),\qquad W' = \operatorname{diag}(\mathbf g)\,W \end{aligned} \]

读出来的是每一份写入各自经过 \(W'\) 之后的和，整体再乘 \(1/r_j\)。

第 2 步，写在不同方向上就互不干扰。设第 3 层把某个信息写在方向 \(\mathbf e\) 上（\(\Delta_3 = c\,\mathbf e\)），第 20 层只要让 \(W'\) 的某一列与 \(\mathbf e\) 对齐，就能读出 \(c\)（再乘 \(1/r_{20}\)）。中间 16 层写了什么都不影响这次读取，只要它们写的方向与 \(\mathbf e\) 近似正交。\(d\) 维空间里严格正交的方向只有 \(d\) 个，但两两夹角接近 90° 的方向，数量随 \(d\) 指数增长，远多于 \(d\) 个；这是叠加的几何基础（第 章）。

第 3 步，删除要专门做。在这个框架里，没有哪个子层会“顺便”覆盖旧内容。想删掉 \(c\,\mathbf e\)，某一层必须专门写入它的相反数 \(-c\,\mathbf e\)。

对比 Post-Norm（原版的做法，下文详述）：\(\mathbf x_{l+1} = \operatorname{Norm}(\mathbf x_l + F_l)\)，每层之后整个向量被重新缩放。若每层写入的大小与残差流相当，第 3 层写入的内容在向量里的占比每过一层缩小约 \(1/\sqrt 2\)，到第 20 层只剩 \((1/\sqrt2)^{17}\approx 1/360\)。

这个推导告诉我们：Pre-Norm 结构下，残差流是一条“只追加”的总线：任何一层的写入都以原样的绝对大小到达后面所有层和输出层；但残差流越来越长，它的相对份额会下降（见「归一化」一节的 PreNorm 稀释）。logit lens 这类工具因此成立；“删掉后面一半的层性能下降不多”的实验也说明，很多层的写入可以单独去掉而不破坏其它层。它还解释了 2026 年 Attention Residuals 的出发点：既然输出是各层写入的等权和 \(\mathbf x_0 + \sum\Delta_j\)，把等权换成学到的权重就是自然的下一步（见下文）。代价是所有层共用 \(d\) 维的带宽。

不过，残差连接只保证梯度有路可走，不保证大小合适。展开连乘 \(\prod_k(I + J_k)\)，“全部走直通”的那一项恒为 1，所以梯度不会消失；但它还有 \(2^{L-l}\) 条经过分支的路径，每个分支若在初始化时就把梯度放大一点，这些路径加起来随层数指数增长：每层约乘 \(\sqrt{1+\sigma^2}\)（\(\sigma\) 是分支的典型放大倍数）。“有直通路径”和“梯度爆炸”并不矛盾，直通项管下限，不管上限。GPT-2 的做法是在初始化时把每个残差分支的输出层缩小 \(1/\sqrt{2L}\) 倍，让所有分支加起来的扰动有界。下面的演示用真实的随机矩阵相乘比较三种结构，默认看“加残差”：48 层、\(\sigma = 0.9\) 时，第 1 层的梯度约 \(6\times10^5\)；切到“残差 + 分支缩小”，回到 1 附近。

展开连乘：残差网络像很多浅网络的集成

把 \(\prod_{k}(I + J_k)\) 展开，每一项对应“在每一层选择走直通（\(I\)）还是走分支（\(J_k\)）”：

\[ \prod_{k=l}^{L-1}(I + J_k) = I + \sum_{k} J_k + \sum_{k<k'} J_{k'}J_k + \cdots + J_{L-1}\cdots J_l \]

\(L - l\) 层一共有 \(2^{L-l}\) 条路径，经过 \(m\) 个分支的路径有 \(\binom{L-l}{m}\) 条。如果每个 \(J_k\) 的典型大小小于 1，经过分支越多的路径贡献越小，梯度主要来自只经过少数几个分支的“短路径”。Veit 等（2016）在 ResNet 上验证了这一点：随机删掉一层，性能只略微下降，因为大部分路径并不经过它；而普通的深层网络删掉任何一层都会崩溃。

这个推导告诉我们：残差网络的有效深度远小于名义层数。这既是它好训练的原因，也提示深层可能没有被充分利用，这一点在下一节的 Pre-Norm 中会再次出现。

MLP：逐位置的加工与“键值记忆”

注意力给定权重之后，输出只是 value 的线性组合：softmax 决定从哪里取，不对取来的内容做逐维加工。每个块的第二个子层是一个两层的全连接网络，叫前馈网络（FFN，也常叫 MLP）。它对每个位置独立计算，不看其它位置。原版 Transformer 的写法是：

\[ \operatorname{FFN}(\mathbf x) = \htmlClass{sym-phi}{\phi}\big(\mathbf x\,\htmlClass{sym-W1}{W_1}\big)\,\htmlClass{sym-W2}{W_2}\qquad\longrightarrow\qquad \operatorname{SwiGLU}(\mathbf x) = \Big(\operatorname{SiLU}(\mathbf x W_1)\ \htmlClass{c-new}{\odot\ \mathbf x\,\htmlClass{sym-W3}{W_3}}\Big)\,W_2 \]
先把 \(d\) 维放大到 \(d_{\text{ff}}\) 维，过一个非线性函数，再压回 \(d\) 维。右边是 2023 年以后的标准：多一个矩阵 \(W_3\)，它的输出和激活结果逐元素相乘，两支互相门控。
\(W_1\)
\(d\times d_{\text{ff}}\)，升维；原版 \(d_{\text{ff}} = 4d\)
\(\phi\)
激活函数：原版用 ReLU \(\max(0, z)\)，GPT-1、BERT（2018）起用更平滑的 GELU
\(W_2\)
\(d_{\text{ff}}\times d\)，降维回到残差流
\(W_3\)
\(d\times d_{\text{ff}}\)，线性分支（代码里叫 up_proj），与 \(\operatorname{SiLU}(\mathbf xW_1)\)（gate_proj）逐元素相乘；有了它，SwiGLU 有三个矩阵，所以 \(d_{\text{ff}}\) 通常取约 \(\tfrac83 d\)，使总参数仍是 \(8d^2\)
\(\operatorname{SiLU}(z) = z\cdot\sigma(z)\)（\(\sigma\) 是 sigmoid）。\(\operatorname{SiLU}(2) = 2\times 0.88 = 1.76\)，\(\operatorname{SiLU}(-2) = -2\times 0.12 = -0.24\)。如果对应的门 \(\mathbf xW_3\) 那一维是 0，不管激活值多大，这一维的输出都是 0；门是 \(-1\)，输出就反号。两个线性投影相乘，让 MLP 能表达“当 A 且 B 时”这类乘法关系。

这种带门的结构叫SwiGLU（Shazeer, 2020）。在参数量相同时，它比 ReLU / GELU 版本效果稍好且稳定，PaLM 和 LLaMA 之后成为默认选择。论文作者坦言无法从理论上解释为什么它更好，这是典型的经验驱动的改进。

SwiGLU 为什么取 8/3·d，门又多给了什么

第 1 步，对齐参数量。原版 MLP 两个矩阵：\(2\cdot d\cdot 4d = 8d^2\)。SwiGLU 三个矩阵：\(3\cdot d\cdot d_{\text{ff}}\)。令两者相等：

\[ 3\,d\,d_{\text{ff}} = 8\,d^2\quad\Longrightarrow\quad d_{\text{ff}} = \tfrac83\,d \]

计算量也随之对齐：每个 token 前向 \(2\times 3\,d\,d_{\text{ff}} = 16d^2\)，与原版的 \(2\times 8d^2\) 相同。比较两种结构必须在同样的参数量和计算量下比，否则“更好”可能只是因为“更大”。

第 2 步，取整。\(\tfrac83 d\) 一般不是整数，还要凑成硬件友好的倍数。LLaMA 7B 与 Llama 2 7B：\(d = 4096\)，\(\tfrac83 d\approx 10923\)，向上取到 256 的倍数得 11008。Llama 3 8B 在此基础上再乘 1.3、取到 1024 的倍数，得 14336 \(= 3.5d\)：它有意让 MLP 比“等参数”多约 30%。

第 3 步，门带来的乘法。看 SwiGLU 的第 \(i\) 个隐藏单元：\(\operatorname{SiLU}(\mathbf x\cdot\mathbf k_i)\,(\mathbf x\cdot\mathbf k'_i)\)，\(\mathbf k_i\)、\(\mathbf k'_i\) 分别是 \(W_1\)、\(W_3\) 的第 \(i\) 列。在 0 附近 \(\sigma(z)\approx \tfrac12\)，\(\operatorname{SiLU}(z)\approx z/2\)，于是

\[ \operatorname{SiLU}(\mathbf x\cdot\mathbf k_i)\,(\mathbf x\cdot\mathbf k'_i) \approx \tfrac12\,(\mathbf x\cdot\mathbf k_i)(\mathbf x\cdot\mathbf k'_i) = \tfrac12\,\mathbf x\,\big(\mathbf k_i\,\mathbf k_i'^{\top}\big)\,\mathbf x^\top \]

这是输入 \(\mathbf x\) 的二次型：一个单元就能表示“特征 A 和特征 B 同时出现”。ReLU 单元 \(\max(0, \mathbf x\cdot\mathbf k_i)\) 是分段线性的，要靠多个单元组合才能近似乘法。

这个推导告诉我们：\(\tfrac83\) 不是调出来的魔数，而是“参数量不变”的直接结果。SwiGLU 用少三分之一的隐藏单元（\(\tfrac83 d\) 对 \(4d\)），换来每个单元的乘法交互；为什么这种交互对语言特别有用，至今没有理论解释。

MLP 占了每层约三分之二的参数。它存了什么？「从零开始」里的 \(\mathbf m = 1.30\,\mathbf v_1 + 1.38\,\mathbf v_2 + \cdots\) 已经给出了读法。把 \(W_1\) 的第 \(i\) 列看成一个“键” \(\mathbf k_i\)，\(W_2\) 的第 \(i\) 行看成一个“值” \(\mathbf v_i\)，矩阵乘法按中间维度展开：

\[ \operatorname{FFN}(\mathbf x) = \sum_{i=1}^{d_{\text{ff}}} \phi(\mathbf x\cdot\mathbf k_i)\ \mathbf v_i \]

当前向量和哪些键吻合，就把对应的值按吻合程度加进残差流。这和注意力 \(\mathbf o = \sum_j \operatorname{softmax}_j(\mathbf q\cdot\mathbf k_j)\,\mathbf v_j\) 几乎是同一个形式，区别有两处：注意力的键值来自上下文里的其它 token，MLP 的键值是训练时学到、固定在参数里的；MLP 用逐个元素的激活函数而不是 softmax，很多键可以同时被激活（玩具里 8 个键激活了 4 个），也可以都不激活。一句话：注意力从上下文里检索，MLP 从参数里检索。

这个读法也回答了“为什么要先放大 4 倍再压回来”：\(d_{\text{ff}}\) 就是记忆条目的个数。放大到 \(4d\)，意味着每层有 \(4d\) 个键值对可用，而计算量仍只随 \(d\cdot d_{\text{ff}}\) 线性增长；4 这个倍数本身是原版论文的经验取值，没有理论推导。Geva 等（2021）检查训练好的模型：低层 MLP 的键常对应浅层文字模式（例如“以某个词结尾的句子”），高层的键对应语义主题；值向量投到词表上，会抬高某些下一个 token 的概率。之后的知识编辑方法 ROME（Meng 等, 2022）先用“因果追踪”定位出存放某条事实的中间层 MLP，再只改那一层的一个秩 1 部分，就能把“埃菲尔铁塔在巴黎”改成“在罗马”。所以常说“知识存在 MLP 里”；MoE 把 MLP 拆成很多专家来扩大参数容量，出发点也在这里（第 章）。这句话有多准确，见下面的争议框。

知识真的存放在 MLP 的某个位置吗

主张
因果追踪（causal tracing）可以定位到存储某条事实的中间层 MLP，在那里修改权重就能改掉这条事实（ROME, 2022）。
反方
Hase 等（2023）发现，定位结果并不能预测在哪一层编辑效果最好：在“没有定位到”的层编辑，往往同样有效。编辑一条事实还常常连带改坏相关事实，或者换个问法就失效。
现在怎么看
知识是分布式存放的，并以叠加（superposition）的方式共用同一批神经元（第 章）。“某条知识在某一层”是有用的近似，不是精确描述。

归一化：放在哪里比用哪种更重要

深层网络里，向量的大小会随层数漂移：某些层输出越来越大，某些越来越小，训练随之不稳定。层归一化（LayerNorm, 2016）对每个位置的向量单独做标准化；RMSNorm（2019）把它简化成只除以均方根：

\[ \operatorname{LayerNorm}(\mathbf x) = \htmlClass{sym-g}{\mathbf g}\odot\frac{\mathbf x - \htmlClass{sym-mu}{\mu}}{\sqrt{\htmlClass{sym-s2}{\sigma^2} + \epsilon}} + \mathbf b,\qquad \operatorname{RMSNorm}(\mathbf x) = \mathbf g\odot\frac{\mathbf x}{\sqrt{\htmlClass{c-new}{\tfrac1d\sum_i x_i^2} + \epsilon}} \]
LayerNorm：减去均值、除以标准差，再乘一组可学习的缩放系数。RMSNorm：不减均值，也不加偏置，只除以均方根，计算更省，效果几乎一样。

\(\mathbf x = (1, 2, 3, 6)\)。LayerNorm：\(\mu = 3\)，\(\sigma^2 = (4+1+0+9)/4 = 3.5\)，\(\sigma = 1.87\)，结果 \((-1.07,\ -0.53,\ 0,\ 1.60)\)。RMSNorm：均方根 \(\sqrt{(1+4+9+36)/4} = 3.54\)，结果 \((0.28,\ 0.57,\ 0.85,\ 1.70)\)。两者都把向量缩放到“每维约为 1”的尺度。

比用哪种归一化更关键的，是放在残差的哪一侧。原版 Transformer 是 Post-Norm：先相加再归一化；GPT-2 把 Pre-Norm 带进了大语言模型（此前翻译模型里已有人使用）：只对子层的输入归一化，残差路径上不做任何处理：

\[ \begin{aligned} \text{Post-Norm:}\quad \mathbf x_{l+1} &= \htmlClass{c-new}{\htmlClass{sym-N}{\operatorname{Norm}}}\big(\mathbf x_l + \htmlClass{sym-F}{F}(\mathbf x_l)\big)\\ \text{Pre-Norm:}\quad \mathbf x_{l+1} &= \mathbf x_l + F\big(\htmlClass{c-new}{\operatorname{Norm}}(\mathbf x_l)\big) \end{aligned} \]
区别只在 Norm 套在哪里。Post-Norm 归一化“相加的结果”，残差流每层都被重新缩放；Pre-Norm 只归一化送进子层的副本，残差流本身只做加法。

Post-Norm 的症状是：不预热就发散。训练开头要做学习率预热（warmup），前几千步把学习率从接近 0 逐步升到目标值，原版 Transformer 用了 4000 步。原因不在“梯度消失”，而在输出附近：初始化时，Post-Norm 靠近输出的几层参数梯度很大，而且不随层数变小；Pre-Norm 的最后一次归一化要除以很长的残差流，把这份梯度压小了约 \(\sqrt L\) 倍（Xiong 等, 2020）。同样的学习率，Post-Norm 这几层一步走得远得多；而 Adam 在最初几步对梯度尺度的估计还不准，两者叠加就容易发散。预热就是先把步长压小，等优化器的统计量稳定下来。Pre-Norm 因此可以不预热也训得动（实践中大多仍保留一段较短的预热）。

下面的演示用真实的 LayerNorm 前向和反向，比较两种结构在初始化时的梯度。默认页是每层参数的梯度：24 层时，最后一层 Post-Norm 约 3.1、Pre-Norm 约 1.0，差约 3 倍，把层数拖大差距还会变大。第二页是传到每层的梯度：Post-Norm 只走直通路径的那一份几乎消失（24 层只剩约 \(2\times10^{-3}\)），但总梯度并不消失，因为分支也在传梯度。

为什么 Post-Norm 难训练、需要学习率预热

第 1 步，直通路径。Pre-Norm 中，\(\mathbf x_{l+1} = \mathbf x_l + \cdots\)，直通路径的雅可比恰好是 \(I\)，与上一节完全一样。Post-Norm 中，直通路径每层都要穿过一次归一化。初始化时，若 \(\mathbf x_l\) 和 \(F(\mathbf x_l)\) 每维方差都约为 1 且互不相关，它们的和方差约为 2，归一化要除以 \(\sqrt 2\)。于是只走直通路径的梯度每层缩小约 \(1/\sqrt2\)：

\[ \Big\|\frac{\partial\mathbf x_L}{\partial\mathbf x_l}\Big\|_{\text{只走直通}} \approx \Big(\frac{1}{\sqrt 2}\Big)^{L-l} \]

24 层就是 \(2^{-12}\approx 1/4096\)（演示第一页的橙色虚线）。

第 2 步，总梯度不一定消失。梯度还可以走分支。Post-Norm 每层完整的雅可比是“归一化的雅可比 × \((I + J_F)\)”。若分支的雅可比也大致保持向量的大小（随机初始化时就是这样），\(I + J_F\) 把梯度放大约 \(\sqrt 2\)，正好抵消归一化的 \(1/\sqrt 2\)：演示里 Post-Norm 的总梯度（实线）几乎不衰减。Liu 等（2020）在真实的 Transformer 上也发现，Post-Norm 的编码器没有梯度消失，只有解码器里接收编码器输出的那些子层有。区别在于：Post-Norm 的梯度全靠分支传递，分支在训练中一旦不再“保持大小”，就没有东西兜底；Pre-Norm 的恒等路径保证每层至少收到输出端的那一份。

第 3 步，输出附近的梯度。Xiong 等（2020）证明了与预热更直接相关的一点：初始化时，Post-Norm 最后几层参数的梯度大小与层数 \(L\) 无关；Pre-Norm 的则约按 \(1/\sqrt L\) 缩小，因为最后一次归一化要除以残差流的长度，而残差流的长度随层数增长（理想情况下按 \(\sqrt L\)，演示第三页）。同样的学习率下，Post-Norm 输出附近的参数一步走得大好几倍。而 Adam（按每个参数梯度的历史大小自动调整步长的优化器）在训练最初几步对梯度尺度的估计还不准，两者叠加，大学习率就容易发散。预热让最初几千步的步长足够小，等 Adam 的估计稳定下来。

第 4 步，参数改一点，输出变多少。Liu 等（2020）从另一个角度看：Post-Norm 每层都把残差和分支等量地混在一起，输出对每一层的参数都同样敏感；所有参数各扰动一点，输出变化的方差随层数线性累积，是 \(O(L)\)。Pre-Norm 第 \(l\) 层的写入在残差流里只占约 \(1/\sqrt l\)，累积起来只有 \(O(\log L)\)。他们认为这种“放大效应”才是 Post-Norm 不稳定的主因，梯度消失不是。

这个推导告诉我们：Post-Norm 难训练，不是因为“梯度一定消失”，而是因为它没有恒等路径兜底、输出对每一层都同样敏感；Pre-Norm 用一条干净的恒等路径换来了稳定。代价是残差流本身从不被归一化，会随层数变长（演示第三页）。DeepNet（2022）走另一条路：保留 Post-Norm，但把残差乘一个大于 1 的系数 \(\alpha\)，\(\operatorname{Norm}(\alpha\mathbf x + F(\mathbf x))\)，让直通路径占主导，同时缩小分支的初始化，训练出了 1000 层的 Transformer。

Pre-Norm 也有代价：残差流本身从不归一化。每层的分支看到的是归一化后的输入，写入的大小大致固定；残差流却越加越长。在各层写入方向互不相关的理想情况下，长度按 \(\sqrt l\) 增长（演示第三页，玩具模型），越深的层写入的内容在残差流里占比越小、对输出的影响越弱。Sun 等（2025）认为真实训练中的增长比这更快。Kimi 的 Attention Residuals 论文把这个现象叫PreNorm 稀释（PreNorm dilution）。

深层贡献小，是冗余还是缺陷

主张
深层是冗余，可以直接剪掉。Gromov 等（2024）删掉 Llama 2 70B 后部近一半的层，再做少量微调修复，问答类任务的性能下降很小；残差网络本来就像很多浅网络的集成，少几层不要紧。
反方
深层是被结构浪费的。“深度的诅咒”（Sun 等, 2025）把原因归到 Pre-Norm：残差流越来越长，深层写入的份额越来越小，于是学不到东西。他们提出按 \(1/\sqrt l\) 缩放归一化输出；OLMo 2（2024）把归一化移到子层的输出上，Gemma 2/3 在子层前后各放一次（“夹心”归一化）；Kimi 的 Attention Residuals（2026）干脆改掉残差的求和方式（见下文）。
现在怎么看
Pre-Norm 仍是主流，“深层利用不足”这一现象已被广泛接受，分歧在于该剪还是该修。删层实验只测了部分任务，还不能说明深层本来就没用。

位置编码：注意力本身不知道顺序

回看「从零开始」：注意力只用到了三个位置的内容和权重，哪个 token 在前、哪个在后，计算里根本没有出现。注意力对输入顺序是置换等变的：把输入的 token 打乱，每个位置的输出只是跟着换位置，数值完全不变。“狗咬人”和“人咬狗”在它看来是同一组向量。第 章用两句词序相反的话演示过这一点，下面给出一般的证明。

不加掩码的注意力为什么是置换等变的

设 \(P\) 是一个置换矩阵（每行每列恰有一个 1），\(PX\) 就是把 \(X\) 的行打乱。由于 \(Q = XW_Q\)，打乱后 \(Q\to PQ\)，同理 \(K\to PK\)、\(V\to PV\)。分数矩阵变为 \(PQ(PK)^\top = P\,QK^\top P^\top\)，即行和列按同样方式重排。按行 softmax 与重排可以交换顺序，所以：

\[ \operatorname{softmax}\big(P\,QK^\top P^\top\big)\,PV = P\,\operatorname{softmax}(QK^\top)\,P^\top P\,V = P\cdot\operatorname{Attention}(Q, K, V) \]

（\(P^\top P = I\)。）MLP 和归一化逐位置计算，本来就与顺序无关。所以整个块是置换等变的：输出只是同样地被打乱。

这个推导告诉我们：如果不注入位置信息，模型完全无法区分顺序。例外是因果掩码：第 \(i\) 个位置恰好能看到 \(i\) 个 token，这本身就泄露了位置（见下面的意外框）。

所以需要另外注入位置编码。最直接的办法是给第 \(m\) 个位置一个向量 \(\mathbf p_m\)，加到嵌入上：

  • 正弦位置编码（2017）：\(\mathbf p_m\) 是固定的，各维是不同频率的正弦和余弦，\(\sin(m\,\omega_i)\)、\(\cos(m\,\omega_i)\)，\(\omega_i = 10000^{-2i/d}\)。同一组 \((\sin,\cos)\) 平移 \(k\) 个位置，恰好等于旋转一个固定角度 \(k\omega_i\)，原文据此期望模型能学会按相对位置注意。
  • 可学习的位置嵌入（BERT、GPT-2/3）：每个位置学一个向量。超出训练长度就没有对应的向量，无法外推。

毛病出在注意力分数里。位置向量和内容向量相加之后一起乘 \(W_Q, W_K\)，分数 \((\mathbf x_m+\mathbf p_m)M(\mathbf x_n+\mathbf p_n)^\top\)（\(M = W_QW_K^\top\)）展开成四项：内容-内容、内容-位置、位置-内容、位置-位置。中间两项各只含一个绝对位置，第四项在 \(M\) 是任意学到的矩阵时也不只依赖 \(m-n\)。也就是说，“只看相对位置”只是模型可能学到的一种特例，绝对位置一直混在分数里，模型得自己学会忽略它们。

加法的位置编码会在注意力分数里混入什么

设第 \(m\) 个位置的输入是内容加位置：\(\mathbf x_m + \mathbf p_m\)。记 \(M = W_QW_K^\top\)（\(d\times d\)），位置 \(m\) 对 \(n\) 的分数（省略 \(1/\sqrt{d_h}\)）展开成四项：

\[ \begin{aligned} s_{mn} &= (\mathbf x_m + \mathbf p_m)\,M\,(\mathbf x_n + \mathbf p_n)^\top \\ &= \underbrace{\mathbf x_m M\mathbf x_n^\top}_{\text{内容-内容}} + \underbrace{\mathbf x_m M\mathbf p_n^\top}_{\text{内容-位置}} + \underbrace{\mathbf p_m M\mathbf x_n^\top}_{\text{位置-内容}} + \underbrace{\mathbf p_m M\mathbf p_n^\top}_{\text{位置-位置}} \end{aligned} \]

中间两项各只含一个绝对位置（\(n\) 或 \(m\)），和“隔了多远”无关。再看第四项。如果 \(M = I\)：

\[ \mathbf p_m\mathbf p_n^\top = \sum_i\big[\sin m\omega_i\,\sin n\omega_i + \cos m\omega_i\,\cos n\omega_i\big] = \sum_i \cos\big((m-n)\,\omega_i\big) \]

只依赖 \(m - n\)，这正是正弦编码设计时期望的。但 \(M\) 是学出来的任意矩阵，它会把不同频率的分量交叉相乘，出现 \(\sin(m\omega_i)\cos(n\omega_j)\)（\(i\ne j\)）这类项，它们不是 \(m-n\) 的函数。所以加法编码下，“只看相对位置”只是模型可能学到的一种特例，绝对位置一直混在分数里。

两代修法各删掉了不同的东西。T5 删掉后三项，换成只依赖距离的标量：\(s_{mn} = \mathbf x_m M\mathbf x_n^\top + \operatorname{bias}(m-n)\)，位置与内容不再相互作用。RoPE 改成乘法：\(\mathbf q_m = \mathbf x_mW_Q\) 旋转 \(R_m\)，\(\mathbf k_n\) 旋转 \(R_n\)（行向量写法），分数只剩一项：

\[ s_{mn} = \mathbf x_m W_Q\,R_m^\top R_n\,W_K^\top\mathbf x_n^\top = \mathbf x_m W_Q\,R_{n-m}\,W_K^\top\mathbf x_n^\top \]

内容和相对位置相乘在一起，不含任何绝对位置。

这个推导告诉我们：位置编码的演进，是在一步步清理分数里的绝对位置项：正弦编码指望模型自己学会忽略它们；T5 用加法偏置把它们删掉，但牺牲了位置与内容的交互；RoPE 用旋转同时做到了“只看相对位置”和“与内容相乘”。原版论文已经指出“平移等于旋转”，RoPE 只是把这个旋转从输入挪到了每一层的 q、k 上。

两种修法各删掉了不同的东西。相对位置偏置（T5, 2019；ALiBi, 2021）删掉后三项，直接给分数加一个只依赖距离 \(m-n\) 的标量：T5 按距离分桶、每个桶学一个数，ALiBi 的偏置随距离线性变负、不用学。代价是位置与内容不能相互作用。RoPE（旋转位置编码，苏剑林等, 2021）换成乘法：不往向量上加东西，而是按位置旋转 query 和 key。把 \(d_h\) 维向量两两分组，看成 \(d_h/2\) 个二维平面，第 \(i\) 个平面按位置 \(m\) 旋转角度 \(m\theta_i\)。两个旋转后的向量做点积，结果只取决于它们的角度差，也就是相对位置，而且和内容相乘在一起：

\[ \big\langle \htmlClass{sym-R}{R_m}\,\mathbf q,\ R_n\,\mathbf k\big\rangle = \big\langle \mathbf q,\ R_{\htmlClass{c-new}{n-m}}\,\mathbf k\big\rangle,\qquad \htmlClass{sym-th}{\theta_i} = \htmlClass{sym-b}{\Theta}^{-2i/d_h} \]
位置 \(m\) 的 query 转了 \(m\theta\)，位置 \(n\) 的 key 转了 \(n\theta\)，点积只看两者之差 \(n-m\)：绝对位置自然地变成了相对位置。
\(R_m\)
按位置 \(m\) 旋转的矩阵：\(d_h/2\) 个二维旋转拼成的分块对角阵，第 \(i\) 块转 \(m\theta_i\)
\(\theta_i\)
第 \(i\) 个平面的旋转频率，\(i = 0, 1, \dots, d_h/2 - 1\)。\(i\) 小的转得快，\(i\) 大的转得慢
\(\Theta\)
base（频率的底），原版取 10000；越大，最慢的那些平面转得越慢。\(d_h\) 是每个头的维数
一个平面，\(\theta = 0.5\)，\(\mathbf q = \mathbf k = (1, 0)\)。\(m = 5\)：q 转 2.5 弧度，变成 \((\cos 2.5, \sin 2.5)\)；\(n = 3\)：k 转 1.5 弧度。点积 \(= \cos(2.5 - 1.5) = \cos 1 \approx 0.54\)。把两者都后移 10 个位置（\(m = 15, n = 13\)），角度差仍是 1 弧度，点积不变。
第 1 步：把 query 和 key 的维度两两分组，每组看成一个二维平面。
第 2 步：位置 \(m\) 的 query，第 \(i\) 个平面旋转 \(m\theta_i\)；key 同理旋转 \(n\theta_i\)。value 不旋转：它是被搬运的内容，位置只需要影响“看谁”。
第 3 步：旋转矩阵满足 \(R_m^\top = R_{-m}\)、\(R_{-m}R_n = R_{n-m}\)，所以点积只依赖 \(n - m\)。

不同平面的频率差别很大：\(d_h = 128\)、\(\Theta = 10000\) 时，最快的平面每 6 个位置转一圈，用来分辨相邻的 token；最慢的平面要约 5 万个位置才转一圈，用来编码远距离。拖动下面的滑块验证“同时平移，点积不变”，并观察 base 对远程衰减的影响：

用复数看 RoPE，以及远程衰减从哪来

把第 \(i\) 个平面的两个分量看成一个复数 \(q^{(i)} = q_{2i} + \mathrm i\,q_{2i+1}\)。旋转 \(m\theta_i\) 就是乘以 \(e^{\mathrm i m\theta_i}\)。两个二维向量的点积等于 \(\operatorname{Re}[a\bar b]\)，所以：

\[ \operatorname{Re}\Big[q^{(i)}e^{\mathrm i m\theta_i}\ \overline{k^{(i)}e^{\mathrm i n\theta_i}}\Big] = \operatorname{Re}\Big[q^{(i)}\,\overline{k^{(i)}}\ e^{\mathrm i (m-n)\theta_i}\Big] \]

\(m\) 和 \(n\) 只以差的形式出现。完整的点积是 \(d_h/2\) 个平面之和。设 \(\mathbf q = \mathbf k\)（一个 token 和“自己的副本”比较），点积变成 \(\sum_i |q^{(i)}|^2\cos\big((m-n)\theta_i\big)\)。距离为 0 时所有余弦都是 1；距离增大，各平面的角度彼此错开，余弦有正有负、相互抵消，总和趋于 0。这就是 RoPE 的“远程衰减”：内容相同的两个 token，离得越远，匹配分数越低。base 越大，频率整体越低，衰减越慢。

这个推导告诉我们：RoPE 给模型的不只是“相对位置”，还有一个“越远越不相关”的先验。长上下文需要削弱这个衰减，所以要调大 base。

上下文扩展就是在改 RoPE。如果训练时只见过 8K 个位置，最慢的那些平面在训练中连一圈都没转完；推理时拉到 128K，它们会转到从没见过的角度，模型就乱了。几种修补方法：

  • 位置插值（PI, 2023）：把位置按比例压缩，\(m \to m\cdot n_{\text{train}}/n_{\text{test}}\)（训练长度除以目标长度），让所有角度都落回见过的范围。代价是相邻位置的角度差也被压小，分辨近距离变难。
  • NTK-aware 缩放与 YaRN（2023）：只压缩低频平面、保留高频平面，YaRN 还对注意力分数做温度修正。少量长文本微调即可把上下文扩大数倍到数十倍。
  • 直接调大 base：Llama 3 用 \(\Theta = 500{,}000\)，2025 年后的长上下文模型常用到数百万，配合分阶段的长文本继续训练（第 章）。

意外：不用位置编码也能工作

原以为
注意力是置换等变的，没有位置编码就分不清顺序，模型无法工作。
实际发现
Haviv 等（2022）发现，带因果掩码的语言模型去掉位置编码（NoPE，no positional encoding），效果只略差；Kazemnejad 等（2023）发现它在超出训练长度时外推得更好。原因是因果掩码：第 \(i\) 个位置只能看到 \(i\) 个 token，模型可以借此“数”出自己的位置。
为什么
位置信息不一定要显式给出，结构本身就隐含了它。只有双向的编码器（如 BERT）才真正离不开位置编码。
现在怎么看
大规模下完全不用位置编码仍然吃亏，但混合使用成了一种趋势：Llama 4（2025）的部分层不用 RoPE（iRoPE），SmolLM3 等也每隔几层放一个 NoPE 层。Kimi Linear（2025-10）和 Kimi K3（2026-07）走得更远：全注意力（MLA）层一律不用位置编码，位置信息交给与之混合的线性注意力层（它按顺序递推，天然知道先后）；K3 技术报告称它不做任何位置编码修改就直接外推到 100 万 token。

参数量和计算量

块里可学习的参数都在矩阵里。注意力有 \(W_Q, W_K, W_V, W_O\) 四个 \(d\times d\) 的矩阵；MLP 有升维的 \(W_1\)（\(d\times d_{\text{ff}}\)）和降维的 \(W_2\)（\(d_{\text{ff}}\times d\)），原版取 \(d_{\text{ff}} = 4d\)；归一化各有 \(d\) 个系数，可以忽略。计算量用FLOPs（浮点运算次数）衡量，一次乘法加一次加法记 2 FLOPs。

\[ \underbrace{4\,\htmlClass{sym-d}{d}^2}_{\text{注意力}} + \underbrace{2\cdot d\cdot \htmlClass{sym-ff}{4d}}_{\text{MLP}} = \htmlClass{c-new}{12\,d^2}\ \text{（每层）},\qquad \htmlClass{sym-N}{N} \approx 12\,\htmlClass{sym-L}{L}\,d^2,\qquad C_{\text{前向}}\approx 2N,\qquad C_{\text{训练}}\approx 6N\ \ \text{（FLOPs / token）} \]
注意力是四个方阵，MLP 是两个“长条”矩阵，MLP 的参数是注意力的两倍（SwiGLU 三个 \(d\times\tfrac83 d\) 矩阵，也是 \(8d^2\)）。每个参数对每个 token 做一次乘加，前向就是 \(2N\)；训练还要反向，总共约 \(6N\)。
\(d\)
隐藏维度
\(d_{\text{ff}} = 4d\)
MLP 的中间维度，原版取 \(4d\)
\(N\)
不含嵌入层的参数量
\(L\)
层（块）数
玩具 \(d = 4\)：注意力 \(4\times 16 = 64\)；MLP 若按原版取 \(d_{\text{ff}} = 16\)，是 \(2\times 4\times 16 = 128\)；合计 \(192 = 12\times 4^2\)（手算时中间维度只取了 8，为了能把数字列出来）。GPT-3：\(L = 96\)，\(d = 12288\)，\(N \approx 12\times 96\times 12288^2 \approx 1.74\times 10^{11}\)，正是 175B。训练 3000 亿 token：\(6\times 1.75\times 10^{11}\times 3\times 10^{11}\approx 3.1\times 10^{23}\) FLOPs，与论文报告一致。

真实模型和 \(12Ld^2\) 有几处出入。嵌入层在小模型里占比显著（GPT-2 small 约三成），在大模型里可以忽略；GQA 让 \(W_K, W_V\) 变小，注意力的占比低于 \(1/3\)；Llama 3 8B 的 MLP 还有意比“等参数”多约 30%。合起来，Llama 3 8B 约 80 亿参数，每生成一个 token 前向约 \(1.5\times 10^{10}\) 次运算（输入嵌入只是查表，不算乘法），写一段 1000 个 token 的回答约 \(1.5\times 10^{13}\) 次。另有一项不在 \(N\) 里：注意力分数 \(QK^\top\) 和“乘 V”没有参数，但计算量随上下文长度增长，上下文一长就不能忽略，推导见第 章「代价」一节。

每 token 的计算量为什么是 2N 和 6N

第 1 步，前向。线性层 \(\mathbf y = \mathbf x W\)，\(W\) 是 \(d_{\text{in}}\times d_{\text{out}}\)：\(\mathbf y\) 的每个分量要 \(d_{\text{in}}\) 次乘法和 \(d_{\text{in}}\) 次加法，共 \(2d_{\text{in}}d_{\text{out}}\) FLOPs，正好是“每个权重 2 次”。

第 2 步，反向。要算传给前一层的 \(\partial\mathcal L/\partial\mathbf x = (\partial\mathcal L/\partial\mathbf y)W^\top\) 和更新这一层的 \(\partial\mathcal L/\partial W = \mathbf x^\top\,\partial\mathcal L/\partial\mathbf y\)，各是一次同样大小的矩阵乘法。前向 2 + 反向 4 = 每个参数每个 token 6 FLOPs（有更一般的推导）。

这个推导告诉我们：只要知道参数量和训练 token 数，就能估算训练成本，这是规模定律（第 章）的基础。

2026：连残差连接也开始改

块里只有一处在前沿模型里十年没动：把子层串起来的 \(\mathbf x + F(\mathbf x)\)。它有两个局限。一是带宽：所有层共用一条 \(d\) 维的残差流，前面写入的东西都挤在同一个空间里，后面的层只能读到等权相加的总和 \(\mathbf x_0 + \sum\Delta_j\)。二是 Pre-Norm 与 Post-Norm 的跷跷板：Pre-Norm 稳定但深层被稀释，Post-Norm 每层占比均衡但梯度没有恒等通路。字节跳动 2024 年的超连接（hyper-connections）想两头兼顾：把残差流扩成 \(n_s\) 条并行的流，每层用可学习的矩阵决定各条流怎样混合、子层从哪条读、写回哪条，让网络自己学“残差有多强”。2026 年的两个前沿模型沿两个方向改了残差：

  • DeepSeek 的 mHC（流形约束超连接，manifold-constrained hyper-connections，2025-12 论文，用于 2026-04 发布的 DeepSeek V4）：在超连接的基础上加约束。不加约束时，层层相乘的混合矩阵会把信号放大到失控：论文报告 27B 模型中放大倍数达到约 3000 倍，训练在约 1.2 万步时损失突然飙升。mHC 把混合矩阵约束为双随机矩阵（元素非负、每行每列之和都为 1），这种矩阵不会放大信号，相乘之后仍是双随机矩阵。实际用 Sinkhorn 迭代只做有限次（论文 20 次），结果是近似双随机，所以实测最大放大约 1.6 倍，而不是严格的 1；\(n_s = 4\) 时额外开销约 6.7%。
  • Kimi 的 Attention Residuals（2026-03 论文，用于 2026-07 发布的 Kimi K3）：把等权相加 \(\mathbf x_0 + \sum_l F_l\)（「残差连接」一节的“总线”）改成每层用一个学到的查询向量，对之前各层的输出做 softmax 注意力，有选择地取用。它针对的正是 PreNorm 稀释。论文把残差连接看成“沿深度方向的 RNN”，这个改法就像当年用注意力替代 RNN。实用的分块版本（Block AttnRes）把层分成约 8 块、只对块的汇总做注意力，论文报告它达到基线多用 1.25 倍算力时的损失。一篇独立预印本分析学到的权重，发现早层多取嵌入、中层多取当前块，后层转向中间的块。

两种改法的共同点：都保留了一条“总和不被放大也不被衰减”的通路，残差连接最初的那条直通路径。

为什么双随机矩阵能保证稳定

超连接把残差流写成 \(n_s\times d\) 的矩阵 \(X_l\)，更新为 \(X_{l+1} = H_l X_l + (\text{分支输出})\)，其中 \(H_l\) 是 \(n_s\times n_s\) 的混合矩阵。直通路径经过 \(L\) 层后是 \(H_{L-1}\cdots H_1H_0\)。若每个 \(H\) 的最大放大倍数是 1.2，60 层后就是 \(1.2^{60}\approx 5.6\times 10^4\)。

双随机矩阵 \(H\)（\(H_{ij}\ge 0\)，\(\sum_j H_{ij} = \sum_i H_{ij} = 1\)）有三个性质：(1) 谱范数 \(\|H\|_2\le 1\)，它只能“混合”各条流，不能放大；(2) 两个双随机矩阵的乘积仍是双随机矩阵，所以任意多层的连乘也满足 (1)；(3) 每列和为 1，即 \(\mathbf 1^\top H = \mathbf 1^\top\)，所以 \(\mathbf 1^\top X_{l+1} = \mathbf 1^\top X_l + \mathbf 1^\top(\text{分支输出})\)：各条流之和这一分量原样传下去，正是普通残差的恒等路径。其它分量（各条流之间的差异）只会被混合或缩小，例如 \(H = \tfrac12\mathbf 1\mathbf 1^\top\)（\(n_s = 2\)）就把差异 \((1,-1)\) 抹成 0。\(n_s = 1\) 时 \(H\) 退化为标量 1，正是普通残差。mHC 用 Sinkhorn-Knopp 迭代（交替地把行和、列和归一化为 1）把任意正矩阵投影成近似双随机矩阵。

这个推导告诉我们：双随机约束保证的是“不放大”，以及“各条流之和不放大也不衰减”；单条流之间的差异可以衰减。普通残差用恒等矩阵满足这一点，mHC 在更大的一族矩阵里满足它，从而获得更灵活的跨层信息流。

架构改动到底有多重要

一种看法
规模和数据才是关键，架构细节影响很小。Narang 等（2021）在统一的代码库里测试了几十种 Transformer 改进，发现绝大多数无法稳定复现论文中的收益。
另一种看法
少数改动确实留了下来，并且在规模化后一直有效：Pre-Norm、SwiGLU、RoPE、GQA、MoE。2025–26 年的新结构仍在报告收益：Block AttnRes 报告约 1.25 倍的等效算力。Kimi K3 技术报告称，KDA、AttnRes、Stable LatentMoE 等结构改动加上数据与训练配方的改进，合计让规模效率比 K2 提高约 2.5 倍，但这个数无法单独归因给架构。
现在怎么看
大部分改动不值得做，但被大规模验证过的少数改动收益可观且会累积。判断一项改动要看它是否在多个规模、多个团队的实现中都成立，而不是一篇论文的单次结果。

常见误解

  • Transformer 的参数主要在注意力里。MLP 约占每层参数的三分之二；用 GQA 后注意力占比更低。MoE 模型里 MLP（专家）占绝大部分。
  • 每一层都把向量“改写”成新的表示。Pre-Norm 结构下，每层只往残差流里加一个修改量，嵌入和前面各层写入的内容一直原样留在里面（「从零开始」的 \(\mathbf x' = \mathbf x + \mathbf a + \mathbf m\)）。“覆盖”只能靠专门写入相反数来实现。
  • 位置编码加在输入嵌入上。那是 2017–2022 年的主流做法（GPT-2/3、OPT 都把可学习的位置向量加在输入上）。RoPE 在每一层的注意力内部旋转 q 和 k，value 和残差流里都没有位置编码。
  • 用了 RoPE，模型就能处理任意长度。超出训练长度后，低频平面会转到没见过的角度。需要调大 base 或插值，并在长文本上继续训练。

演进史

块的演进是两条互不依赖的线：残差与归一化管“能不能堆深”，位置编码管“知不知道顺序”。块内其它部件（ReLU 换 SwiGLU、去掉偏置、GQA）见上面的对照表。两条线在 2023 年的 LLaMA 配方里汇合：Pre-RMSNorm + SwiGLU + RoPE + 去偏置，经 PaLM（2022）、LLaMA（2023-02）大规模验证后，成为几乎所有开源模型的起点。

残差连接与层归一化

卡在哪
网络加深到几十层后，连训练集上的误差都变高：不是过拟合，是优化不动。BatchNorm 按批次统计均值方差，序列长度不一、逐个生成时都不好用。
怎么解决
ResNet 让每层只学一个修改量、加回输入，梯度有了直通路径；LayerNorm 对每个位置的向量单独标准化，与批次无关。
代价
分支的贡献层层累加；归一化放在残差的哪一侧，后来证明影响很大。
引出
原版 Transformer 把两者都用上了。
被简化取代Highway Networks（2015）
同年稍早，用一个学到的门在“直通”和“变换”之间加权。ResNet 证明不需要门、直接相加就够了，而且更好训练。十年后，超连接、mHC 和 Attention Residuals 又以受约束的方式把“可学习的跨层混合”带了回来。
2017-06

原版 Transformer：Post-Norm

卡在哪
RNN 不能并行，远距离依赖难学（第 章）。
怎么解决
注意力 + ReLU 前馈网络，每个子层之后“相加再归一化”，编码器、解码器各 6 层。
代价
要 4000 步学习率预热才训得稳，层数再多就难训。
引出
怎样把它堆得更深、训得更稳？
2018–2020

Pre-Norm 成为默认

卡在哪
模型加深后 Post-Norm 经常发散。
怎么解决
翻译模型里先有人把归一化移到子层之前；GPT-2（2019，最大 48 层）把它带进语言模型，并把残差分支的初始化缩小 \(1/\sqrt{2L}\)；T5 同年用了只缩放、不减均值的归一化，即 RMSNorm 的形式。Xiong 等（2020）从理论上解释了为什么 Pre-Norm 可以不用预热。
代价
残差流不再被归一化，深层的贡献被稀释。
引出
深层到底有没有被用上？
另一条路DeepNet（2022）：保留 Post-Norm
把残差乘一个大于 1 的系数、分支初始化缩小，让直通路径占主导，训练出 1000 层的模型。
部分保留并行块（GPT-J 2021、PaLM 2022）
把注意力和 MLP 并排计算、一起加回残差，PaLM 报告大规模下训练快约 15%，质量损失很小。多数后来的模型仍用串联结构。
2024–2025

稀释被量化，归一化开始打补丁

卡在哪
Gromov 等（2024）删掉后部近一半的层性能下降很小；Sun 等（2025）把原因归到 Pre-Norm 的残差流增长。
怎么解决
Gemma 2（2024-06）在子层前后各放一次归一化，OLMo 2（2024-11）把归一化移到子层输出上；Sun 等提出按 \(1/\sqrt l\) 缩放归一化输出。
代价
只是在归一化的位置上折中，残差的等权求和没变。
引出
能不能改残差连接本身？
2024-09 – 2026

改残差本身：超连接、mHC、Attention Residuals

卡在哪
单条残差流是 \(d\) 维的带宽瓶颈，等权求和让深层被稀释。
怎么解决
超连接（2024-09）把残差流扩成多条；mHC（2025-12，DeepSeek V4）用双随机约束管住放大；Attention Residuals（2026-03，Kimi K3）沿深度做注意力。
代价
额外的显存和通信开销，需要专门的内核和并行策略配合。
引出
仍在发展，见上一节。
重新兴起循环使用同一组层（looped Transformer）
Universal Transformer（2018）和 ALBERT（2019）让多层共享参数，当时没有成为主流。2025 年它以“循环深度”的形式回归：让同一组层反复计算多次，用推理时的额外计算换取更好的推理能力（如 Huginn、Ouro，以及在 ARC 上表现突出的小型递归模型 HRM、TRM）。能否在大模型上取代“多算几步思维链”，仍有争论（第 章）。

线二：位置编码

2017-06

正弦编码，加在输入上

卡在哪
注意力是置换等变的，不知道顺序。
怎么解决
每个位置一个固定的正弦向量，加到嵌入上；GPT、BERT 改用可学习的位置向量。
代价
绝对位置混进注意力分数；可学习的位置向量不能外推。
引出
位置能不能只以“相对距离”进入分数？
2019–2021

相对位置偏置：T5、ALiBi

卡在哪
同上。
怎么解决
直接给分数加一个只依赖距离的标量：T5 分桶查表，ALiBi 随距离线性变负。
代价
位置与内容不能相互作用；T5 的查表在实现上偏慢。
引出
能不能既只看相对位置、又和内容相乘？
基本退出T5 偏置、ALiBi、可学习位置嵌入
Transformer-XL（2019-01）、XLNet（2019-06）更早用过相对位置的写法。ALiBi 外推性好，被 BLOOM、MPT 采用，但在长上下文扩展上不如 RoPE 灵活，2023 年后新模型基本都选了 RoPE。
2021-04

RoPE：用旋转编码位置

卡在哪
同上。
怎么解决
按位置旋转 q、k，分数只依赖相对位置且与内容相乘；没有额外参数。PaLM、LLaMA 之后成为标准。
代价
训练长度之外，低频平面转到没见过的角度。
引出
上下文怎样扩到训练长度之外？
2023–2024

改频率扩上下文：插值、NTK、YaRN、大 base

卡在哪
训练 4K 的模型推到更长就乱。
怎么解决
位置插值、NTK 缩放、YaRN 都只改 RoPE 的频率；Llama 3 把 base 调到 50 万，配合分阶段的长文本训练（第 章）。
代价
每扩一次都要重新调频率、再训一段。
引出
能不能干脆少用显式的位置编码？
2022–2026

NoPE 与混合

卡在哪
Haviv 等（2022）、Kazemnejad 等（2023）发现因果掩码本身就泄露位置，去掉位置编码只略差、外推更好。
怎么解决
Llama 4（2025）、SmolLM3 让部分层不用 RoPE；Kimi Linear（2025-10）、Kimi K3（2026-07）的全注意力层一律不用，位置交给线性注意力层。
代价
纯 NoPE 在大规模下仍吃亏，必须和带顺序的层混合。
引出
仍在发展。

自测

1. Llama 3 8B：\(d = 4096\)，32 层，32 个 Q 头、8 个 KV 头（每头 128 维），SwiGLU 中间维度 14336，词表 128256，输入输出嵌入不共享。估算总参数量。
每层注意力：\(W_Q\) 与 \(W_O\) 各 \(4096^2\approx 16.8\)M；8 个 KV 头共 \(8\times128 = 1024\) 维，\(W_K, W_V\) 各 \(4096\times 1024\approx 4.2\)M；合计约 41.9M。每层 MLP：\(3\times 4096\times 14336\approx 176.2\)M。每层约 218M，32 层约 6.98B。嵌入和输出层：\(2\times 128256\times 4096\approx 1.05\)B。总计约 8.03B。
2. RoPE 为什么只旋转 query 和 key，不旋转 value？
位置只需要影响“看谁”，也就是注意力分数 \(\mathbf q\cdot\mathbf k\)；旋转 q、k 正好让分数只依赖相对位置。value 是被搬运的内容，如果也按位置旋转，输出里就混入了绝对位置，不同位置搬来的内容方向各异，后续层更难使用，也失去了“只依赖相对位置”的性质。
3. 把「从零开始」的玩具块从 Pre-Norm 换成 Post-Norm，嵌入向量 \(\mathbf x_0 = (2, 0, -1, 1)\) 还会原样留在这个块的输出里吗？堆 48 层之后呢？
不会。Post-Norm 每个子层之后都对整个向量归一化：第一个子层就把 \(\mathbf x + \mathbf a\) 整体除以 1.31，\(\mathbf x\) 只以缩小后的形式存在。若每层写入与残差流大小相当，嵌入的占比每个子层约缩小 \(1/\sqrt 2\)，48 层（96 个子层）后约 \(2^{-48}\)，几乎被冲掉。Pre-Norm 下残差流只做加法，\(\mathbf x_0\) 原样留到最后，输出层读到的是 \(\mathbf x_0 + \sum\Delta_j\)；它的绝对大小不变，只是相对份额随残差流变长而下降。
4. 一个 7B 的稠密模型在 2 万亿 token 上训练，大约需要多少 FLOPs？如果一块 GPU 实际能跑 400 TFLOPS，需要多少 GPU·天？
\(6\times 7\times 10^9\times 2\times 10^{12} = 8.4\times 10^{22}\) FLOPs。单卡每天 \(4\times 10^{14}\times 86400\approx 3.5\times 10^{19}\) FLOPs，约需 \(8.4\times 10^{22}/3.5\times 10^{19}\approx 2400\) GPU·天，例如 256 块 GPU 跑约 9 天。
5. 动手算：用 SwiGLU 的“参数量不变”规则，估算 Llama 2 13B（\(d = 5120\)）的 MLP 中间维度（向上取到 256 的倍数），并比较它每层 MLP 的参数量与原版 \(4d\) 的两矩阵 MLP。
\(\tfrac83\times 5120\approx 13653\)，\(13653/256\approx 53.3\)，向上取整到 54，\(54\times 256 = 13824\)，与 Llama 2 13B 的实际配置一致。SwiGLU：\(3\times 5120\times 13824\approx 2.12\) 亿；原版：\(2\times 5120\times 20480\approx 2.10\) 亿。取整只多了约 1%。
