Transformer：注意力、MLP、归一化和残差怎样拼成一个块

从 2019 年的 GPT-2 到 2026 年的 DeepSeek V4、Kimi K3，大模型的主体都是同一种“块”堆几十到上百层。注意力只是块的一半。这一章把块里其余的部件逐个讲清：为什么要有残差连接，MLP 在做什么，归一化放在哪里、为什么放在那里，位置信息从哪来，参数和计算量怎样估算。最后看 2017 年至今块里换掉了什么，以及 2026 年连十年没动过的残差连接也开始被改。

上一章的注意力让每个位置能从其它位置收集信息，但它留下了三个问题：只有一层不够，层一深就难训练；注意力本质上只是加权平均，缺少逐位置的非线性加工；它对顺序完全不敏感。这一章的部件分别回答这三个问题。

  • 嵌入、softmax、logit：第 章
  • 激活函数、梯度与链式法则、雅可比矩阵：

一个块里有什么

今天的大语言模型几乎都是只有解码器（decoder-only）的 Transformer：只用带因果掩码的自注意力，任务统一成“预测下一个 token”。整个模型是：词嵌入 → 同一种Transformer 块重复 \(L\) 次 → 最后一次归一化 → 输出层得到 logit。每个块内部有两个子层，前后各一次归一化和残差相加：

\[ \htmlClass{sym-h}{\mathbf h} = \htmlClass{c-dir}{\mathbf x} + \htmlClass{sym-attn}{\operatorname{Attn}}\big(\htmlClass{sym-norm}{\operatorname{Norm}}(\mathbf x)\big),\qquad \htmlClass{sym-xp}{\mathbf x'} = \htmlClass{c-dir}{\mathbf h} + \htmlClass{sym-mlp}{\operatorname{MLP}}\big(\operatorname{Norm}(\mathbf h)\big) \]
先归一化，再做注意力，结果加回原向量；再归一化，过 MLP，结果再加回去。每个子层都只是在原向量上做“增量修改”。
\(\mathbf h\)
注意力子层之后的中间结果
\(\operatorname{Attn}\)
多头因果自注意力（第 章），唯一在位置之间交换信息的部件
\(\operatorname{Norm}\)
归一化（RMSNorm），把向量缩放到固定的尺度，见下文
\(\operatorname{MLP}\)
逐位置的前馈网络，每个位置独立计算，见下文
\(\mathbf x'\)
这个块的输出，作为下一个块的输入
Llama 3 8B：\(L = 32\) 个块，每个位置的向量 \(d = 4096\) 维。一个 token 从嵌入到输出要经过 32 次注意力、32 次 MLP、65 次归一化和 64 次残差相加。

点击下图中的组件查看说明。这是 2023 年以后的“现代标准块”（Llama 风格）：Pre-RMSNorm、RoPE、GQA、SwiGLU。下文逐个解释这些名字。

残差连接：让梯度能穿过一百层

块公式里的“加回去”就是残差连接（He 等, 2015）：一个子层 \(F\) 不直接输出新向量，而是输出一个修改量，加到输入上：

\[ \htmlClass{sym-x}{\mathbf x_{l+1}} = \htmlClass{c-dir}{\mathbf x_l} + \htmlClass{c-adv}{\htmlClass{sym-F}{F_l}(\mathbf x_l)}\quad\Longrightarrow\quad \frac{\partial \mathcal L}{\partial \mathbf x_l} = \frac{\partial \mathcal L}{\partial \mathbf x_L}\prod_{k=l}^{L-1}\Big(\htmlClass{c-dir}{I} + \htmlClass{sym-J}{\frac{\partial F_k}{\partial \mathbf x_k}}\Big) \]
每一层的输出 = 原样传下去的输入 + 这一层算出来的修改。反向传播时，每层的雅可比矩阵都是“单位矩阵 + 子层的雅可比”，所以梯度总有一条不经过任何乘法衰减的直通路径。
\(\mathbf x_l\)
第 \(l\) 层的输入向量
\(F_l\)
第 \(l\) 层的子层（注意力或 MLP，含归一化）
\(\partial F_k/\partial\mathbf x_k\)
子层的雅可比矩阵：输入微小变化时，输出怎样变化
48 层，每层把梯度缩小到 0.9 倍。没有残差：\(0.9^{48}\approx 0.006\)，第一层几乎收不到梯度。有残差：展开连乘，其中“全部取 \(I\)”的那一项就是 \(\partial\mathcal L/\partial\mathbf x_L\) 本身，原封不动地到达第一层。

由此产生理解 Transformer 的一个重要视角：每个位置上有一条贯穿所有层的向量，叫残差流（residual stream）。注意力和 MLP 都不替换它，只是从中读取信息、算完再写回去。注意力负责把别的位置的信息搬到当前位置，MLP 负责在当前位置内部加工；所有层共享这条“总线”，后面的层可以读到前面任何一层写入的内容。

不过，残差连接只保证梯度有路可走，不保证大小合适。如果每个分支在初始化时就输出很大的修改，层层相加之后，前向的激活和反向的梯度仍会慢慢变大。GPT-2 的做法是在初始化时把每个残差分支的输出层缩小 \(1/\sqrt{2L}\) 倍。下面的演示用真实的随机矩阵相乘，比较三种结构；切到第二页可以看到 Pre-Norm 结构的一个副作用（下一节解释）：

展开连乘：残差网络像很多浅网络的集成

把 \(\prod_{k}(I + J_k)\) 展开，每一项对应“在每一层选择走直通（\(I\)）还是走分支（\(J_k\)）”：

\[ \prod_{k=l}^{L-1}(I + J_k) = I + \sum_{k} J_k + \sum_{k<k'} J_{k'}J_k + \cdots + J_{L-1}\cdots J_l \]

\(L - l\) 层一共有 \(2^{L-l}\) 条路径，经过 \(m\) 个分支的路径有 \(\binom{L-l}{m}\) 条。如果每个 \(J_k\) 的典型大小小于 1，经过分支越多的路径贡献越小，梯度主要来自只经过少数几个分支的“短路径”。Veit 等（2016）在 ResNet 上验证了这一点：随机删掉一层，性能只略微下降，因为大部分路径并不经过它；而普通的深层网络删掉任何一层都会崩溃。

这个推导告诉我们：残差网络的有效深度远小于名义层数。这既是它好训练的原因，也提示深层可能没有被充分利用，这一点在下一节的 Pre-Norm 中会再次出现。

MLP：逐位置的加工与“键值记忆”

注意力的输出只是 value 的加权平均，本质上是线性的混合。每个块的第二个子层是一个两层的全连接网络，叫前馈网络（FFN，也常叫 MLP）。它对每个位置独立计算，不看其它位置。原版 Transformer 的写法是：

\[ \operatorname{FFN}(\mathbf x) = \htmlClass{sym-phi}{\phi}\big(\mathbf x\,\htmlClass{sym-W1}{W_1}\big)\,\htmlClass{sym-W2}{W_2}\qquad\longrightarrow\qquad \operatorname{SwiGLU}(\mathbf x) = \Big(\operatorname{SiLU}(\mathbf x W_1)\ \htmlClass{c-new}{\odot\ \mathbf x\,\htmlClass{sym-W3}{W_3}}\Big)\,W_2 \]
先把 \(d\) 维放大到 \(d_{\text{ff}}\) 维，过一个非线性函数，再压回 \(d\) 维。右边是 2023 年以后的标准：多一个矩阵 \(W_3\)，它的输出和激活结果逐元素相乘，起“门”的作用。
\(W_1\)
\(d\times d_{\text{ff}}\)，升维；原版 \(d_{\text{ff}} = 4d\)
\(\phi\)
激活函数：原版用 ReLU \(\max(0, z)\)，GPT-2 起用更平滑的 GELU
\(W_2\)
\(d_{\text{ff}}\times d\)，降维回到残差流
\(W_3\)
\(d\times d_{\text{ff}}\)，门控分支；有了它，SwiGLU 有三个矩阵，所以 \(d_{\text{ff}}\) 通常取约 \(\tfrac83 d\)，使总参数仍是 \(8d^2\)
\(\operatorname{SiLU}(z) = z\cdot\sigma(z)\)（\(\sigma\) 是 sigmoid）。\(\operatorname{SiLU}(2) = 2\times 0.88 = 1.76\)，\(\operatorname{SiLU}(-2) = -2\times 0.12 = -0.24\)。如果对应的门 \(\mathbf xW_3\) 那一维是 0，不管激活值多大，这一维的输出都是 0；门是 \(-1\)，输出就反号。两个线性投影相乘，让 MLP 能表达“当 A 且 B 时”这类乘法关系。

这种带门的结构叫SwiGLU（Shazeer, 2020）。在参数量相同时，它比 ReLU / GELU 版本效果稍好且稳定，PaLM 和 LLaMA 之后成为默认选择。论文作者坦言无法从理论上解释为什么它更好，这是典型的经验驱动的改进。

MLP 占了每层约三分之二的参数。它存了什么？一个有用的视角是把它看成一张巨大的“键值表”：

MLP 是一张键值记忆表

把 \(W_1\) 的第 \(i\) 列记作 \(\mathbf k_i\)，\(W_2\) 的第 \(i\) 行记作 \(\mathbf v_i\)。矩阵乘法按中间维度展开：

\[ \operatorname{FFN}(\mathbf x) = \sum_{i=1}^{d_{\text{ff}}} \phi(\mathbf x\cdot\mathbf k_i)\ \mathbf v_i \]

对比注意力：\(\mathbf o = \sum_j \operatorname{softmax}_j(\mathbf q\cdot\mathbf k_j)\,\mathbf v_j\)。形式几乎一样：用当前向量去匹配一组“键”，按匹配程度把对应的“值”加起来。区别在于：注意力的键值来自上下文中的其它 token，MLP 的键值是训练时学到、固定在参数里的；MLP 用激活函数而不是 softmax，所以很多键可以同时被激活或同时不激活。

Geva 等（2021）检查了训练好的模型：低层 MLP 的键常对应浅层模式（例如“以某个词结尾的句子”），高层的键对应语义主题；值向量投到词表上，会提高某些下一个 token 的概率。后来的知识编辑研究（ROME, 2022）发现，改动中间层 MLP 的一个低秩部分，就能把“埃菲尔铁塔在巴黎”改成“在罗马”。

这个推导告诉我们：注意力从上下文里检索，MLP 从参数里检索。模型的“知识”很大程度上存放在 MLP 里，这也是 MoE 把 MLP 拆成很多专家、扩大参数容量的出发点（第 章）。

知识真的存放在 MLP 的某个位置吗

主张
因果追踪（causal tracing）可以定位到存储某条事实的中间层 MLP，在那里修改权重就能改掉这条事实（ROME, 2022）。
反方
Hase 等（2023）发现，定位结果并不能预测在哪一层编辑效果最好：在“没有定位到”的层编辑，往往同样有效。编辑一条事实还常常连带改坏相关事实，或者换个问法就失效。
现在怎么看
知识是分布式存放的，并以叠加（superposition）的方式共用同一批神经元（第 章）。“某条知识在某一层”是有用的近似，不是精确描述。

归一化：放在哪里比用哪种更重要

深层网络里，向量的大小会随层数漂移：某些层输出越来越大，某些越来越小，训练随之不稳定。层归一化（LayerNorm, 2016）对每个位置的向量单独做标准化；RMSNorm（2019）把它简化成只除以均方根：

\[ \operatorname{LayerNorm}(\mathbf x) = \htmlClass{sym-g}{\mathbf g}\odot\frac{\mathbf x - \htmlClass{sym-mu}{\mu}}{\sqrt{\htmlClass{sym-s2}{\sigma^2} + \epsilon}} + \mathbf b,\qquad \operatorname{RMSNorm}(\mathbf x) = \mathbf g\odot\frac{\mathbf x}{\sqrt{\htmlClass{c-new}{\tfrac1d\sum_i x_i^2} + \epsilon}} \]
LayerNorm：减去均值、除以标准差，再乘一组可学习的缩放系数。RMSNorm：不减均值，也不加偏置，只除以均方根，计算更省，效果几乎一样。
\(\mu\)
向量 \(\mathbf x\) 各分量的平均值
\(\sigma^2\)
各分量的方差
\(\mathbf g\)
可学习的逐维缩放系数（\(\mathbf b\) 是可学习的偏置）；\(\epsilon\) 是防止除以 0 的小常数
\(\mathbf x = (1, 2, 3, 6)\)。LayerNorm：\(\mu = 3\)，\(\sigma^2 = (4+1+0+9)/4 = 3.5\)，\(\sigma = 1.87\)，结果 \((-1.07,\ -0.53,\ 0,\ 1.60)\)。RMSNorm：均方根 \(\sqrt{(1+4+9+36)/4} = 3.54\)，结果 \((0.28,\ 0.57,\ 0.85,\ 1.70)\)。两者都把向量缩放到“每维约为 1”的尺度。

比用哪种归一化更关键的，是放在残差的哪一侧。原版 Transformer 是 Post-Norm：先相加再归一化；GPT-2 起改为 Pre-Norm：只对子层的输入归一化，残差路径上不做任何处理：

\[ \text{Post-Norm:}\ \ \mathbf x_{l+1} = \operatorname{Norm}\big(\mathbf x_l + F(\mathbf x_l)\big)\qquad\qquad \text{Pre-Norm:}\ \ \mathbf x_{l+1} = \mathbf x_l + F\big(\operatorname{Norm}(\mathbf x_l)\big) \]
为什么 Post-Norm 难训练、需要学习率预热

看残差的直通路径。Pre-Norm 中，\(\mathbf x_{l+1} = \mathbf x_l + \cdots\)，直通路径的雅可比恰好是 \(I\)，与上一节完全一样。

Post-Norm 中，直通路径每层都要穿过一次归一化。初始化时，若 \(\mathbf x_l\) 和 \(F(\mathbf x_l)\) 每维方差都约为 1 且互不相关，它们的和方差约为 2，归一化要除以 \(\sqrt 2\)。于是直通路径每层把梯度缩小约 \(1/\sqrt2\)：

\[ \Big\|\frac{\partial\mathbf x_L}{\partial\mathbf x_l}\Big\|_{\text{直通}} \approx \Big(\frac{1}{\sqrt 2}\Big)^{L-l} \]

24 层就是 \(2^{-12}\approx 1/4096\)。靠近输入的层梯度很小，靠近输出的层梯度相对很大。Xiong 等（2020）的分析表明，Post-Norm 初始化时输出附近参数的梯度偏大，一上来就用大学习率会发散，必须先用很小的学习率“预热”几千步；Pre-Norm 各层梯度均衡，可以省掉预热。

这个推导告诉我们：Pre-Norm 的稳定性来自残差路径上的“干净恒等”。代价是残差流本身从不被归一化，会随层数变长（演示第二页）。DeepNet（2022）走另一条路：保留 Post-Norm，但把残差乘一个大于 1 的系数 \(\alpha\)，\(\operatorname{Norm}(\alpha\mathbf x + F(\mathbf x))\)，让直通路径占主导，训练出了 1000 层的 Transformer。

Pre-Norm 是不是让深层“白干活”了

主张
Pre-Norm 稳定好训，是事实上的标准，没必要再改。
证据
Pre-Norm 的残差流长度随层数约按 \(\sqrt l\) 增长，每层新写入的内容占比越来越小。Gromov 等（2024）删掉 Llama 2 70B 后部近一半的层，再做少量微调修复，问答类任务的性能下降很小；“深度的诅咒”（Sun 等, 2025）把原因归到 Pre-Norm，并提出按 \(1/\sqrt l\) 缩放归一化输出来缓解。
反方的做法
OLMo 2（2024）把归一化移到子层的输出上，Gemma 2/3 在子层前后各放一次（“夹心”归一化），都试图兼得稳定性和深层的有效性。Kimi 的 Attention Residuals（2026）把这个现象称为 PreNorm 稀释，干脆改掉残差的求和方式（见下文）。
现在怎么看
Pre-Norm 仍是主流，但“深层利用不足”已被广泛接受。2025–26 年的多种新结构，都是在不牺牲稳定性的前提下解决这个问题。

位置编码：注意力本身不知道顺序

注意力对输入顺序是置换等变的：把输入的 token 打乱，每个位置的输出只是跟着换位置，数值完全不变。“狗咬人”和“人咬狗”在它看来是同一组向量。

证明：不加掩码的注意力是置换等变的

设 \(P\) 是一个置换矩阵（每行每列恰有一个 1），\(PX\) 就是把 \(X\) 的行打乱。由于 \(Q = XW_Q\)，打乱后 \(Q\to PQ\)，同理 \(K\to PK\)、\(V\to PV\)。分数矩阵变为 \(PQ(PK)^\top = P\,QK^\top P^\top\)，即行和列按同样方式重排。按行 softmax 与重排可以交换顺序，所以：

\[ \operatorname{softmax}\big(P\,QK^\top P^\top\big)\,PV = P\,\operatorname{softmax}(QK^\top)\,P^\top P\,V = P\cdot\operatorname{Attention}(Q, K, V) \]

（\(P^\top P = I\)。）MLP 和归一化逐位置计算，本来就与顺序无关。所以整个块是置换等变的：输出只是同样地被打乱。

这个推导告诉我们：如果不注入位置信息，模型完全无法区分顺序。但注意一个例外：加了因果掩码后，第 \(i\) 个位置恰好能看到 \(i\) 个 token，这本身就泄露了位置信息。这就是下面的“不用位置编码也能工作”这一意外发现的原因。

所以需要另外注入位置编码。历史上有几种做法：

  • 正弦位置编码（2017）：给第 \(m\) 个位置一个固定向量，各维是不同频率的正弦和余弦，\(\sin(m/10000^{2i/d})\)、\(\cos(m/10000^{2i/d})\)，直接加到嵌入上。
  • 可学习的位置嵌入（BERT、GPT-2）：每个位置学一个向量。超出训练长度就没有对应的向量，无法外推。
  • 相对位置偏置（T5, 2019；ALiBi, 2021）：不改向量，直接给注意力分数加一个只依赖距离 \(m-n\) 的偏置，ALiBi 的偏置随距离线性变负。
  • 旋转位置编码 RoPE（苏剑林等, 2021）：今天的标准，下面详细讲。

RoPE 的想法是：不往向量上加东西，而是按位置旋转 query 和 key。把 \(d\) 维向量两两分组，看成 \(d/2\) 个二维平面，第 \(i\) 个平面按位置 \(m\) 旋转角度 \(m\theta_i\)。两个旋转后的向量做点积，结果只取决于它们的角度差，也就是相对位置：

\[ \big\langle \htmlClass{sym-R}{R_m}\,\mathbf q,\ R_n\,\mathbf k\big\rangle = \big\langle \mathbf q,\ R_{\htmlClass{c-new}{n-m}}\,\mathbf k\big\rangle,\qquad \htmlClass{sym-th}{\theta_i} = \htmlClass{sym-b}{b}^{-2i/d} \]
位置 \(m\) 的 query 转了 \(m\theta\)，位置 \(n\) 的 key 转了 \(n\theta\)，点积只看两者之差 \(n-m\)：绝对位置自然地变成了相对位置。
\(R_m\)
按位置 \(m\) 旋转的矩阵：\(d/2\) 个二维旋转拼成的分块对角阵，第 \(i\) 块转 \(m\theta_i\)
\(\theta_i\)
第 \(i\) 个平面的旋转频率，\(i = 0, 1, \dots, d/2 - 1\)。\(i\) 小的转得快，\(i\) 大的转得慢
\(b\)
base，原版取 10000；越大，最慢的那些平面转得越慢
一个平面，\(\theta = 0.5\)，\(\mathbf q = \mathbf k = (1, 0)\)。\(m = 5\)：q 转 2.5 弧度，变成 \((\cos 2.5, \sin 2.5)\)；\(n = 3\)：k 转 1.5 弧度。点积 \(= \cos(2.5 - 1.5) = \cos 1 \approx 0.54\)。把两者都后移 10 个位置（\(m = 15, n = 13\)），角度差仍是 1 弧度，点积不变。
第 1 步：把 query 和 key 的维度两两分组，每组看成一个二维平面。
第 2 步：位置 \(m\) 的 query，第 \(i\) 个平面旋转 \(m\theta_i\)；key 同理旋转 \(n\theta_i\)。value 不旋转。
第 3 步：旋转矩阵满足 \(R_m^\top = R_{-m}\)、\(R_{-m}R_n = R_{n-m}\)，所以点积只依赖 \(n - m\)。

不同平面的频率差别很大：\(d = 128\)、\(b = 10000\) 时，最快的平面每 6 个位置转一圈，用来分辨相邻的 token；最慢的平面要约 5 万个位置才转一圈，用来编码远距离。拖动下面的滑块验证“同时平移，点积不变”，并观察 base 对远程衰减的影响：

用复数看 RoPE，以及远程衰减从哪来

把第 \(i\) 个平面的两个分量看成一个复数 \(q^{(i)} = q_{2i} + \mathrm i\,q_{2i+1}\)。旋转 \(m\theta_i\) 就是乘以 \(e^{\mathrm i m\theta_i}\)。两个二维向量的点积等于 \(\operatorname{Re}[a\bar b]\)，所以：

\[ \operatorname{Re}\Big[q^{(i)}e^{\mathrm i m\theta_i}\ \overline{k^{(i)}e^{\mathrm i n\theta_i}}\Big] = \operatorname{Re}\Big[q^{(i)}\,\overline{k^{(i)}}\ e^{\mathrm i (m-n)\theta_i}\Big] \]

\(m\) 和 \(n\) 只以差的形式出现。完整的点积是 \(d/2\) 个平面之和。设 \(\mathbf q = \mathbf k\)（一个 token 和“自己的副本”比较），点积变成 \(\sum_i |q^{(i)}|^2\cos\big((m-n)\theta_i\big)\)。距离为 0 时所有余弦都是 1；距离增大，各平面的角度彼此错开，余弦有正有负、相互抵消，总和趋于 0。这就是 RoPE 的“远程衰减”：内容相同的两个 token，离得越远，匹配分数越低。base 越大，频率整体越低，衰减越慢。

这个推导告诉我们：RoPE 给模型的不只是“相对位置”，还有一个“越远越不相关”的先验。长上下文需要削弱这个衰减，所以要调大 base。

上下文扩展就是在改 RoPE。如果训练时只见过 8K 个位置，最慢的那些平面在训练中连一圈都没转完；推理时拉到 128K，它们会转到从没见过的角度，模型就乱了。几种修补方法：

  • 位置插值（PI, 2023）：把位置按比例压缩，\(m \to m\cdot L_{\text{train}}/L_{\text{test}}\)，让所有角度都落回见过的范围。代价是相邻位置的角度差也被压小，分辨近距离变难。
  • NTK-aware 缩放与 YaRN（2023）：只压缩低频平面、保留高频平面，YaRN 还对注意力分数做温度修正。少量长文本微调即可把上下文扩大数倍到数十倍。
  • 直接调大 base：Llama 3 用 \(b = 500{,}000\)，2025 年后的长上下文模型常用到数百万，配合分阶段的长文本继续训练（第 章）。

意外：不用位置编码也能工作

原以为
注意力是置换等变的，没有位置编码就分不清顺序，模型无法工作。
实际发现
Haviv 等（2022）发现，带因果掩码的语言模型去掉位置编码（NoPE），效果只略差；Kazemnejad 等（2023）发现它在超出训练长度时外推得更好。原因是因果掩码：第 \(i\) 个位置只能看到 \(i\) 个 token，模型可以借此“数”出自己的位置。
为什么
位置信息不一定要显式给出，结构本身就隐含了它。只有双向的编码器（如 BERT）才真正离不开位置编码。
现在怎么看
大规模下完全不用位置编码仍然吃亏，但混合使用成了一种趋势：Llama 4（2025）的部分层不用 RoPE（iRoPE），Cohere Command A 和 SmolLM3 也每隔几层放一个 NoPE 层，用于改善长上下文。

参数量和计算量

有了块的结构，就能估算一个模型有多少参数、算一个 token 要多少计算。计算量用FLOPs（浮点运算次数）衡量，一次乘法加一次加法记 2 FLOPs。

\[ \htmlClass{sym-N}{N} \approx 12\,\htmlClass{sym-L}{L}\,\htmlClass{sym-d}{d}^2,\qquad C_{\text{前向}}\approx 2N\ \ \text{FLOPs / token},\qquad C_{\text{训练}}\approx \htmlClass{c-new}{6N}\ \ \text{FLOPs / token} \]
每层约 \(12d^2\) 个参数：注意力的 Q、K、V、O 四个 \(d\times d\) 矩阵共 \(4d^2\)，MLP 两个 \(d\times 4d\) 矩阵共 \(8d^2\)（SwiGLU 三个 \(d\times\tfrac83 d\) 矩阵，也是 \(8d^2\)）。每个参数对每个 token 做一次乘加，前向就是 \(2N\)；训练还要反向，总共约 \(6N\)。
\(N\)
不含嵌入层的参数量
\(L\)
层（块）数
\(d\)
隐藏维度
GPT-3：\(L = 96\)，\(d = 12288\)，\(N \approx 12\times 96\times 12288^2 \approx 1.74\times 10^{11}\)，正是 175B。训练 3000 亿 token：\(6\times 1.75\times 10^{11}\times 3\times 10^{11}\approx 3.1\times 10^{23}\) FLOPs，与论文报告一致。
为什么训练是 6N：反向传播的计算量是前向的两倍

看一个线性层 \(\mathbf y = \mathbf x W\)，\(W\) 是 \(d_{\text{in}}\times d_{\text{out}}\)。前向：每个权重参与一次乘加，\(2d_{\text{in}}d_{\text{out}}\) FLOPs。反向需要两样东西：

\[ \frac{\partial\mathcal L}{\partial \mathbf x} = \frac{\partial\mathcal L}{\partial \mathbf y}\,W^\top\quad(\text{传给前一层}),\qquad \frac{\partial\mathcal L}{\partial W} = \mathbf x^\top\frac{\partial\mathcal L}{\partial \mathbf y}\quad(\text{更新这一层}) \]

两者各是一次同样大小的矩阵乘法，各 \(2d_{\text{in}}d_{\text{out}}\) FLOPs。前向 2 + 反向 4 = 每个参数每个 token 6 FLOPs。

这个推导告诉我们：只要知道参数量和训练 token 数，就能估算训练成本，这是规模定律（第 章）的基础。公式忽略了注意力分数本身的 \(n^2\) 项，序列长度远小于 \(6d\) 时误差不大（第 章最后一节）。

2026：连残差连接也开始改

从 2015 年的 ResNet 到 2025 年，残差连接一直是最简单的 \(\mathbf x + F(\mathbf x)\)。2026 年的两个前沿模型都改了它：

  • DeepSeek 的 mHC（流形约束超连接，2025-12 论文，用于 DeepSeek V4）：把单条残差流扩成 \(n\) 条并行的流，每层用可学习的矩阵混合它们（字节跳动 2024 年的“超连接”）。不加约束时，层层相乘的混合矩阵会把信号放大到失控：论文报告 27B 模型中放大倍数达到约 3000 倍，训练在约 1.2 万步时崩溃。mHC 把混合矩阵约束为双随机矩阵（元素非负、每行每列之和都为 1），这种矩阵的谱范数不超过 1，相乘之后仍是双随机矩阵，放大倍数因此被控制在约 1.6 倍，额外开销约 6.7%。
  • Kimi 的 Attention Residuals（2026-03 论文，据报道用于 Kimi K3）：普通残差把所有层的输出等权相加，\(\mathbf x_L = \mathbf x_0 + \sum_l F_l\)；它改成每层用一个学到的查询向量，对之前各层的输出做 softmax 注意力，有选择地取用。它针对的正是上面演示第二页的 PreNorm 稀释：等权相加让深层的贡献越来越小。论文把残差连接看成“沿深度方向的 RNN”，这个改法就像当年用注意力替代 RNN。后续的独立分析发现，学到的权重主要集中在最近的几层和最初的嵌入上。
为什么双随机矩阵能保证稳定

超连接把残差流写成 \(n\times d\) 的矩阵 \(X_l\)，更新为 \(X_{l+1} = H_l X_l + (\text{分支输出})\)，其中 \(H_l\) 是 \(n\times n\) 的混合矩阵。直通路径经过 \(L\) 层后是 \(H_{L-1}\cdots H_1H_0\)。若每个 \(H\) 的最大放大倍数是 1.2，60 层后就是 \(1.2^{60}\approx 5.6\times 10^4\)。

双随机矩阵 \(H\)（\(H_{ij}\ge 0\)，\(\sum_j H_{ij} = \sum_i H_{ij} = 1\)）有两个性质：(1) 谱范数 \(\|H\|_2\le 1\)，它只能“混合”各条流，不能放大；(2) 两个双随机矩阵的乘积仍是双随机矩阵，所以任意多层的连乘也满足 (1)。\(n = 1\) 时它退化为标量 1，正是普通残差。mHC 用 Sinkhorn-Knopp 迭代（交替地把行和、列和归一化为 1）把任意正矩阵投影成近似双随机矩阵。

这个推导告诉我们：残差连接的本质要求是“直通路径不放大也不衰减”。普通残差用恒等矩阵满足它，mHC 在更大的一族矩阵里满足它，从而获得了更灵活的跨层信息流。

架构改动到底有多重要

一种看法
规模和数据才是关键，架构细节影响很小。Narang 等（2021）在统一的代码库里测试了几十种 Transformer 改进，发现绝大多数无法稳定复现论文中的收益。
另一种看法
少数改动确实留了下来，并且在规模化后一直有效：Pre-Norm、SwiGLU、RoPE、GQA、MoE。2025–26 年的新结构仍在报告可观的收益：Attention Residuals 报告约 1.25 倍的等效算力；据报道，Kimi K3 的混合注意力与 Attention Residuals 合计带来约 2.5 倍的规模效率提升。
现在怎么看
大部分改动不值得做，但被大规模验证过的少数改动收益可观且会累积。判断一项改动要看它是否在多个规模、多个团队的实现中都成立，而不是一篇论文的单次结果。

常见误解

  • 现在的大模型是“编码器 + 解码器”的 Transformer。GPT 系列、Llama、Qwen、DeepSeek、Kimi 都只有解码器。编码器-解码器结构主要留在翻译、语音识别等输入输出分明的任务里。
  • Transformer 的参数主要在注意力里。MLP 约占每层参数的三分之二；用 GQA 后注意力占比更低。MoE 模型里 MLP（专家）占绝大部分。
  • 位置编码加在输入嵌入上。那是 2017 年的做法。RoPE 在每一层的注意力内部旋转 q 和 k，value 和残差流里都没有位置编码。
  • 用了 RoPE，模型就能处理任意长度。超出训练长度后，低频平面会转到没见过的角度。需要调大 base 或插值，并在长文本上继续训练。
  • 残差连接只是一个让训练快一点的小技巧。没有它，几十层的网络几乎无法训练；“残差流”也是理解模型内部信息流动的基本框架。

演进史

2015-12

ResNet：残差连接

卡在哪
网络加深到几十层后，连训练集上的误差都变高：不是过拟合，是优化不动。
怎么解决
每层只学一个修改量，加到输入上；梯度有了直通路径。
代价
激活值随层数累加，需要配合归一化和合适的初始化。
引出
序列模型该用什么归一化？
被简化取代Highway Networks（2015）
同年稍早，用一个学到的门在“直通”和“变换”之间加权。ResNet 证明不需要门、直接相加就够了，而且更好训练。十年后，mHC 和 Attention Residuals 又以受约束的方式把“可学习的跨层混合”带了回来。
2016-07

LayerNorm

卡在哪
BatchNorm 按批次统计均值方差，序列长度不一、批次小、推理时逐个生成，都让它不好用。
怎么解决
对每个位置的向量单独标准化，与批次无关。
代价
放在残差的哪一侧，后来证明影响很大。
引出
Transformer 采用了它，放在残差相加之后。
2017-06

原版 Transformer

卡在哪
RNN 不能并行，远距离依赖难学（第 章）。
怎么解决
注意力 + ReLU 前馈网络 + Post-LayerNorm + 正弦位置编码，编码器-解码器结构。
代价
Post-Norm 需要精心的学习率预热，深层难训；绝对位置编码难以外推。
引出
怎样把它堆得更深、训得更稳？
2019–2020

Pre-Norm 成为默认

卡在哪
模型加深后 Post-Norm 经常发散。
怎么解决
GPT-2 把归一化移到子层之前，并缩小残差分支的初始化；Xiong 等（2020）从理论上解释了为什么 Pre-Norm 可以不用预热。同期提出 RMSNorm。
代价
残差流不再被归一化，深层的贡献被稀释。
引出
块内其它部件还能怎么改进？
另一条路DeepNet（2022）与回归的 Post-Norm
DeepNet 保留 Post-Norm，把残差放大、分支初始化缩小，训练出 1000 层的模型。2024–25 年 OLMo 2、Gemma 等又把一部分归一化放回子层输出，说明“Pre 还是 Post”并没有最终答案。
2020–2023

“LLaMA 配方”定型：RMSNorm + SwiGLU + RoPE

卡在哪
各家用的组件五花八门，许多改进无法复现。
怎么解决
SwiGLU（2020）、RoPE（2021）经 PaLM（2022）、LLaMA（2023）大规模验证，与 Pre-RMSNorm、去掉偏置一起成为几乎所有开源模型的默认结构。
代价
结构趋同，差异转移到数据、训练方法和注意力变体上。
引出
上下文怎样从 4K 扩到 128K 以上？
基本退出可学习位置嵌入、T5 相对偏置、ALiBi
可学习位置嵌入无法外推；T5 的分桶相对偏置计算不便；ALiBi（2021）外推性好，被 BLOOM、MPT 采用，但在长上下文扩展上不如 RoPE 灵活，2023 年后新模型基本都选了 RoPE。
部分保留并行块（GPT-J 2021、PaLM 2022）
把注意力和 MLP 并排计算、一起加回残差，而不是先后串联，训练快约 15%。大模型上质量损失很小，但多数后来的模型仍用串联结构，少数（如 Cohere 的部分模型）保留了并行块。
2023–2024

长上下文与稳定性的修补

卡在哪
RoPE 超出训练长度就失效；规模变大后注意力分数和激活值失控。
怎么解决
位置插值、NTK、YaRN 和大 base 扩展上下文；QK-Norm、夹心归一化稳定训练；DeepSeek-V3 加入多 token 预测（MTP）。
代价
块越来越复杂，各种修补相互作用，难以单独归因。
引出
能不能从根本上改结构，而不只是打补丁？
2025–2026

重新审视深度方向

卡在哪
Pre-Norm 让深层贡献被稀释；单条残差流限制了跨层信息传递。
怎么解决
部分层去掉位置编码（Llama 4 等）；mHC 多残差流（DeepSeek V4）；Attention Residuals 沿深度做注意力（Kimi K3）；注意力层与线性注意力层混合（第 章）。
代价
额外的显存和通信开销，需要专门的内核和并行策略配合。
引出
块已经搭好，模型怎样用它一个 token 一个 token 地生成文本？
重新兴起循环使用同一组层（looped Transformer）
Universal Transformer（2018）和 ALBERT（2019）让多层共享参数，当时没有成为主流。2025 年它以“循环深度”的形式回归：让同一组层反复计算多次，用推理时的额外计算换取更好的推理能力（如 Huginn、Ouro，以及在 ARC 上表现突出的小型递归模型）。能否在大模型上取代“多算几步思维链”，仍有争论（第 章）。

自测

1. Llama 3 8B：\(d = 4096\)，32 层，32 个 Q 头、8 个 KV 头（每头 128 维），SwiGLU 中间维度 14336，词表 128256，输入输出嵌入不共享。估算总参数量。
每层注意力：\(W_Q\) 与 \(W_O\) 各 \(4096^2\approx 16.8\)M；\(W_K, W_V\) 各 \(4096\times 1024\approx 4.2\)M；合计约 41.9M。每层 MLP：\(3\times 4096\times 14336\approx 176.2\)M。每层约 218M，32 层约 6.98B。嵌入和输出层：\(2\times 128256\times 4096\approx 1.05\)B。总计约 8.03B。
2. RoPE 为什么只旋转 query 和 key，不旋转 value？
位置只需要影响“看谁”，也就是注意力分数 \(\mathbf q\cdot\mathbf k\)；旋转 q、k 正好让分数只依赖相对位置。value 是被搬运的内容，如果也按位置旋转，输出里就混入了绝对位置，不同位置搬来的内容方向各异，后续层更难使用，也失去了“只依赖相对位置”的性质。
3. 一个 7B 的稠密模型在 2 万亿 token 上训练，大约需要多少 FLOPs？如果一块 GPU 实际能跑 400 TFLOPS，需要多少 GPU·天？
\(6\times 7\times 10^9\times 2\times 10^{12} = 8.4\times 10^{22}\) FLOPs。单卡每天 \(4\times 10^{14}\times 86400\approx 3.5\times 10^{19}\) FLOPs，约需 \(8.4\times 10^{22}/3.5\times 10^{19}\approx 2400\) GPU·天，例如 256 块 GPU 跑约 9 天。
