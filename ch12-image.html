文生图与图生图：潜空间扩散、DiT 与原生多模态

第 11 章讲了去噪的数学。一个真实的文生图系统还要解决三件事：在哪个空间里去噪（像素太贵，要压缩到潜空间）、用什么网络去噪（U-Net → DiT → MMDiT）、怎么听懂提示词并接受各种控制（文本编码器、引导、编辑、参考图）。2025–26 年，这条线又和语言大模型合流了。

潜空间：先压缩，再扩散

直接在 1024×1024×3 的像素上做扩散，每一步都要处理三百万个数，而且大部分算力花在人眼察觉不到的高频细节上。潜空间扩散（Latent Diffusion, 2022，即 Stable Diffusion） 先训练一个 VAE，把图像压缩 8 倍（每边）成一个小的“潜图”，扩散只在潜图上做，最后再用 VAE 解码器还原成像素。

  • SD 1.x / SDXL：8× 下采样，4 个通道（512² 图像 → 64×64×4）。
  • SD3 / FLUX.1：通道数增加到 16，细节和文字更好。
  • DC-AE（2024）等深度压缩编码器：32× 甚至更高，用于高分辨率和视频。

Transformer 去噪器（DiT）还要把潜图再切成 2×2 的 patch，每个 patch 就是一个 token。分辨率和 token 数的关系决定了生成速度，因为注意力的代价随 token 数平方增长：

去噪网络：U-Net → DiT → MMDiT

  • U-Net（SD 1.x、SDXL）：卷积编码-解码结构，中间插入自注意力层和 交叉注意力 层。图像特征做 Q，文本向量做 K/V（第 2 章），每个像素位置去“查”提示词里的词。
  • DiT（Diffusion Transformer, 2022-12）：直接用 Transformer 处理 patch token，时间步 t 通过 adaLN（自适应层归一化）注入。扩展性和语言模型一样好，是 Sora 和之后所有大模型的基础。
  • MMDiT（SD3, 2024）：文本 token 和图像 token 拼成一条序列做 联合注意力，两种模态各有自己的权重。FLUX、Qwen-Image（20B, 2025-08）等沿用这一设计。
  • 文本编码器：从 CLIP（2021）到 T5-XXL（Imagen, 2022），再到 2025 年后直接用多模态大模型（如 Qwen2.5-VL）编码提示词。模型能理解长而复杂的描述，也能把中文、英文文字准确“写”进图里。

原生多模态：自回归回来了

扩散之外，另一条路线是 把图像也变成 token，让语言模型直接生成。早期的 DALL·E（2021）、Parti（2022）质量不如扩散；2024 年以后几项突破改变了局面：

  • VAR（2024，NeurIPS 最佳论文）：不按像素顺序，而是“由粗到细”预测下一个分辨率尺度。Infinity 再把 token 换成按比特（bitwise）预测。
  • MAR / Transfusion（2024）：自回归负责结构和语义，每个 token 用一个小扩散头生成连续值，避免离散化带来的损失。
  • GPT-4o 图像生成（2025-03）：语言模型原生生成图像，提示词理解、文字渲染、多轮编辑明显领先，让“统一模型”路线成为主流方向之一。
  • 统一理解与生成：Janus、BAGEL、HunyuanImage 3.0（80B MoE，自回归框架）等，同一个模型既能看图又能画图。2026 年 GPT Image 2、Nano Banana 2 / Pro 处在榜首，开源的 FLUX.2、Qwen-Image-2.0、Seedream 5.0 紧随其后。

为什么文本用自回归、图像用扩散？文本是离散、顺序性强的；图像是连续、空间上整体相关的，扩散擅长同时调整所有像素。统一模型通常把两者结合：语言模型负责“想清楚画什么”，扩散解码器负责“画得精细”。
